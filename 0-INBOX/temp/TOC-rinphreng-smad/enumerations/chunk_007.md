Enumeration Block 1:
བཞི་པ་མཚན་གྱི་ཡན་ལག་ལ་གཉིས་ལས། སྤྱི་དོན་ལ་གསུམ། ཐུན་མོང་དང་ཐུན་མོང་མིན་པའི་རབ་དབྱེ། ཐུན་མོང་དང་ཐུན་མོང་མ་ཡིན་པའི་དོན། མཚན་ཕྱི་མ་ལ་ཅིར་འགྱུར་རོ། །དང་པོ་ལ་གཉིས། ཐུན་མོང་བ་དང་། ཐུན་༄༅། །མོང་མིན་པའི་རབ་དབྱེའོ། །དང་པོ་ལ་གཉིས་ལས།
Enumeration Block 2:
གཉིས་པ་རྗེས་སུ་མཐུན་པའི་རབ་དབྱེ་ལ་གསུམ་ལས།
Enumeration Block 3:
གཉིས་པ་ཐུན་མོང་དང་ཐུན་མོང་མིན་པའི་དོན་ལ་གསུམ། དངོས་དང་། དེའི་རྒྱུ་མཚན་དང་། སོ་སོའི་དོན་ནོ། །
Enumeration Block 4:
གསུམ་པ་མཚན་ཕྱི་མ་ལ་ཅིར་འགྱུར་ལ་གཉིས་ལས།
Enumeration Block 5:
གཉིས་པ་གཞུང་དོན་ལ་གསུམ། མདོར་བསྟན། རྒྱས་བཤད། དེ་དག་གི་རྒྱུ་མཚན་བསྟན་པའོ། །
