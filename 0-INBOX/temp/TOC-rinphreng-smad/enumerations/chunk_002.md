Enumeration Block 1:
དགུ་པ་གོས་ལས་གྱུར་པ་ལ་ལྔ་ལས། གསུ་བེལ་པ་གསུམ་ནི།
Enumeration Block 2:
བཅུ་པ་སེར་སྣ་ལས་གྱུར་པ་ལྔ་ནི།
Enumeration Block 3:
བཅུ་གཅིག་པ་གནས་ཁང་ལས་གྱུར་པ་ལ་གཉིས་ནི།
Enumeration Block 4:
བཅུ་གཉིས་པ་སྡོམ་པ་ལས་གྱུར་པ་བཅུ་དྲུག་གི་དང་པོ་མཐོ་འཚམ་པ་ནི།
Enumeration Block 5:
བརྙས་ཐབས་བྱེད་པ་གསུམ་ནི།
Enumeration Block 6:
ལྕི་བའི་ཆོས་ལས་འདས་པ་བཞི་ནི།
Enumeration Block 7:
གནོད་པ་སྤྱོད་པ་གསུམ་ནི།
