Enumeration Block 1:
གཉིས་པ་གང་མང་ལ་བཞི། ཞི་བྱེད་གཞན་ཡིན་པར་བསྟན་པ། གཞི་གང་ལ་བྱ་བ། བྱེད་པ་པོ་གང་གིས་བྱ་བ། ཚུལ་ཇི་ལྟར་བྱ་བའོ། །
Enumeration Block 2:
དེ་ཞི་བར་བྱ་བ་གཉིས་ལས།
Enumeration Block 3:
གླེང་བའི་ཁ་ན་མ་ཐོ་བ་མེད་པ་དེ་ནི་བཞི་སྟེ། མཐོང་ཐོས་དོགས་གསུམ་གྱི་གཞི་མེད་པ་ལ་གླེང་བ་དང་། ལྟུང་བྱེད་ལ་གཞན་དགེ་འདུན་ལྷག་མ་ལྟ་བུ་རྗེས་སུ་བསྒྲུབ་པའི་དབང་གིས་གླེང་བ་དང་། ལྟུང་བ་དེ་གླེང་བྱས་སྔར་ཕྱིར་བཅོས་ཟིན་པ་ལ་ཕྱིར་བཅོས་པ་ལ་མི་ལྟོས་པའི་ཕྱིར་གླེང་བ་དང་། སྨྱོན་པའི་གནས་སྐབས་སུ་བྱ་བ་མིན་པ་བྱས་པ་ལ་དེས་གླེང་བའོ། །
Enumeration Block 4:
གསུམ་པ་ལྟུང་ཕྱིར་རྩོད་པ་ཞི་བྱེད་ལ་གཉིས། ཉེས་པའི་ངོ་བོ་ཤེས་པའི་ཞི་བྱེད་དང༌། མི་ཤེས་པའི་ཞི་བྱེད་དོ། །དང་པོ་ལ་གཉིས་ལས།
Enumeration Block 5:
ལྟུང་བ་དང་བཅས་པ་ཉིད་ཀྱི་ཕྱིར་འཁྲུག་ལོང་རྣམ་པ་གསུམ་སྟེ། གླེང་བྱ་གླེང་བྱེད་གཉིས་ལས་གཞན་ལ་ཕྱིར་འཕྲོས་པ་མེད་པ། ཕྱོགས་དང་གཞན་གྱི་ཕྱོགས་སུ་རྣམ་པར་གནས་པ་དང་བྲལ་བ་དང་། དེ་གཉིས་སུ་མ་ཟད་གཞན་ལ་ཡང་ཕྱིར་འཕྲོས་པ་དང་བཅས་པ་རྣམ་པ་གཉིས་ཡོད་ལ། གཉིས་པོ་གང་ཞེ་ན། ཉི་ཚེ་བ་དགེ་འདུན་གྱི་ཁོངས་སུ་གཏོགས་པའི་ཁ་ཡར་བ་ལ་འཕྲོས་པ་དང༌། དགེ་སློང་གཅིག་ཀྱང་མ་ལུས་པར་དགེ་སློང་གི་དགེ་འདུན་མཐའ་དག་དང་འབྲེལ་བ་ཐམས་ཅད་ཕྱོགས་དང་གཞན་ཕྱོགས་སུ་གྱུར་པས་འཁྲུག་ལོང་དུ་གྱུར་པའོ། །
Enumeration Block 6:
གཉིས་པ་ཞི་བྱེད་དངོས་ལ་གཉིས་ལས།
Enumeration Block 7:
གཉིས་པ་རྒྱས་བཤད་ལ་གཉིས་ལས།
Enumeration Block 8:
ལུགས་གཞན་དགག་པ་ལ་གཉིས་ལས།
Enumeration Block 9:
དེ་དགག་པ་ལ་གསུམ་ལས།
