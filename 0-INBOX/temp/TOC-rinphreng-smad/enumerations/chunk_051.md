Enumeration Block 1:
གཉིས་པ་ལྟུང་བ་དངོས་བཤགས་པ་ལ་གཉིས། དགོས་པ་སྤྱིར་བཤད་པ་དང་། བསྡུས་དོན་སོ་སོར་བཤད་པའོ། །
Enumeration Block 2:
གཉིས་པ་བསྡུས་དོན་སོ་སོར་བཤད་པ་ལ་གསུམ་ཕམ་པའི་བཤགས་པའི་ཚུལ་དང༌། ལྷག་མའི། དེ་ལས་གཞན་པའོ། །

དང་པོ་ལ། ཆད་པའི་བསླབ་པ་ནོད་ཚུལ། དེ་ལ་སྤྱད་པའི་ཚུལ་ལོ། །

དང་པོ་ལ་བདུན་ལས།
Enumeration Block 3:
གཉིས་པ་ལ་དྲུག་ལས།
Enumeration Block 4:
གཉིས་པ་ལྷག་མ་བཤགས་ཚུལ་ལ་གཉིས་ལས་མགུ་བ་ལའང་གཉིས་ལས།

གནོད་པ་ལ་བདུན་ལས།
Enumeration Block 5:
གཉིས་པ་སྤྱད་པའི་ཚུལ་ལ་བདུན་ལས།
Enumeration Block 6:
གཉིས་པ་དབྱུང་བས་བཅོས་པ་ལ་ལྔ་ལས།
Enumeration Block 7:
གཉིས་པ་ཚིག་གི་དོན་ལ་གཉིས། རང་སྟོབས་ཀྱིས་ཕྱིར་བཅོས་པ་དང་། གཞན་སྟོབས་ཀྱིས་སོ། །དང་པོ་ལ་གཞི་གསུམ་ལས་ཕྱིར་བཅོས་པའི་གཞི་ལ་ལུང་གི་བྱེ་བྲག་གཉིས་ལས།

གཞི་ལ་གཉིས། ནན་ཏུར་ཇི་ལྟར་བྱ་བ་དང་། ཕྱིར་བཅོས་ཇི་ལྟར་བྱ་བའོ། །དང་པོ་ལ་གསུམ། གཞི་གང་ལ་ནན་ཏུར་བྱ་བ་སྤྱིར་བཤད་པ། བཟོད་པ་བྱ་བའི་ཚུལ་ཞར་བྱུང་དང་བཅས་པ། རྒྱུ་གང་ལ་ནན་ཏུར་བྱ་བ་བྱེ་བྲག་ཏུ་བཤད་པའོ། །
Enumeration Block 8:
གསུམ་པ་ལ་གསུམ། སྨད་པ་ནན་ཏུར་བྱ་བ། སྤང་བ་ནན་ཏུར་བྱ་བ། མཇུག་གི་ཆོ་གའོ། །
