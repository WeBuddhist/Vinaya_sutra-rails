Enumeration Block 1:
གསུམ་པ་དེ་ལས་གཞན་པའི་རྩོད་པ་ཞི་བར་བྱ་བ་ལ་གཉིས་ལས། གཞིའི་སྐབས་ནས་འབྱུང་བ་ལ་གསུམ། འཁྲུག་ལོང་གི་རྒྱུ། ཞི་བྱེད་ཀྱི་ཆོས། དེ་དང་འབྲེལ་བའི་བསླབ་བྱའོ། །
Enumeration Block 2:
དེའི་རྒྱུ་བཞི་སྟེ། ཆོས་ཡིན་མིན་དང་རྟག་མི་རྟག་སོགས་དངོས་པོའི་དེ་བཞིན་ཉིད་དམ་གནས་ལུགས་ལ་ལོག་པར་བསྒྲུབ་པ་དང་། གདམས་ངག་ལ་སོགས་པ་འཇོག་པས་གཞན་སྤོང་བ་དང་། ལྟུང་བ་སྡེ་ལྔ་དང་བཅས་པ་ཉིད་ལ་བྱས་མ་བྱས་དང་ལུས་ཀྱི་ལྟུང་བ་ཡིན་གྱི། ངག་དང་སེམས་ཀྱི་མ་ཡིན་པ་སོགས་དང་། གསོལ་བ་ལ་སོགས་པའི་ལས་ལ་མཐུན་པ་མི་སྦྱིན་པའོ། །
Enumeration Block 3:
གཉིས་པ་ཞི་བྱེད་ཀྱི་ཆོས་ལ་གཉིས་ལས།
Enumeration Block 4:
རྒྱུ་གཉིས་པ་སྤོང་བ་ལས་བྱུང་བ་མི་བསྡམས་ཕྱིར་རྩོད་པ་ནི། གཞི་བཅས་དང་གཞི་མེད་གཉིས་ལས།
Enumeration Block 5:
རྒྱུ་གསུམ་པ་ལྟུང་བ་དང་བཅས་པ་ཉིད་ལས་བྱུང་བ་ལྟུང་ཕྱིར་རྩོད་པ་ནི་གཉིས་ལས།
Enumeration Block 6:
གཉིས་པ་རྒྱས་བཤད་ལ་གསུམ། འགྱེད་ཕྱིར་རྩོད་པ་ཞི་བྱེད། སྤོང་ཕྱིར་རྩོད་པ་ཞི་བྱེད། ལྟུང་ཕྱིར་རྩོད་པ་ཞི་བྱེད་དོ། །དང་པོ་ལ་གཉིས། མངོན་སུམ་གྱིས་ཞི་བར་བྱ་བ་དང་། གང་མང་གིས་ཞི་བར་བྱ་བའོ། །
Enumeration Block 7:
གཉིས་པ་གང་མང་ལ་བཞི། ཞི་བྱེད་གཞན་ཡིན་པར་བསྟན་པ། གཞི་གང་ལ་བྱ་བ། བྱེད་པ་པོ་གང་གིས་བྱ་བ། ཚུལ་ཇི་ལྟར་བྱ་བའོ། །
