Enumeration Block 1:
གཉིས་པ་དུས་དང་དུས་མིན་པར་བསྡུས་པ་འབྱུང་བའི་གཞི་ལ་གཉིས་ལས།
Enumeration Block 2:
གཞིའི་སྐབས་ནས་འབྱུང་བ་ལ་གསུམ། འཆབ་པ་གང་ལ་འབྱུང་མི་འབྱུང་གི་བྱེ་བྲག །བླ་ཐབས་པའི་ཉེས་པ། ལྷག་མའི་ལྟུང་བ་ཕྱིར་བཅོས་ཐབས་སོ། །
Enumeration Block 3:
གཉིས་པ་ཞུ་བའི་སྐབས་ནས་འབྱུང་བ་ལ་གསུམ། འཆབ་པ་དངོས་ཀྱི་སེལ་བ། ཀུན་སློང་གི་མཚན་ཉིད། བླ་ཐབས་པའི་དམིགས་བསལ་ལོ། །
Enumeration Block 4:
གསུམ་པ་ས་གཞན་ན་གནས་པ་སྤྱོད་པའི་གཞི་ལ་གཉིས་ལས། གཞིའི་སྐབས་ནས་འབྱུང་བ་ལ་གཉིས་ལས། སྤྱི་དོན་ལ་དྲུག་ལས། སྤོ་སྤྱོད་གསུམ། སྤོ་ལྡན་གསུམ། མགུ་སྤྱོད་བཅུ་གཉིས། མགུ་ལྡན་བཅུ་གཉིས། ངོ་བོ་ཉིད་འཚོལ་བ་བྱིན་པ། བསླབ་པ་བྱིན་པ། བསྡིགས་སོགས་བཞི། གནས་ཕྱུང་བདུན་ཏེ་ཞེ་གསུམ་མོ། །
Enumeration Block 5:
བསྡུ་ན། དང་པོ་སོ་གཉིས་རྣམ་པར་དག་པའི་དང་། བར་མ་བཞི་སྨད་པའི་དང་། ཐ་མ་བདུན་སྤངས་པའི་ས་གཞན་པ་སྟེ་གསུམ་མོ། །
