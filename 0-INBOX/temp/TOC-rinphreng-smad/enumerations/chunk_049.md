Enumeration Block 1:
གསུམ་པ་ལ་གཉིས། མཚན་ཉིད་དང་མི་ལྡན་པས་ལས་མི་འཆགས་པར་བསྟན་པ། མཚན་ཉིད་དང་ལྡན་པས་ཐོས་དགོས་པར་བསྟན་པའོ། །
Enumeration Block 2:
བཞི་པ་ཕྱིར་བཅོས་པའི་གཞི་ལ་གཉིས། ལྟུང་བ་ཕྱིར་བཅོས་པའི་ཚུལ། རྩོད་པ་ཕྱིར་བཅོས་པའི་ཚུལ་ལོ། །དང་པོ་ལ་གཉིས། སྤྱིའི་དོན། ཚིག་གི་དོན་ནོ། །དང་པོ་ལ་གཉིས། ཕྱིར་བཅོས་པའི་ཐབས་ནན་ཏུར། ཕྱིར་བཅོས་པ་དངོས་སོ། །དང་པོ་ལ་དྲུག །དབྱེ་བ། བསྡུ་བ། ངོ་བོ། སྒྲ་དོན། དེ་ཇི་ལྟར་བྱ་བའི་ཚུལ། དགོས་པའོ། །དང་པོ་ནི། བཅུ་བཞི་སྟེ། བསྡིགས་པ་སྨད་པ་བསྐྲད་པ་ཕྱིར་(དགྱེད,འགྱེད)། གསོ་སྦྱོང་བཞག་པ། དགག་དབྱེ་༄༅། །བཞག་པ། གནས་ཕྱུང་བདུན། ལྷུང་བཟེད་ཁ་སྦུབ་པའོ། །
Enumeration Block 3:
ཡུལ་གྱི་དབང་གིས་བསྡུ་ན་གཉིས་ཏེ། རབ་ཏུ་བྱུང་བ་ལ་བྱ་བ། ཁྱིམ་པ་ལ་བྱ་བ་སྟེ།
Enumeration Block 4:
ཆོ་གའི་སྒོ་ནས་བསྡུ་ན་ཡང་གཉིས་ཏེ་གསོལ་བཞི་དང་། འབའ་ཞིག་གིས་བསྒྲུབ་པ་སྟེ་
Enumeration Block 5:
ངོ་བོའི་སྒོ་ནས་བསྡུ་ན་གསུམ་སྟེ། སྨད་པ་དང་། རྣམ་པར་དག་པ། སྤང་བའི་ནན་ཏུར་ཏེ།
Enumeration Block 6:
ལྔ་པ་ལ་དྲུག །ཡུལ་གང་ལ། བྱེད་པ་པོ། ཆོ་ག །གནས་དུས་གང་དུ། དེ་དག་གི་བསླབ་བྱ། གྲོལ་བའི་རྒྱུའོ། །
