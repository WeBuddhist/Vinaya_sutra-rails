Enumeration Block 1:
ལྔ་པ་ལ་དྲུག །ཡུལ་གང་ལ། བྱེད་པ་པོ། ཆོ་ག །གནས་དུས་གང་དུ། དེ་དག་གི་བསླབ་བྱ། གྲོལ་བའི་རྒྱུའོ། །
Enumeration Block 2:
གཉིས་པ་ཕྱིར་བཅོས་པ་དངོས་ལ་གཉིས། མཐོལ་བ་དང་། བཤགས་པའོ། །དང་པོ་ལ་ལྔ། ཡུལ། རྟེན། དངོས་པོ། ཆོ་ག །དགོས་པའོ། །
Enumeration Block 3:
གཉིས་པ་བཤགས་པ་ལ་གཉིས། འཆབ་པའི་ཉེས་པ་བཤགས་པ་དང་། ལྟུང་བ་དངོས་བཤགས་པའོ། །དང་པོ་ལ་གཉིས། བཤགས་པ་ཙམ་གྱིས་བཤགས་པ། ཞག་གི་ཆད་ལས་ཀྱི་སྒོ་ནས་བཤགས་པའོ། །དང་པོ་ལ་ལྔ་ལས།
Enumeration Block 4:
གཉིས་པ་ཞག་གི་ཆད་པའི་ལས་ཀྱི་སྒོ་ནས་བཤགས་པ་ལ་གཉིས། སྤོ་བ་ནོད་པ་དང༌། སྤྱད་པའོ། །དང་པོ་ལ་བདུན།
ཡུལ་གང་ལས།
རྟེན་གང་གིས། གང་གི་དོན་དུ། ཡུན་ཇི་སྲིད། ཆོ་ག །སྒྲ་དོན། དགོས་པའོ། །
Enumeration Block 5:
གཉིས་པ་སྤོ་བ་སྤྱད་པ་ལ་བདུན་ལས།
Enumeration Block 6:
གཉིས་པ་ལྟུང་བ་དངོས་བཤགས་པ་ལ་གཉིས། དགོས་པ་སྤྱིར་བཤད་པ་དང་། བསྡུས་དོན་སོ་སོར་བཤད་པའོ། །
