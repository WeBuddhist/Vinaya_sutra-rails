Enumeration Block 1:
ས་གོང་སྤོ་བས་གསུམ་བསྟན་ཏེ། །
བསྙེན་རྫོགས་དབྱུང་བ་བཟོད་པའོ། །
དགེ་འདུན་ལ་མཁོ་ལས་གཉིས་ཏེ། །

མཚམས་དགྲོལ་སྲ་བརྐྱང་དབྱུང་བའོ། །
Enumeration Block 2:
རབ་བྱུང་ལ་མཁོ་བས་བཅུ་དྲུག་སྟེ།
མཚམས་བཅད་མི་འབྲལ་མྱོས་པ་དང་། །
སྣམ་སྦྱར་སྟན་དང་ཕྱག་མི་བྱ། །

འཁོར་གཉིས་འཁར་བ་དྲ་བ་དང་། །
རྙེད་པ་གཅིག་བྱ་སྡོམ་གཉིས་དང་། །
བུ་དང་ཉེ་དུ་ཕྱིར་འགྲོ་བའོ། །
Enumeration Block 3:
རྗེས་སུ་གནང་བས་གསང་སྟེ་དང་། ནང་དུ་དང་། གསོ་སྦྱོང་དགག་དབྱེ་སྟེ་བཞིའོ། །
Enumeration Block 4:
སྦྱིན་པས་གཅིག་སྟེ། སྲ་བརྐྱང་གཏད་པ་དང་ཆོས་གོས་ངན་པ་ལ་སྦྱིན་པའོ། །
Enumeration Block 5:
རང་གིས་གནས་ངན་ལེན་བརྗོད་པ་དང་། ཚུལ་ཤིང་ལེན་པ་གཉིས་བསྟན་ནོ། །
Enumeration Block 6:
ཁྱིམ་པའི་དོན་རྣམ་པར་བཞག་པས་བསླབ་སྡོམ་དང་། ཁ་སྦུབ་གཉིས་སོ། །
Enumeration Block 7:
དབྱུང་བས་གཞིག་པ་དང་བཟློག་པ་གཉིས་བསྟན་ཏེ།
Enumeration Block 8:
གཉིས་པ་ཐུན་མོང་མིན་པ་ལ་བཞི། ལས་བྱེད་པ་དགེ་འདུན་གྱི་མཚན་ཉིད་འཆགས་དུས་དང་བཅས་པ། བྱེད་པ་པོ་ལས་མཁན་གྱི་མཚན་ཉིད་ཞར་བྱུང་དང་བཅས་པ། ལས་ཉམས་སུ་མྱོང་བའི་མཚན་ཉིད། ལས་དང་འབྲེལ་བའི་བྱ་བ་གཞན་བསྟན་པའོ། །
