Enumeration Block 1:
དགོས་འབྲེལ་ཡན་ལག་བཞི་པོ་རེ་རེ་ལ་གཉིས་གཉིས་སུ་ཕྱེ་བས་བརྒྱད་ཡོད་པ་ལས། བརྗོད་བྱ་ལ་གཉིས་ཏེ། དངོས་ཀྱི་བརྗོད་བྱ་དང་། ཞེན་པའི་བརྗོད་བྱའོ། །
Enumeration Block 2:
དགོས་པ་ལ་གཉིས་ཏེ། དགོས་པ་དོན་གྱི་ཆོས་སུ་བཞག་པ་དང་། དགོས་པ་ཤེས་པའི་ཆོས་སུ་བཞག་པའོ། །
Enumeration Block 3:
འབྲེལ་བ་ལ་གཉིས་ཏེ། བསྟན་བཅོས་དང་དགོས་པ་འབྲེལ་བ་དང་། དགོས་པ་དང་ཉིང་དགོས་འབྲེལ་བའོ། །
Enumeration Block 4:
ཉིང་དགོས་ལ་གཉིས་ཏེ། དགོས་པའི་དགོས་པ་གནས་སྐབས་པ་དང་། དགོས་པའི་དགོས་པ་མཐར་ཐུག་པའོ། །
Enumeration Block 5:
དྲུག་པ་དགོས་པ་ལ་སོགས་ལ་རྩོད་པ་སྤང་བ་ལ་བཞི་ལས།
Enumeration Block 6:
བཞི་པ་ཉིང་དགོས་ལ་རྩོད་པ་སྤོང་བ་ལ་གསུམ་སྟེ། བརྒལ་ལན་གྱི་སྒོ་ནས་ཉིང་དགོས་ངོས་བཟུང་བ་དང་། འདུས་བྱས་འདུས་མ་བྱས་ཀྱི་སྒོ་ནས་རྩོད་པ་སྤང་བ་དང༌། གནས་སྐབས་མཐར་ཐུག་གི་སྒོ་ནས་རྩོད་པ་སྤང་བའོ། །
