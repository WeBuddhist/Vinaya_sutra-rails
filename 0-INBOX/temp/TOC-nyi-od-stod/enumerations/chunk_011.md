Enumeration Block 1:
དེ་གཏན་ལ་དབབ་པ་ལ་གསུམ་ལས།
Enumeration Block 2:
དེ་ལ་གཉིས་ལས། དང་པོ་བསླབ་པ་པོའི་གང་ཟག་ཉེ་བར་བསྒྲུབ་པའོ། །
Enumeration Block 3:
འདི་ལ་གཉིས་ལས།
Enumeration Block 4:
འདིའི་སྤྱི་དོན་ལ་གཉིས་ཏེ། བསྙེན་པར་རྫོགས་པ་བཅུར་དབྱེ་བ་དང་། སྔོན་གྱི་ཆོ་ག་བྱེ་བྲག་ཏུ་བསྟན་པའོ། །
Enumeration Block 5:
གཉིས་པ་སྔོན་གྱི་ཆོ་ག་བྱེ་བྲག་ཏུ་བསྟན་པ་ལ་གཉིས་ལས།
Enumeration Block 6:
གཉིས་པ་སྔོན་ཆོག་གཏན་ལ་དབབ་པ་ལ་གསུམ་སྟེ། སྔོན་ཆོག་ལ་སྒྲོ་འདོགས་དགག་པ་དང་། སྔོན་ཆོག་དངོས་ཀྱི་དོན་བསྟན་པ་དང་། དབྱེ་བ་ལ་རྩོད་པ་སྤང་བའོ། །
དང་པོ་ལ་གཉིས་ཏེ། སྔོན་ཆོག་བཅུར་དགག་པ་དང༌། ཞར་ལ་བྱུང་བའོ། །
Enumeration Block 7:
ཁྱད་པར་དུ་ཡང་འཕྲིན་སྔོན་གྱི་ཆོ་གར་འདོད་པ་འདི་ལ་སྒྲུབ་བྱེད་ཀྱི་གཞུང་གཏན་ནས་མེད་ཅིང་གནོད་བྱེད་གསུམ་སྟེ།
