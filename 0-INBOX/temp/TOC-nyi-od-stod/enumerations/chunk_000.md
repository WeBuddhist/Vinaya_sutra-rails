Enumeration Block 1:
འདི་ལ་གཉིས་ཏེ། གཞན་འཇུག་པའི་ཡན་ལག་ཏུ་དགོས་འབྲེལ་བསྟན་པ་དང་། བརྗོད་བྱ་ངེས་པར་འབྱུང་བའི་ཚུལ་ཁྲིམས་བསྟན་པའོ། །
Enumeration Block 2:
འདི་ལ་གཉིས་ཏེ། སྤྱིའི་དོན་དང་། ཡན་ལག་གི་དོན་ནོ། །
དང་པོ་ལ་གཉིས་ཏེ། བསྟན་བཅོས་ཀྱི་དབུར་དགོས་འབྲེལ་གྱི་ངག་བཀོད་པའི་དགོས་པ་དང་། དགོས་འབྲེལ་གྱི་བསྡུས་པའི་དོན་ཏོ། །
དང་པོ་ལ་གསུམ་སྟེ། གཞན་ལུགས་དགག་པ་དང་། རང་ལུགས་བཞག་པ་དང་། དེ་ལ་རྩོད་པ་སྤང་བའོ། །
དང་པོ་ལ་བཞི་ལས།
Enumeration Block 3:
དེ་དགག་པ་ལ་གཉིས་ལས།
Enumeration Block 4:
གཉིས་པ་རང་ལུགས་བཞག་པ་ལ་གཉིས་ཏེ། དགོས་པ་དངོས་དང་། ཉིང་དགོས་སོ། །
དང་པོ་ལ་གཉིས་ལས།
Enumeration Block 5:
གསུམ་པ་རྩོད་པ་སྤང་བ་ལ་གསུམ་ལས་
Enumeration Block 6:
གཉིས་པ་ཡོངས་གཅོད་འཇུག་པའི་ཕྱོགས་ལ་མི་ནུས་མི་དགོས་ཀྱི་སྐྱོན་སྤོང་བ་ལ་གཉིས་ལས།
Enumeration Block 7:
གཉིས་པ་བསྡུས་པའི་དོན་ལ་བདུན་ལས་
Enumeration Block 8:
དགོས་འབྲེལ་བཞི་གསུམ་བཅུ་གཉིས་ཡོད་པ་ལས།
