Enumeration Block 1:
དེ་ལ་གཉིས་ཏེ། གཉེན་པོ་གོམས་པའི་སྒོ་ནས་བརྟན་པ་དང་། བརྟན་པ་རིམ་གྱིས་མི་སྤོང་བའི་སྒོ་ནས་བརྟན་པའོ། །
Enumeration Block 2:
གཉིས་པ་བསྡུས་པའི་དོན་ལ་གསུམ་ལས།
Enumeration Block 3:
གཉིས་པ་བསླབ་ཚིགས་སྔ་མ་མེད་པ་ལ་ཕྱི་མ་སྐྱེ་མི་སྐྱེའི་དོན་ལ་གཉིས་ལས།
Enumeration Block 4:
དེ་དག་དགག་པ་ལ་གཉིས་ལས།
Enumeration Block 5:
གསུམ་པ་གང་ཟག་གཅིག་ལ་སྡོམ་པ་གསུམ་ཇི་ལྟར་གནས་ཚུལ་ནི་གསུམ་ལས།
Enumeration Block 6:
དགེ་བསྙེན་ཉིད་དང་ཞེས་པ་འདི་ལ་གསུམ་ལས།
