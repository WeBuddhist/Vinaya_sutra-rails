Enumeration Block 1:
གཉིས་པ་རྟེན་གང་གིས་བླང་བ་ལ་བཞི་ལས།
Enumeration Block 2:
འདིའི་སྤྱིའི་དོན་ལ་གཉིས་ལས་།
Enumeration Block 3:
གཉིས་པ་བསྡུས་པའི་དོན་ལ་བརྒྱད་ལས།
Enumeration Block 4:
གསུམ་པ་མཚན་ཉིད་ལ་གཉིས་ཏེ། བླ་མ་ཙམ་གྱི་མཚན་ཉིད་དང་། སོ་སོའི་མཚན་ཉིད་དོ། །
Enumeration Block 5:
གཉིས་པ་ལ་གཉིས་ཏེ། བླ་མ་བྱར་རུང་བའི་མཚན་ཉིད་བླ་མ་ཡིན་པའི་མཚན་ཉིད་དོ། །
Enumeration Block 6:
བདུན་པ་བླ་མར་གྱུར་པའི་དུས་ནི་གཉིས་ལས།
Enumeration Block 7:
གསང་སྟེ་སྟོན་པའི་སློབ་དཔོན་དུ་གྱུར་པའི་དུས་ངོས་བཟུང་བ་འདི་ལ་གསུམ་ལས།
