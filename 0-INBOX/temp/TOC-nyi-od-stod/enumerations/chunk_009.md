Enumeration Block 1:
གཉིས་པ་གཞུང་གི་དོན་བྱེ་བྲག་ཏུ་བསྟན་པ་ལ་གཉིས། སྐབས་སྒྲུབ་པ་དང་། དངོས་ཀྱི་དོན་བསྟན་པའོ། །དང་པོ་ལ་གཉིས་ཏེ། གོ་རིམ་ངེས་པའི་རྒྱུ་མཚན་དང་། དེ་ལས་འཕྲོས་པ་འདུལ་བ་མདོར་བསྡུས་ཀྱི་སྤྱི་དོན་བསྟན་པའོ། །
དང་པོ་ལ་གཉིས་ཏེ། རྩོད་པ་དང་། ལན་གདབ་པའོ། །
Enumeration Block 2:
དེ་གཏན་ལ་འབེབས་པ་ལ་གཉིས་ལས།
Enumeration Block 3:
གཉིས་པ་བསྡུས་པའི་དོན་ལ་བརྒྱད་དེ། དབྱེ་བ་ངོ་བོ་མཚན་ཉིད་ངེས་ཚིག་དང་། གཞི་དང་རྒྱུ་མཚན་དང་ནི་སྦྱར་ཚུལ་དང་།
སྔར་བཅས་རྗེས་བཅས་གང་ཡིན་བརྟག་པ་སྟེ། །བརྒྱད་ཀྱིས་འདི་དོན་རྣམ་པར་བཤད་པར་བྱ། །
Enumeration Block 4:
རྒྱུ་མཚན་གྱི་སྒོ་ནས་ཕྱེ་ན་དགག་སྒྲུབ་གནང་གསུམ་ལས།
Enumeration Block 5:
ངོ་བོའི་སྒོ་ནས་ཕྱེ་ན་གཉིས་ལས།
Enumeration Block 6:
གནས་སྐབས་ཀྱི་སྒོ་ནས་ཕྱེ་ན་གཉིས་ཏེ། ངོ་བོ་ཉིད་ཀྱིས་འདུལ་བ་མདོར་བསྡུས་དང་བྱེད་པའི་འདུལ་བ་མདོར་བསྡུས་སོ། །
Enumeration Block 7:
དྲུག་པ་རྒྱུ་མཚན་གང་གིས་སྦྱར་བ་ལ་གསུམ་སྟེ། དགག་བྱའི་རྒྱུ་མཚན་དང་། དགོས་པའི་རྒྱུ་མཚན་དང། དགག་དགོས་མེད་པའི་རྒྱུ་མཚན་ནོ། །
དང་པོ་ལ་བཞི་ལས།
Enumeration Block 8:
དགག་བྱ་ལ་ཕྱེ་ན་གཉིས་ཏེ། སྤྱིའི་དགག་བྱ་དང་། སྒོས་ཀྱི་དགག་བྱའོ། །
