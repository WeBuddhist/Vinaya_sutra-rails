Enumeration Block 1:
གཉིས་པ་ཡོངས་གཅོད་འཇུག་པའི་ཕྱོགས་ལ་མི་ནུས་མི་དགོས་ཀྱི་སྐྱོན་སྤོང་བ་ལ་གཉིས་ལས།
Enumeration Block 2:
གཉིས་པ་བསྡུས་པའི་དོན་ལ་བདུན་ལས་དང་པོ་དགོས་འབྲེལ་གྱི་རབ་ཏུ་དབྱེ་བ་ནི།
དགོས་འབྲེལ་བཞི་གསུམ་བཅུ་གཉིས་ཡོད་པ་ལས།
Enumeration Block 3:
གཉིས་པ་གྲངས་ངེས་པའི་རྒྱུ་མཚན་ལ་གཉིས་ཏེ། གྲངས་ངེས་དངོས་དང་། ཞར་ལ་བྱུང་བའོ། །
དང་པོ་ལ་གསུམ་ལས།
Enumeration Block 4:
གཉིས་པ་ཞར་ལ་བྱུང་བ་ལ་གཉིས་ལས།
Enumeration Block 5:
དགོས་འབྲེལ་ཡན་ལག་བཞི་པོ་རེ་རེ་ལ་གཉིས་གཉིས་སུ་ཕྱེ་བས་བརྒྱད་ཡོད་པ་ལས།
བརྗོད་བྱ་ལ་གཉིས་ཏེ། དངོས་ཀྱི་བརྗོད་བྱ་དང་། ཞེན་པའི་བརྗོད་བྱའོ། །
