Enumeration Block 1:
དགེ་ཚུལ་ཉིད་དང་ཞེས་པ་འདི་ལ་གསུམ་ལས།
Enumeration Block 2:
དགེ་སློང་ཉིད་དག་གིས་ཞེས་པ་འདི་ལ་གསུམ་ལས།
Enumeration Block 3:
འདིའི་སྤྱི་དོན་ལ་གཉིས་ཏེ། སྐབས་དོན་དགེ་བསྙེན་གྱི་སྤྱི་དོན་དང་། ཐུན་མོང་བ་སྐྱབས་འགྲོའི་སྤྱི་དོན་ནོ། །
དང་པོ་ལ་གཉིས་ལས།
Enumeration Block 4:
གཉིས་པ་བསྡུས་པའི་དོན་ལ་བཞི་ལས།
Enumeration Block 5:
གཉིས་པ་ཐུན་མོང་བ་སྐྱབས་འགྲོའི་སྤྱི་དོན་ལ་གཉིས་ཏེ། དགོས་པའི་དོན་དང་། བསྡུས་པའི་དོན་ནོ། །
དང་པོ་ལ་གསུམ་སྟེ། དགོས་པ་ངོས་གཟུང་བ་དང་། རྩོད་པ་སྤང་བ་དང་། འཕྲོས་པའི་དོན་ནོ། །
Enumeration Block 6:
གཉིས་པ་རྩོད་པ་སྤང་བ་ལ་གཉིས་ལས།
