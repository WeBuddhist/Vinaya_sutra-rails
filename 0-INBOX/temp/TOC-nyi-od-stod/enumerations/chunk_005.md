Enumeration Block 1:
བྱེད་རྒྱུ་ལ་གཉིས་ལས་
Enumeration Block 2:
གཉིས་པ་བྱེད་རྒྱུ་བྱེད་པ་དང་བཅས་པ་འདི་ལ་གསུམ་ལས།
Enumeration Block 3:
འདི་ལ་གཉིས་ཏེ། {འདི་ལ་སྡོམ་པ་མ་སྐྱེས་པ།} སྐྱེད་པར་བྱེད་པ་གཞིའི་འབྱུང་བ་དང་། {སྡོམ་པ་སྐྱེས་ཟིན་པ།} གནས་པར་བྱེད་པ་རྟེན་༄༅། །གྱི་འབྱུང་བའོ། །
Enumeration Block 4:
གཉིས་པ་རིག་བྱེད་རྒྱུར་གྱུར་པ་ལ་གཉིས་ལས།
Enumeration Block 5:
གསུམ་པ་སེམས་པ་རྒྱུར་གྱུར་པ་ལ་གཉིས་ཏེ། རྒྱུའི་ཀུན་སློང་དང་། དུས་ཀྱི་ཀུན་སློང་ངོ་
