Enumeration Block 1:
གཉིས་པ་བསྔོས་པ་འཚོལ་བ་ལ་གཉིས་ལས།
བསྔོས་པའི་གོས་འཚོལ་བ་ལ་གཉིས་ལས།
སྤགས་པ་སློང་བ་ལ་གཉིས་ལས།
Enumeration Block 2:
གཉིས་པ་གོས་ཀྱི་རྒྱུ་འཚོལ་བ་ལ་གཉིས་ལས།
Enumeration Block 3:
གཉིས་པ་རུང་བ་དང་འགལ་བའི་ཉེས་པ་བསྟན་པ་ལ་གཉིས་ལས།
Enumeration Block 4:
ཡན་ལག་ལ་བཞི་ལས།
Enumeration Block 5:
གཉིས་པ་གདིང་བ་ལས་གྱུར་པ་ལ་གཉིས། གྲང་བ་སྐྱོབ་པ་དང༌། གནས་མལ་སྐྱོབ་པ་ལས་གྱུར་པའོ། །དང་པོ་ལ་གཉིས། འདོད་པ་ཆེ་བ་ལས་གྱུར་པ་དང༌། ཆོག་མི་ཤེས་པ་ལས་གྱུར་བའོ། །དང་པོ་ལ་གསུམ་ལས།
སྲིན་བལ་ལ་གཉིས་ལས་དང་པོ་རྣམ་འབྱེད་ཀྱི་སྐབས་ནས་འབྱུང་བ་ལ་གསུམ་ལས།
Enumeration Block 6:
གཉིས་པ་ཡན་ལག་གི་མཚན་ཉིད་ལ་གཉིས་ལས།
Enumeration Block 7:
ཡན་ལག་ལ་བཞི་ལས།
