Enumeration Block 1:
གསུམ་པ་བསྡུས་དོན་བཤད་པ་ལ། རྣམ་འབྱེད་ཀྱི་དཀྱུས་འདི་རྣམས་རྣམ་པ་གསུམ་གྱིས་ས་གཅོད་པར་མཛད་དེ། ལྟུང་བ་རྣམ་གཞག་དང༌། ལྟུང་བ་མེད་པ་དང༌། བསླབ་བྱའོ། །
Enumeration Block 2:
དེ་ལ་ཡན་ལག་གི་མཚན་ཉིད་དང༌། སེལ་བ་གཉིས།
Enumeration Block 3:
སེལ་བ་ལ་སེལ་བའི་ངོ་བོ་དང༌། དབྱེ་བ་དང༌། ཅིར་འགྱུར་བ་གསུམ་མོ། །
Enumeration Block 4:
ཅིར་འགྱུར་ལ་དངོས་དང༌། དེ་ལས་འཕྲོས་པ་སྦོམ་པོའི་དོན་གཏན་ལ་དབབ་པའོ། །

དང་པོ་ལ། ན་སྨད་དང༌། ཆེས་ན་སྨད་དང༌། ལྟུང་བ་མེད་པའོ། །
Enumeration Block 5:
མཚན་ཉིད་པ་ལ་ལྔ། དབྱེ་བ། བསྡུ་བ། ངོ་བོ། སྒྲ་དོན། མཁས་པ་དག་གི་ལུགས་དཔྱད་པའོ། །དང་པོ་ནི། མཚན་ཉིད་པ་ལ་བཞི་སྟེ། ཕམ་པར་གཏོགས་པའི་ལྕི་ཡང་གཉིས། ལྷག་མར་གཏོགས་པའི་ལྕི་ཡང་གཉིས་སོ། །
Enumeration Block 6:
ཕམ་པ་དང༌། ལྷག་མས་ཀུན་ནས་བསླང་བ་གཉིས་སུ་འདུའོ། །
Enumeration Block 7:
སྦོམ་པོ་མཚན་ཉིད་པ་གཉིས་ཁོ་ན་སྟེ། སྦྱོར་བ་དང་དངོས་གཞིའི་སྦོམ་པོའོ་ཞེས་ཟེར།
Enumeration Block 8:
སྦོམ་པོ་གསུམ་སྟེ། སྦྱོར་བའི་སྦོམ་པོ་དང༌། སྦྱོར་བའི་རྣམ་པའི་སྦོམ་པོ་དང༌། དངོས་གཞིའི་རྣམ་པའི་སྦོམ་པོའོ། །
Enumeration Block 9:
སྦྱོར་བ་མཚན་ཉིད་པ་བཞི་ཡིན་ཏེ། སྦྱོར་བ་སོགས་གསུམ་དང༌། དངོས་གཞིའི་སྦོམ་པོའོ། །
Enumeration Block 10:
སྦྱོར་བ་མཚན་ཉིད་པ་ལ་སྦྱོར་བའི་སྦོམ་པོ་དང་དངོས་གཞིའི་སྦོམ་པོ་གཉིས་ཡོད་ལ།
Enumeration Block 11:
དབྱེ་ན། ཕམ་ལྷག་བསྐྱེད་པ་མཐར་ཐུག་འབྲེལ་བ་དང༌། མི་བསྐྱེད་པ་མ་འབྲེལ་བ་གཉིས་སོ། །
Enumeration Block 12:
བཏགས་པ་བ་ཡང་གཉིས་ཡིན་ལ།
