Enumeration Block 1:
བཅུ་པ་བརྒྱད་པ་ལ་ལྔ། ལམ་གྱི་གཞི་ལས་གྱུར་པ་དང༌། ཆོ་གའི་དང༌། འཕྲལ་གྱི་བྱ་བའི་དང༌། འཁྲུལ་བ་བསྐྱེད་པའི་དང༌། བརྒྱུ་བ་དུས་མིན་པའི་འོ། །
Enumeration Block 2:
ཡན་ལག་ལ་བཞི་ལས།
Enumeration Block 3:
གཞུང་དོན་ལ་གསུམ། ཡན་ལག་གི་མཚན་ཉིད། བསླབ་བྱ། ཞར་ལ་སྡོམ་པ་སྐྱེ་འཇིག་གི་དུས་བསྟན་པའོ། །
Enumeration Block 4:
གསུམ་པ་འཕྲལ་གྱི་བྱ་བའི་གཞི་ལས་གྱུར་པ་ལ་ལྔ། བྱ་བ་ངན་པས་བརྐོ་བ་ལས་གྱུར་པ་དང༌། ཟས་ཀྱི་བྱ་བ་ཚུལ་མིན་པ་ལས་དང༌། རང་གི་བྱ་བ་ལ་སྦྱོར་བ་སྤོང་བ་ལས་དང༌། གཞན་གྱི་བྱ་བ་ལ་གནོད་པ་ལས་དང༌། སངས་༄༅། །རྒྱས་དང་དགེ་འདུན་གྱི་བྱ་བ་ལ་མ་གུས་པ་ལས་སོ། །
Enumeration Block 5:
ཡན་ལག་ལ་བཞི་ལས།
Enumeration Block 6:
གཞུང་དོན་ལ་གཉིས། རྣམ་གཞག །ལྟུང་མེད་དོ། །དང་པོ་ལ་གཉིས། ཡན་ལག་གི་མཚན་ཉིད་དང༌། སེལ་བའོ། །དང་པོ་ལ་གསུམ་ལས།
Enumeration Block 7:
གཉིས་པ་ཟས་ཀྱི་བྱ་བ་ཚུལ་མིན་པར་གྱུར་པ་ལ་བཞི། བསླབ་བྱ། རྣམ་གཞག །ལྟུང་མེད། སྡོམ་རྒྱུན་ཐ་དད་ལ་ལྟུང་བ་ཐ་དད་པར་བསྟན་པའོ། །
Enumeration Block 8:
ཡན་ལག་ལ་བཞི་ལས།
Enumeration Block 9:
གཞུང་དོན་ལ་གཉིས་ལས།
