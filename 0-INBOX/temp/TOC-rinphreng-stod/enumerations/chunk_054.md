Enumeration Block 2:
གཉིས་པ་རྣམ་གཞག་ལ་གཉིས་ལས།
Enumeration Block 3:
ཡན་ལག་ལ་གསུམ་ལས།
Enumeration Block 4:
གཞུང་དོན་ལ་གཉིས་ལས།
Enumeration Block 5:
གཉིས་པ་བཤགས་པ་ཙམ་དང་འབྲེལ་བ་ལྟུང་བྱེད་འབའ་ཞིག་པ་ལ།

བཅུ་ཚན་དགུ་ལས། དང་པོ་ལ་གསུམ། གནོད་པ་ལས་གྱུར་པ་དང༌། འདོད་པ་ལས་དང༌། གནོད་པ་ལས་གྱུར་པ་གཞན་བསྟན་པའོ། །དང་པོ་ལ་གསུམ། དོན་འགྲུབ་པ་ལ་དང༌། ཡིད་བདེ་བ་དང༌། བློ་མཐུན་པ་ལ་གནོད་པའོ། །དང་པོ་ལ་གསུམ་ལས།
Enumeration Block 6:
རྫུན་སྨྲ་བ་ལ་ཕམ་པ་དང༌། ལྷག་མ་དང༌། སྦོམ་པོ་དང༌། ལྟུང་བྱེད་དང༌།

ཉེས་བྱས་སུ་འགྱུར་བ་ལྔ་ལས།
Enumeration Block 7:
གཉིས་པ་ཤེས་བཞིན་གྱི་རྫུན་དངོས་ལ་གཉིས་ལས།
Enumeration Block 8:
ཡན་ལག་ལ་བཞི་ལས།
Enumeration Block 9:
གཉིས་པ་ཡིད་བདེ་བ་ལ་གནོད་པ་ལ་གཉིས་ལས།
Enumeration Block 10:
གསུམ་པ་བློ་མཐུན་པ་ལ་གནོད་པ་ལ་གཉིས། མཛའ་བ་འབྱེད་པ་དང་མི་མཛའ་བ་འབྱེད་པའོ། །དང་པོ་ལ་གཉིས། ཡན་ལག་གི་མཚན་ཉིད་དང༌། སེལ་བའོ། །
Enumeration Block 11:
གཉིས་པ་མི་མཛའ་བ་འབྱེད་པ་ལ་གཉིས་ལས།
Enumeration Block 12:
