Enumeration Block 1:
གཉིས་པ་གཞུང་དོན་ལ་གཉིས་ལས།
Enumeration Block 2:
ཁུ་བ་ནི་ལྔ་སྟེ། སྔོན་པོ་དང༌། སེར་པོ་དང༌། དམར་པོ་དང༌། བསྐ་བ་དང༌། སླ་བའོ། །
Enumeration Block 3:
ཁུ་བ་འབྱུང་བ་དུ་མ་ཡོད་དེ། གནས་ནས་འབྱུང་བ་དང༌། སྦུབས་སུ་འོངས་པ་ལས་འབྱུང་བ་དང༌། དབང་པོའི་མཐའ་ནས་འབྱུང་བའོ། །
Enumeration Block 4:
གཉིས་པ་རྒྱས་བཤད་ལ་གཉིས། ཡན་ལག་གི་མཚན་ཉིད་དང༌། སེལ་བའོ། །
Enumeration Block 5:
གཉིས་པ་ལ་གསུམ་ལས།
Enumeration Block 6:
གསུམ་པ་འདུལ་བྱེད་ཀྱི་སྐབས་ནས་འབྱུང་བ་ལ་གཉིས། ཡན་ལག་གི་མཚན་ཉིད་དང༌། སེལ་བའོ། །
Enumeration Block 7:
གཉིས་པ་སེལ་བ་ལ་གསུམ་ལས།
Enumeration Block 8:
གཉིས་པ་གཞན་གྱི་ལུས་ཀྱི་རེག་བྱའི་བདེ་བ་ལ་ཆགས་པ་ལ་གསུམ་ལས།
རྣམ་འབྱེད་ཀྱི་སྐབས་ནས་འབྱུང་བ་ལ་གཉིས་ལས།
ཐུན་མོང་གི་མཚན་ཉིད་དང༌། ཐུན་མོང་མིན་པའོ། །
དང་པོ་ལ་གསུམ། བུད་མེད་བྱེད་པ་པོར་བསྟན་པ། དེ་དག་གི་མཚན་ཉིད། ལྷག་མ་དང་པོ་གསུམ་གྱི་ཐུན་མོང་གི་མཚན་ཉིད་དོ། །དང་པོ་ལ་གཉིས་ལས།
