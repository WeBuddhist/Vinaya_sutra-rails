Enumeration Block 1:
བཞི་པ་བཟློག་པའི་ཕམ་པ་ལ་གཉིས། ཡན་ལག་གི་ཁྱད་པར་དང་། ཐུན་མོང་གི་ཡན་ལག་དབྱེན་དང་འདྲ་བར་བསྟན་པའོ། །
Enumeration Block 2:
གཉིས་པ་དགེ་འདུན་ལྷག་མའི་སྡེ་ལ་གཉིས། དང་པོས་གྱུར་པ་དང་། བསྒོ་བ་ལས་གྱུར་པའོ། །དང་པོ་ལ་གཉིས། ཐུན་མོང་བ་མིང་ཙམ་དང་། སོ་སོའི་མཚན་ཉིད་དོ། །དང་པོ་ལ་གཉིས་ལས།
སྨྱན་བྱེད་པ་ལ་གཉིས་ལས།
Enumeration Block 3:
གཉིས་པ་གཞི་མེད་བག་ཙམ་ལ་གཉིས། མིང་ཙམ་དངོས་དང་། ཡུལ་གྱི་བྱེ་བྲག་གོ །
Enumeration Block 4:
གཉིས་པ་སོ་སོའི་མཚན་ཉིད་ལ་ལྔ། གླ་ལེན་པ་དང་། གཅིག་པུ་རྒྱུ་བ་དང་། རབ་ཏུ་འབྱིན་པ་དང་། ཤི་༄༅། །བའི་ནོར་ལེན་པ་དང་། བཟོད་པ་གསོལ་དུ་འཇུག་པའོ། །དང་པོ་ལ་གཉིས་ལས།
ལེན་པ་ལ་གཉིས། ཡན་ལག་གི་མཚན་ཉིད་དང་། སེལ་བའོ། །
Enumeration Block 5:
གཉིས་པ་གཅིག་པུ་རྒྱུ་བ་ལ་གཉིས། ཐུན་མོང་བ་དང་། སོ་སོའི་མཚན་ཉིད་དོ། །དང་པོ་ལ་གཉིས། ཁྲིམས་གྲོགས་ཀྱི་མཚན་ཉིད་དམིགས་བསལ་དང་བཅས་པ། དུས་དང་འབྲེལ་བའི་མཚན་ཉིད་དོ། །
Enumeration Block 6:
གཉིས་པ་ལ་བཞི་ལས།
Enumeration Block 7:
གཉིས་པ་ཉིན་མོ་འབྲལ་བ་ལ་གཉིས་ལས།
Enumeration Block 8:
གཉིས་པ་ཆུ་བརྒལ་བ་ལ་གཉིས་ལས།
Enumeration Block 9:
བཞི་པ་ཤི་བའི་ནོར་ལེན་པ་ལ་གཉིས་ལས།
Enumeration Block 10:
གཉིས་པ་བསྒོ་བ་ལས་གྱུར་པ་ལ་གཉིས། ཐུན་མོང་མིན་པ་དང་། ཐུན་མོང་པའོ། །དང་པོ་ལ་བཞི་ལས།
