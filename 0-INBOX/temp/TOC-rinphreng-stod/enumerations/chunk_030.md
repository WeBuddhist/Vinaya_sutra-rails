Enumeration Block 1:
གསུམ་པ་གཞན་གྱི་སྲོག་ལ་གནོད་པ་སྲོག་གཅད་པའི་ཕམ་པ་ལ་བཞི་ལས།
རྣམ་འབྱེད་ཀྱི་སྐབས་ནས་འབྱུང་བ་ལ་གསུམ། བྱུང་བ་དང་འབྲེལ་བའི་བསླབ་བྱ། ལྟུང་བ་རྣམ་གཞག །བཅས་པ་དང་འབྲེལ་བའི་བསླབ་བྱའོ། །དང་པོ་ལ་བཞི་ལས
Enumeration Block 2:
གཉིས་པ་ལྟུང་བ་རྣམ་གཞག་ལ་གཉིས། སྤྱི་དོན་དང༌། གཞུང་དོན་ནོ། །
Enumeration Block 3:
ཡན་ལག་ལ་བཞི་ལས།
Enumeration Block 4:
གཞུང་དོན་ལ་གཉིས་ལས
Enumeration Block 5:
གཉིས་པ་རྒྱས་བཤད་ལ་གཉིས། ཡན་ལག་གི་མཚན་ཉིད་དང་སེལ་བ་རྒྱས་པར་བཤད་པའོ། །དང་པོ་ལ་གསུམ། སྦྱོར་བའི་རབ་དབྱེ། གཞིའི་རབ་དབྱེ། མཐར་ཐུག་ལ་དོགས་པ་བཅད་པའོ། །
Enumeration Block 6:
འདི་ལ་རྩོད་པ་སྤང་བ་ལ་གསུམ་ལས།
Enumeration Block 7:
གཉིས་པ་སེལ་བ་རྒྱས་བཤད་ལ་གསུམ་ལས།
Enumeration Block 8:
དང་དུ་ལེན་པ་གཉིས་ཏེ། སྣང་བ་གསོལ་བ་ལ་དང༌།
རང་ཉིད་བྱེད་པ་སྨྲ་བ་ལ་དང་དུ་ལེན་པ་ལས།
Enumeration Block 9:
གསུམ་པ་བཅས་པ་དང་འབྲེལ་བའི་བསླབ་བྱ་ལ་བཞི་ལས།
