Enumeration Block 1:
སྦོམ་པོ་མཚན་ཉིད་པ་གཉིས་ཁོ་ན་སྟེ། སྦྱོར་བ་དང་དངོས་གཞིའི་སྦོམ་པོའོ།
Enumeration Block 2:
སྦོམ་པོ་གསུམ་སྟེ། སྦྱོར་བའི་སྦོམ་པོ་དང༌། སྦྱོར་བའི་རྣམ་པའི་སྦོམ་པོ་དང༌། དངོས་གཞིའི་རྣམ་པའི་སྦོམ་པོའོ། །
Enumeration Block 3:
སྦྱོར་བ་མཚན་ཉིད་པ་བཞི་ཡིན་ཏེ། སྦྱོར་བ་སོགས་གསུམ་དང༌། དངོས་གཞིའི་སྦོམ་པོའོ། །
Enumeration Block 4:
སྦྱོར་བ་མཚན་ཉིད་པ་ལ་སྦྱོར་བའི་སྦོམ་པོ་དང་དངོས་གཞིའི་སྦོམ་པོ་གཉིས་ཡོད་ལ།
Enumeration Block 5:
དབྱེ་ན། ཕམ་ལྷག་བསྐྱེད་པ་མཐར་ཐུག་འབྲེལ་བ་དང༌། མི་བསྐྱེད་པ་མ་འབྲེལ་བ་གཉིས་སོ། །
Enumeration Block 6:
བཏགས་པ་བ་ཡང་གཉིས་ཡིན་ལ།
Enumeration Block 7:
སྦོམ་པོ་མཚན་ཉིད་པ་གཉིས་ཏེ། སྦྱོར་བའི་སྦོམ་པོ་དང་སྦྱོར་བའི་རྣམ་པའི་སྦོམ་པོའོ། །
Enumeration Block 8:
གཉིས་པ་ལྟུང་བ་མེད་པ་ནི་རྣམ་པ་བཞི་སྟེ། དངོས་གཞིའི་ལྟུང་མེད་དང༌། སྐབས་དེར་གཏོགས་ཀྱི་ལྟུང་མེད་དང༌། ལྟུང་བ་རྣམ་གཞག་གི་ལྟུང་མེད་དང༌། ལྟུང་བ་གཏན་ནས་མེད་པའོ། །
Enumeration Block 9:
བཞི་པ་ལ་གཉིས། བཅས་རང་གཉིས་ཀའི་ལྟུང་མེད་དང་བཅས་པའི་ལྟུང་མེད་དོ། །
Enumeration Block 10:
གཉིས་པ་ལ་བཞི། དགག་བྱ་མེད་པ། བག་ཡངས་དང་འབྲེལ་བ། བསྒྲུབ་པར་མ་ནུས་པ། རྐྱེན་དགོས་དང་ལྡན་པའོ། །
Enumeration Block 11:
བཞི་པ་ལ་གཉིས། རང་གི་རྐྱེན་དགོས་དང་ལྡན་པ་དང་གཞན་གྱི་རྐྱེན་དགོས་དང་ལྡན་པའོ། །དང་པོ་ལ་གཉིས། རྐྱེན་དགོས་གཙོ་བོ་དང་ལྡན་པ་དང༌། གཙོ་བོ་མིན་པ་དང་ལྡན་པའོ། །དང་པོ་ལ་གསུམ། ཚུལ་ཁྲིམས་དང༌། དགེ་སྦྱོང་གི་ཚུལ་དང༌། སྲོག་གི་བར་ཆད་དང་ལྡན་པའོ། །
Enumeration Block 12:
གཙོ་བོ་མིན་པ་དང་འདོམས་པའང་གསུམ་སྟེ། ལུས་དང་བསོད་ནམས་དང་ལོངས་སྤྱོད་ཀྱི་བར་ཆད་དང་འདོམས་པའོ། །
Enumeration Block 13:
གཞན་གྱི་ལ་ཡང་གཉིས་ལས།
Enumeration Block 14:
མཐུན་པ་གསུམ་ནི། དགག་བྱ་ཉེས་དམིགས་དང༌། རྒྱུད་པ་རྒྱུར་འགྲོ་དང༌། སྦྱོར་བ་རྗེས་སུ་མཐུན་པའོ། །
Enumeration Block 15:
གཉིས་པ་གཞུང་དོན་ལ་ལྔ། གཅོད་པར་བྱེད་པ་ཕམ་པའི་སྡེ། གསོ་བ་དགེ་འདུན་ལ་རག་ལས་པ་དགེ་འདུན་ལྷག་མའི་སྡེ། ལྟུང་བར་བྱེད་པ་ལྟུང་བྱེད་ཀྱི་སྡེ། སྨྲེ་སྔགས་འདོན་པའི་སྒོ་ནས་སོ་སོར་བཤགས་པའི་སྡེ། བསླབ་བྱ་ཉེས་བྱས་ཀྱི་སྡེའོ། །དང་པོ་ལ་བཞི། རང་གཞན་གཉིས་ཀའི་ཚངས་སྤྱོད་ལ་གནོད་པ་མི་ཚངས་པར་སྤྱོད་པའི་ཕམ་པ། གཞན་གྱི་ལོངས་སྤྱོད་ལ་གནོད་པ་མ་བྱིན་ལེན་གྱི་ཕམ་པ། གཞན་གྱི་སྲོག་ལ་གནོད་པ་སྲོག་གཅོད་པའི་ཕམ་པ། གཞན་གྱི་དོན་འགྲུབ་པ་ལ་གནོད་པ་རྫུན་དུ་སྨྲ་བའི་ཕམ་པའོ། །དང་པོ་ལ་ལུང་གི་བྱེ་བྲག་བཞི་ལས།
Enumeration Block 16:

Enumeration Block 17:
གླེང་གཞི་ནི། ཡུལ་དང་གང་ཟག་དང་ཉོན་མོངས་པ་དང༌། ཉེས་པའི་གཞིའི་བྱེ་བྲག་གིས་རྣམ་པ་བཞིའོ། །
Enumeration Block 18:
དོན་གསུམ་སྟེ། བསླབ་པ་འཆའ་བའི་སྙད་ཁ་གླེང་གཞི་དང༌། བཅས་པ་འཇོག་པའི་རྒྱུ་མཚན་དགག་བྱ་ཉེས་དམིགས་དང༌། ལྟུང་བའི་རྒྱུ་ཚོགས་ཡན་ལག་གི་བརྩི་བ་རྣམ་པར་བཞག་པའོ། །
