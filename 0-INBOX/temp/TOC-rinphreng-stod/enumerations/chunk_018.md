Enumeration Block 1:
གསུམ་པ་བར་ཆད་ཀྱི་མཚོན་དོན་ལ་གསུམ་ལས།
Enumeration Block 2:
བཞི་པ་བར་ཆད་ཀྱི་མཚན་ཉིད་ལ་གཉིས་ལས།
Enumeration Block 3:
ལྔ་པ་སྐྱེ་བ་དང་མི་སྐྱེ་བ་དོགས་གཅོད་དང་བཅས་པ་ལ་བཞི་ལས།
Enumeration Block 4:
གཉིས་པ་དེས་བསླབ་པར་བྱ་བའི་མཚན་ཉིད་ལ་གཉིས། སྤང་བའི་བསླབ་བྱ་དང༌། ཉམས་སུ་བླང་བའི་བསླབ་བྱའོ། །དང་པོ་ལ་གཉིས། སྡེ་ལྔ་སོ་སོའི་མཚན་ཉིད་དང༌། ཞུ་བ་སྤྱིར་བསྟན་པའོ། །དང་པོ་ལ་གཉིས། དགེ་སློང་གི་སྡེ་ལྔ་སྤྱིར་བཤད་པ། དགེ་སློང་མའི་སྡེ་ལྔ་བྱེ་བྲག་ཏུ་བཤད་པའོ། །དང་པོ་ལ་གཉིས། ཐུན་མོང་བ་བསླབ་པ་འབུལ་བའི་ཆོ་ག་དང༌། སྡེ་ལྔ་བཤད་པ་དངོས་སོ། །དང་པོ་ལ། སྤྱི་དོན་དང༌། གཞུང་དོན་གཉིས་སོ། །
Enumeration Block 5:
གཞུང་དོན་ལ་གཉིས་ལས།
