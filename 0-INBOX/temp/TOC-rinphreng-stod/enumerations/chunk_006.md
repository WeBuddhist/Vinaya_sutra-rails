Enumeration Block 1:
གཉིས་པ་གནས་དང་གནས་པའི་མཚན་ཉིད་ལ་གཉིས། བཅས་པའི་སྐབས། རྗེས་བཅས་ཀྱི་སྐབས་སོ། །དང་པོ་ལ་གཉིས། བཙུན་པ་བརྟན་པའི་ཡན་ལག །མཁས་ཤིང་ཕན་འདོགས་ཀྱི་ཡན་ལག་གོ །
Enumeration Block 2:
གཉིས་པ་མཁས་ཤིང་ཕན་འདོགས་ཀྱི་ཡན་ལག་ལ་གཉིས། མདོར་བསྟན། རྒྱས་བཤད་དོ། །
Enumeration Block 3:
གཉིས་པ་ལ་བཞི། སྡེ་སྣོད་གཉིས་ཤེས་པའི་ཡོན་ཏན། སྡེ་སྣོད་གསུམ་ཤེས་པའི། དགེ་སྦྱོང་གི་ཚུལ་གྱི། འདུལ་བའི་སྡེ་སྣོད་ཤེས་པའི་ཡོན་ཏན་ནོ། །
Enumeration Block 4:
གཉིས་པ་ལ་གཉིས། ཡན་ལག་ཐུན་མོང་བ། ཐུན་མོང་མ་ཡིན་པའོ། །
Enumeration Block 5:
གཉིས་པ་ལ་གཉིས། ཚིག་དོན་གཉིས་ཀ་ཤེས་པའི་ཡོན་ཏན། དོན་ཤེས་པའི་ཡོན་ཏན་ནོ། །དང་པོ་ལ་གཉིས། རང་འཛིན་པའི་ཡོན་ཏན། གཞན་འཛིན་དུ་འཇུག་པའི་ཡོན་ཏན་ནོ། །
Enumeration Block 6:
གཉིས་པ་དོན་ཤེས་པའི་ཡོན་ཏན་ལ་བཞི། བསླབ་པ་གསུམ་ཤེས་པའི་ཡོན་ཏན། ཚུལ་ཁྲིམས་ཤེས་པའི་ཡོན་ཏན། ཕུན་སུམ་ཚོགས་གཉིས་ཀྱི་ཡོན་ཏན། ཚོགས་སྦྱོར་གཉིས་ཀྱི་ཡོན་ཏན་ནོ། །དང་པོ་ལ་གཉིས། རང་སློབ་པའི་ཡོན་ཏན། གཞན་སློབ་ཏུ་འཇུག་པའི་ཡོན་ཏན་ནོ། །
Enumeration Block 7:
གསུམ་པ་ཕུན་སུམ་ཚོགས་གཉིས་ཀྱི་ཡོན་ཏན་ལ་གཉིས་ལས།
Enumeration Block 8:
བཞི་པ་ལ་གཉིས། ཡན་ལག་ཐུན་མོང་བ། ཐུན་མོང་མ་ཡིན་པའོ། །
Enumeration Block 9:
གཉིས་པ་ལ་གསུམ། ཚོགས་ལམ་པའི་ཡོན་ཏན། བསྲིངས་པ་གཉིས་ལྡན་གྱི་ཡོན་ཏན། སྐྱོན་དང་བྲལ་བའི་ཡོན་ཏན་ནོ། །
Enumeration Block 10:
གསུམ་པ་དགེ་སྦྱོང་ཚུལ་གྱི་ཡོན་ཏན་ལ་གཉིས། སློབ་པའི་ཡོན་ཏན། མི་སློབ་པའི་ཡོན་ཏན་ནོ། །
Enumeration Block 11:
བཞི་པ་འདུལ་བའི་སྡེ་སྣོད་ཤེས་པའི་ཡོན་ཏན་ལ་གསུམ། དོན་ཤེས་པའི་ཡོན་ཏན། འཁོར་ལ་མ་ཆགས་པའི་ཡོན་ཏན། ཚིག་དོན་གཉིས་ཀ་ཤེས་པའི་ཡོན་ཏན་ནོ། །
Enumeration Block 12:
བྱུང་བ་མངོན་པར་ཤེས་པ་ལ་གཉིས་ཏེ། བྱུང་ལ་མ་བཅས་པའི་བྱུང་བ་ཤེས་པ་དང༌། བྱུང་ལ་བཅས་པའི་བྱུང་བ་ཤེས་པའོ། །
Enumeration Block 13:
གཉིས་པ་ལ། བཅས་པའི་བྱུང་བ་ཤེས་པ་དང༌། རྗེས་སུ་བཅས་པའི་བྱུང་བ་ཤེས་པ་གཉིས་སོ། །
Enumeration Block 14:
རྗེས་བཅས་ལ་དགུ་སྟེ་སྒྲུབ་པའི་རྗེས་སུ་སྒྲུབ་པ་དང་གནང་བ་དང་དགག་པ་བཅས་པ་དང༌། གནང་བའི་རྗེས་སུ་གནང་བ་དང་སྒྲུབ་པ་དང་དགག་པ་བཅས་པ་དང༌། དགག་པའི་རྗེས་སུ་དགག་པ་དང་སྒྲུབ་པ་དང་གནང་བ་བཅས་པའོ། །
