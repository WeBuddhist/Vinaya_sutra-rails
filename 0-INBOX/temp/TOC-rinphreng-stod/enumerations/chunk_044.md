Enumeration Block 1:
གཉིས་པ་ཟླ་བས་སྤང་བ་ལ་གཉིས་ལས། རྣམ་འབྱེད་ཀྱི་སྐབས་ནས་འབྱུང་བ་ལ་གཉིས། ལྟུང་བ་རྣམ་གཞག་དང༌། བསླབ་བྱའོ། །དང་པོ་ལ་གསུམ་ལས།
Enumeration Block 2:
གཉིས་པ་ཡན་ལག་གི་མཚན་ཉིད་ལ་གཉིས་ལས།
Enumeration Block 3:

Enumeration Block 4:

Enumeration Block 5:
རིགས་བཟློག་པ་དང་ཤན་འབྱུང་བ་ལ་མུ་བཞི་སྟེ།
Enumeration Block 6:
གཉིས་པ་བཟོ་རྗེས་སུ་བསྒྲུབ་པའི་ཐབས་ལ་གསུམ་ལས།
