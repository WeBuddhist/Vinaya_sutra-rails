Enumeration Block 1:
གསུམ་པ་ཤན་དང་འབྲེལ་བའི་ཐུན་མོང་བ་ལ་གཉིས་ལས། ཤན་གྱི་མཐའ་དཔྱད་པ་ལ་ལྔ། དབྱེ་བ། བསྡུ་བ། ངོ་བོ་རྣམ་གྲངས་དང་བཅས་པ། སྒྲ་དོན། ཤན་འདྲེས་པར་འགྱུར་བའི་རྣམ་གཞག་གོ ། དང་པོ་ཤན་ལ་དབྱེ་ན་བཞི། གོས་ཀྱི། ལྷུང་བཟེད་ཀྱི། སྨན་གྱི། ལྟུང་བའི་ཤན་ནོ། །དང་པོ་ལ། བཅུ་པ་དང༌། ཟླ་བ་བར་གཏོགས་པའི་ཤན་གཉིས་སོ། །
Enumeration Block 2:
གསུམ་པ་ལ་གཉིས། རྫས་ཀྱི་ཤན་གྱི་ངོ་བོ་རྣམ་གྲངས་དང་བཅས་པ་དང༌། ལྟུང་བའི་ཤན་གྱིའོ། །
Enumeration Block 3:
ལྔ་པ་ལ་བཞི། ཤན་འདྲེས་པའི་ངོ་བོ། ཤན་འདྲེ་བའི་དུས། ཤན་འདྲེ་བར་བཅས་པའི་དགོས་པ། ཤན་བརྡེག་བྱ་རྡེག་བྱེད་གཏན་ལ་དབབ་པའོ། །
Enumeration Block 4:
གཉིས་པ་ལ་གསུམ། དངོས་དང་ལྟུང་བ་བསྐྱེད་པའི་དུས། དེ་ལ་དོགས་པ་བཅད་པའོ། །
Enumeration Block 5:
བཞི་པ་བརྡེག་བྱ་རྡེག་བྱེད་གཏན་ལ་དབབ་པ་ལ་གཉིས། རྫས་ཀྱི་དང༌། ལྟུང་བའི་ཤན་གྱིའོ། །དང་པོ་ལ་གསུམ། ངོ་བོ། སྒྲ་དོན། གང་གིས་གང་ལ་བརྡེག་པའོ། །
Enumeration Block 6:
གཉིས་པ་ཐུན་མོང་མ་ཡིན་པ་སོ་སོའི་མཚན་ཉིད་ལ་ལྔ། གོས་ལས་གྱུར་པ། ནོར་ལས།
