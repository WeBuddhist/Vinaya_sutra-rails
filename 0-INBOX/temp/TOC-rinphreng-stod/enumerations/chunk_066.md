Enumeration Block 1:
བཞི་པ་ཆོ་ག་ལས་འདས་པ་ལ་གཉིས། གསོག་འཇོག་གི་དང༌། བྱིན་ལེན་གྱིའོ། །དང་པོ་ལ་བཞི། རྣམ་གཞག །ཞར་ལ་བཙོག་པ་ཟ་བའི་ཉེས་པ་བསྟན་པ། བྱེ་བྲག་ལག་ཉའམ་དམིགས་བསལ། བསླབ་བྱའོ། །དང་པོ་ལ་གཉིས་ལས།
Enumeration Block 2:
ཡན་ལག་ལ་བཞི་ལས།
Enumeration Block 3:
གཞུང་དོན་ལ་གསུམ། ཡན་ལག་གི་མཚན་ཉིད་༄༅། །བྱིན་གྱིས་བརླབས་པའི་དགོས་པ་ལ་དོགས་པ་བཅད་པ། སེལ་བའོ། །དང་པོ་ལ་གཉིས་ལས།
Enumeration Block 4:
རྒྱས་པར་བཤད་པ་ལ་བཞི། བཙོས་པའི་མཚན་ཉིད། ཞག་ལོན་གྱི་མཚན་ཉིད། བཙོས་པ་ལ་དོགས་པ་བཅད་པ། གནས་དང་ཉེ་འཁོར་གྱི་མཚན་ཉིད་དོ། །
Enumeration Block 5:
གནས་ནི་གཉིས་ཏེ། སྟེང་གཡོགས་པ་དང་མ་གཡོགས་པའོ། །
Enumeration Block 6:
གསུམ་པ་སེལ་བ་ལ་གཉིས། ཚད་ཀྱི་དང༌། ངོ་བོ་ཉིད་ཀྱི་སེལ་བ་བསླབ་བྱ་དང་བཅས་པའོ། །
Enumeration Block 7:
གཉིས་པ་ངོ་བོ་ཉིད་ཀྱི་སེལ་བ་ལ་ངག་དོན་གཉིས་ཏེ། ལྷན་ཅིག་སྐྱེས་པ་དང༌། ཉེ་བར་བསྒྲུབས་པའོ། །
