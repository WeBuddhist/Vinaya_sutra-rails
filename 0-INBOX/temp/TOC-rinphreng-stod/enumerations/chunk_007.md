Enumeration Block 1:
གཉིས་པ་ལ། བཅས་པའི་བྱུང་བ་ཤེས་པ་དང༌། རྗེས་སུ་བཅས་པའི་བྱུང་བ་ཤེས་པ་གཉིས་སོ། །
Enumeration Block 2:
རྗེས་བཅས་ལ་དགུ་སྟེ་སྒྲུབ་པའི་རྗེས་སུ་སྒྲུབ་པ་དང་གནང་བ་དང་དགག་པ་བཅས་པ་དང༌། གནང་བའི་རྗེས་སུ་གནང་བ་དང་སྒྲུབ་པ་དང་དགག་པ་བཅས་པ་དང༌། དགག་པའི་རྗེས་སུ་དགག་པ་དང་སྒྲུབ་པ་དང་གནང་བ་བཅས་པའོ། །
Enumeration Block 3:
གཉིས་པ་ལ་གཉིས། ཡན་ལག་ཐུན་མོང་བ། ཐུན་མོང་མ་ཡིན་པའོ། །
Enumeration Block 4:
གསུམ་པ་འགལ་རྐྱེན་བར་ཆད་ཀྱི་མཚན་ཉིད་ལ་གཉིས། སྤྱི་དོན་དང། ཚིག་དོན་ནོ། །
Enumeration Block 5:
བར་ཆད་ལ་དབྱེ་ན་བཞི་སྟེ། སྡོམ་པ་སྐྱེ་བ་ལ་བར་དུ་གཅོད་པ་དང༌། སྡོམ་པ་གནས་པ་ལ་བར་དུ་གཅོད་པ་ཕ་མས་མ་གནང་བ་ལྟ་བུ་དང༌། སྡོམ་པ་ཁྱད་པར་དུ་འགྲོ་བ་ལ་བར་དུ་གཅོད་པ་ནད་པ་ལྟ་བུ་དང༌། སྡོམ་ལྡན་མཛེས་པ་ལ་བར་དུ་གཅོད་པ་ལག་རྡུམ་ལ་སོགས་པ་ལྟ་བུའོ། །
Enumeration Block 6:
དང་པོ་ལ་བཞི་སྟེ། ལུས་ཀྱི་རྟེན་མིན་པས་སྡོམ་པ་མི་སྐྱེ་བ་དུད་འགྲོ་དང་སྒྲ་མི་སྙན་པ་ལ་སོགས་པ་ལྟ་བུ་དང༌། ལས་སྒྲིབ་ཀྱི་དབང་གིས་སྡོམ་པ་མི་སྐྱེ་བ་མཚམས་མེད་བྱས་པ་ལྟ་བུ་དང༌། གནས་སྐབས་ཀྱི་དབང་གིས་སྡོམ་པ་མི་སྐྱེ་བ་ཁྱིམ་པའི་ཆ་ལུགས་ཅན་ལྟ་བུ་དང༌། བསམ་པའི་དབང་གིས་སྡོམ་པ་མི་སྐྱེ་བ་ལེན་སེམས་ལོག་པ་ལྟ་བུའོ། །
Enumeration Block 7:
གཉིས་པ་ཚིག་དོན་ལ་བཞི། བསམ་པ་དང་ལུས་རྟེན་རུང་མ་ཐོབ་པ་སྐྱེ་བ་ལ་བར་དུ་གཅོད་པ་དང༌། གཞན་གྱི་དབང་དུ་གྱུར་པ་དང༌། ལུས་ཐོབ་པ་ལས་ཉམས་པ་དང༌། རྣམ་པར་སྨིན་པ་དང་ལས་ཀྱི་སྒྲིབ་པས་མི་སྐྱེ་བར་བསྟན་པ་དང༌། སྐྱེ་ཡང་རབ་ཏུ་དབྱུང་བར་མི་འོས་པའི་བར་ཆད་དོ། །དང་པོ་ལ་གཉིས། བསམ་པ་རྟེན་རུང་མ་ཐོབ་པ། ལུས་རྟེན་རུང་མ་ཐོབ་པའོ། །དང་པོ་ལ་གསུམ་ལས།
