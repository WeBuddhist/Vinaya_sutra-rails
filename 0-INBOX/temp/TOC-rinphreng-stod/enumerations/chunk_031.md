Enumeration Block 1:
ནགས་ནི་གསུམ་སྟེ། སྲོག་ཆགས་ཡོད་པར་ཤེས་པ་དང༌། དོགས་པ་དང༌། མེད་པའི་ཕྱོགས་སོ། །དང་པོ་ལ་གཉིས་ལས།
Enumeration Block 2:
བཞི་པ་གཞན་གྱི་དོན་འགྲུབ་པ་ལ་གནོད་པ་རྫུན་སྨྲ་བའི་ཕམ་པ་ལ་གཉིས་སྤྱི་དོན་དང༌། གཞུང་དོན་ནོ། །དང་པོ་ལ་གསུམ་ལས།
Enumeration Block 3:
ཡན་ལག་ལ་བཞི་ལས།
Enumeration Block 4:
བསམ་པ་ལ་གཉིས་ལས་
Enumeration Block 5:
གཞུང་དོན་ལ་གསུམ་ལས། དང་པོ་རྣམ་འབྱེད་ཀྱི་སྐབས་ནས་འབྱུང་བ་ལ་གཉིས། ལྟུང་བ་རྣམ་གཞག་དང༌བསླབ་བྱའོ། །དང་པོ་ལ་གཉིས་ལས།
Enumeration Block 6:
