Enumeration Block 1:
དུས་ཚོད་དེ་དག་ནི་ལྔའོ། །ལྔ་གང་ཞེ་ན། གྲང་བ་དགུན་གྱི་དུས་དང༌། ཚ་བ་དཔྱིད་ཀྱི་དུས་དང༌། ཆར་འབབ་པ་དབྱར་གྱི་དུས་དང༌། དུས་ཐུང་ངུར་གནས་པས་ཤི་བ་དང་འདྲ་བས་དབྱར་ཐུང་ངུའི་དུས་དང༌། དབྱར་ཡང་ཡིན་དུས་རིང་པོ་ཡང་ཡིན་པས་དབྱར་རིང་པོའི་དུས་རྣམས་སོ། །
Enumeration Block 2:
དུས་གསུམ་དུ་ཡང་ཡོད་དེ། དགུན་དང་དཔྱིད་དང་དབྱར་ཏེ།
Enumeration Block 3:
དུས་བཞིར་ཡང་ཡོད་དེ། དགུན་དཔྱིད་དབྱར་སྟོན་ཏེ།
Enumeration Block 4:
དུས་དྲུག་ཏུ་ཡང་ཡོད་དེ་དགུན་དང༌། དགུན་སྨད་དང༌། དཔྱིད་དང༌། སོ་ག་དང༌། དབྱར་དང་སྟོན་ཏེ།
Enumeration Block 5:
དེ་ལྟར་བསྲུང་ཐབས་བཅུ་གཅིག་བརྗོད་ཀྱང་ལྔར་འདུས་ཏེ། གང་ཟག་གཞན་ལ་བརྟེན་ནས་བསྲུང་བ། རང་གི་བསམ་པ་ཕུན་སུམ་ཚོགས་པའི་སྒོ་ནས་བསྲུང་བ། མི་མཐུན་ཕྱོགས་ངོ་ཤེས་པའི་སྒོ་ནས་བསྲུང་བ། བདེ་བར་གནས་པའི་རྐྱེན་བསྟན་པའི་སྒོ་ནས་བསྲུང་བ། བསླབ་པ་ཡོངས་སུ་སྦྱོང་བའི་སྒོ་ནས་བསྲུང་བའོ། །
Enumeration Block 6:
གཉིས་པ་མི་ཉམས་པར་བསྲུང་བའི་ཐབས་ལ་གཉིས། གནས་དང་གནས་པའི་ཚུལ་ཁྲིམས་དང༌། གནས་དང་གནས་པའི་མཚན་ཉིད་དོ། །དང་པོ་ལ་གཉིས། གནས་པའི་ཚུལ་ཁྲིམས། གནས་ཀྱི་ཚུལ་ཁྲིམས་སོ། །དང་པོ་ལ་གསུམ། བྱ་བ་ཞུ་བའི་མཚན་ཉིད་དམིགས་བསལ་དང་བཅས་པ། རང་གཞན་གྱིས་བསྙེན་བཀུར་ཇི་ལྟར་བྱ་བ། དམན་པའི་གནས་སུ་མ་གཞུག་ཅིང་དམན་པའི་གནས་ནས་བསླང་བའོ། །
Enumeration Block 7:
གཉིས་པ་གནས་དང་གནས་པའི་མཚན་ཉིད་ལ་གཉིས། བཅས་པའི་སྐབས། རྗེས་བཅས་ཀྱི་སྐབས་སོ། །དང་པོ་ལ་གཉིས། བཙུན་པ་བརྟན་པའི་ཡན་ལག །མཁས་ཤིང་ཕན་འདོགས་ཀྱི་ཡན་ལག་གོ །
Enumeration Block 8:
གཉིས་པ་མཁས་ཤིང་ཕན་འདོགས་ཀྱི་ཡན་ལག་ལ་གཉིས། མདོར་བསྟན། རྒྱས་བཤད་དོ། །
