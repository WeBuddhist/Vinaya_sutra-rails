Enumeration Block 1:
ལྔ་པ་གཞན་གྱི་ལུས་ལ་གནོད་པ་ལ་གཉིས་ལས།
Enumeration Block 2:
ཡན་ལག་ལ་བཞི་ལས།
Enumeration Block 3:
གཞུང་དོན་ལ་གསུམ། ཡན་ལག་ཐུན་མོང་བ་དང༌། ཐུན་མོང་མིན་པ་དང༌། བསླབ་བྱའོ། །
Enumeration Block 4:
གཉིས་པ་ལ་གཉིས། ཡན་ལག་གི་མཚན་ཉིད་དང༌། སེལ་བའོ། །
Enumeration Block 5:
ཡན་ལག་ལ་བཞི་ལས།
Enumeration Block 6:
བཅུ་པ་དྲུག་པ་ལ་ལྔ། གནོད་པ་ལས་གྱུར་པ་དང༌། འདོད་པ་ལས་དང༌། ལྟ་བ་ཉམས་པ་ལས་དང༌། གྲོགས་ངན་པ་(བསྟན་,བསྟེན་)པ་ལས་དང༌། དགེ་སྦྱོང་གི་ཚུལ་ཉམས་པ་ལས་གྱུར་པའོ། །དང་པོ་ལ་གསུམ། གཞན་གྱི་འཚོ་བ་ལ་གནོད་པ། རང་གི་ལུས་ལ་གནོད་པ། དགེ་འདུན་གྱི་ལས་ལ་གནོད་པའོ། །
Enumeration Block 7:
ཡན་ལག་ལ་བཞི་ལས།
Enumeration Block 8:
གཉིས་པ་རང་གི་ལུས་ལ་གནོད་པ་ལ་གསུམ། དགག་པའི་བསླབ་པ། གནང་བའི་བསླབ་པ། རྣམ་གཞག་གོ །
Enumeration Block 9:
བྱིན་གྱིས་བརླབ་པ་ནི་བཅུ་གཅིག་སྟེ། གོས་ལྷུང་སྨན་རིན་གསོ་དགག་དབྱེར། དུས་དང་ལྟུང་རྙེད་རུང་ཁང་ངོ༌། །དུས་བྱིན་གྱིས་བརླབ་པ་ལ་དྲུག་ལས།
Enumeration Block 10:
དབྱེ་བ་ནི་གཉིས་ཏེ། དགག་བྱ་ཉེས་དམིགས་འགོག་པ་དང༌། བརྒྱུད་པ་རྒྱུར་འགྲོ་འགོག་པའོ། །
Enumeration Block 11:
ཡན་ལག་ལ་བཞི་ལས།
Enumeration Block 12:
གཞུང་དོན་ལ་གཉིས་ལས།
Enumeration Block 13:
གཉིས་པ་སེལ་བ་ལ་གསུམ། མེའི་སེལ་བ་དང༌། བུད་ཤིང་གི་དང༌། གནས་སྐབས་ཀྱིའོ། །
Enumeration Block 14:
ཡན་ལག་ལ་བཞི་ལས།
