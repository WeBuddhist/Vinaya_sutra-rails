Enumeration Block 1:
བཞི་པ་ལ་གཉིས། སྦྱོར་བའི་ཆོ་ག །དངོས་གཞིའི་ཆོ་གའོ། །དང་པོ་ལ་གསུམ། ཁྲེལ་ཡོད་བསྐྱེད་པའི་ཕྱིར་གནས་ལ་ཞུ་ཞིང་གསོལ་བ། ཆོས་འདི་པའི་བསམ་པ་བསྐྱེད་པའི་ཕྱིར་རྟགས་སྦྱིན་པ། བར་ཆད་སྤང་བའི་ཕྱིར་མཚན་བརྟག་པའོ། །
Enumeration Block 2:
གཉིས་པ་དངོས་གཞི་ལ་གཉིས། རང་ལུགས། གཞན་ལུགས་སོ། །
Enumeration Block 3:
གཉིས་པ་དངོས་གཞི་ལ་གཉིས། དངོས་དང༌། ཞར་བྱུང་ངོ༌། །
Enumeration Block 4:
གཉིས་པ་ཞར་བྱུང་ལ་གསུམ། བླ་མ་རྣམས་ཀྱི་དབྱེ་བ། བླ་མར་འགྱུར་བའི་དུས། གྱུར་པ་ལ་མཚན་ནས་སྨོས་པའི་རིམ་པའོ། །
Enumeration Block 5:
གཉིས་པ་ལ། མདོར་བསྟན། རྒྱས་བཤད་གཉིས། དང་པོ་ལ་གཉིས། སློབ་དཔོན་དུ་འགྱུར་བའི་དུས་དང༌། མཁན་པོར་འགྱུར་བའི་དུས་སོ། །
Enumeration Block 6:
གཉིས་པ་རྒྱས་བཤད་ལ་གསུམ། ཐོབ་པར་བྱེད་པའི་བླ་མར་འགྱུར་བའི་དུས། མི་ཉམས་པར་བསྲུང་བའི་བླ་མར་འགྱུར་བའི་དུས། ཆོས་ཤེས་པར་བྱེད་པའི་བླ་མར་འགྱུར་བའི་དུས་སོ། །དང་པོ་ལ་གཉིས། སློབ་དཔོན་དུ་འགྱུར་བའི་དུས། མཁན་པོར་འགྱུར་བའི་དུས་སོ། །
