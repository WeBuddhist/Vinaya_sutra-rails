Enumeration Block 1:
ཐུན་མོང་མིན་པ་ལ་བཞི། གཞིའི་ཡན་ལག་དང༌། ཀུན་སློང་གི་ཡན་ལག་དང༌། སྦྱོར་བའི་ཡན་ལག་དང༌། མཐར་ཐུག་གི་ཡན་ལག་གོ །དང་པོ་ལ་གཉིས་ལས།
Enumeration Block 2:
གཉིས་པ་གཞུང་དོན་ལ་གཉིས། ལྟུང་བ་རྣམ་གཞག་དང༌། བསླབ་བྱའོ། །དང་པོ་ལ་གཉིས། མདོར་བསྟན་དང༌། རྒྱས་བཤད་དོ། །དང་པོ་ལ་གཉིས། ཡན་ལག་གི་མཚན་ཉིད་དང༌། སེལ་བའོ། །
Enumeration Block 3:
གཉིས་པ་ཕྲན་ཚེགས་ཀྱི་སྐབས་ནས་འབྱུང་བ་ལ་གཉིས། དགག་པའི་བསླབ་བྱ་དང༌། སྒྲུབ་པའི་བསླབ་བྱའོ། །
Enumeration Block 4:
གསུམ་པ་ཞུ་བའི་སྐབས་ནས་འབྱུང་བ་ལ་གསུམ། ཡན་ལག་གི་མཚན་ཉིད། སེལ་བ་དོགས་གཅོད་དང་བཅས་པ། སྔ་ཕྱི་འགལ་བའི་སྐྱོན་སྤང་བའོ། །
Enumeration Block 5:
བཞི་པ་འདུལ་བྱེད་ཀྱི་སྐབས་ནས་འབྱུང་བ་ལ་གསུམ། ལྟུང་བ་རྣམ་གཞག །ལྟུང་མེད། བསླབ་བྱའོ། །དང་པོ་ལ་གསུམ་ལས་
