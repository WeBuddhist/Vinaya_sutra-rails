Enumeration Block 1:
གཞུང་དོན་ལ་གསུམ་ལས། དང་པོ་རྣམ་འབྱེད་ཀྱི་སྐབས་ནས་འབྱུང་བ་ལ་གཉིས། ལྟུང་བ་རྣམ་གཞག་དང༌བསླབ་བྱའོ། །དང་པོ་ལ་གཉིས་ལས།
Enumeration Block 2:
གཉིས་པ་རྒྱས་བཤད་ལ་གསུམ་ལས།
Enumeration Block 3:
སྦྱོར་བའི་རབ་དབྱེ་ལ་གཉིས་ཀྱི་དང་པོ་
Enumeration Block 4:
གཉིས་པ་ངོ་བོའི་རབ་དབྱེ་ལ་གཉིས་ལས།
Enumeration Block 5:
དེ་ལ་གཉིས་ལས།
Enumeration Block 6:
གསུམ་པ་དེའི་ཆོས་བརྗོད་པས་སྨྲ་བ་ལ་གཉིས་ལས།
Enumeration Block 7:
གཉིས་པ་ཞུ་བའི་སྐབས་ནས་འབྱུང་བ་ལ་གཉིས། ཡན་ལག་ལ་དོགས་པ་བཅད་པ། སྦྱོར་བའི་སེལ་བ་དོགས་གཅོད་དང་བཅས་པའོ། །
Enumeration Block 8:
གསུམ་པ་འདུལ་བྱེད་ཀྱི་སྐབས་ནས་འབྱུང་བ་ལ་གཉིས་ལས།
Enumeration Block 9:
རྗེས་སུ་ཡི་རང་ལ་གཉིས་ལས།
Enumeration Block 10:
གཉིས་པ་གསོ་བ་དགེ་འདུན་ལ་རག་ལས་པ་དགེ་འདུན་ལྷག་མའི་སྡེ་ལ་གཉིས། དང་པོས་གྱུར་པ་དང༌། བསྒོ་བ་ལས་གྱུར་པའོ། །དང་པོ་ལ་གཉིས། ཆགས་པས་ཀུན་ནས་བསླང་བ་དང༌། གནོད་པས་ཀུན་ནས་བསླང་བའོ། །དང་པོ་ལ་གཉིས། སེམས་ཅན་ལ་ཆགས་པས་ཀུན་ནས་བསླང་བ་དང༌། ཕྱི་རོལ་ལ་ཆགས་པས་ཀུན་ནས་བསླང་བའོ། །དང་པོ་ལ་གཉིས། བདག་ཉིད་འདོད་པ་བསྟེན་པ་དང༌། གཞན་བསྟེན་དུ་འཇུག་པའོ། །དང་པོ་ལ་གཉིས། ལུས་ཀྱི་རེག་བྱའི་བདེ་བ་ལ་ཆགས་པ་དང༌། སྨྲ་བའི་བདེ་བ་ལ་ཆགས་པའོ། །དང་པོ་ལ་གཉིས། རང་གི་དང༌། གཞན་གྱིའོ། །དང་པོ་ལ་གསུམ་ལས།
Enumeration Block 11:
རྣམ་འབྱེད་ཀྱི་སྐབས་ནས་འབྱུང་བ་ལ་གཉིས། ཐུན་མོང་གི་མཚན་ཉིད་དང༌། སྐབས་དོན་བཤད་པའོ། །
Enumeration Block 12:
གཉིས་པ་ལ་གཉིས། སྤྱི་དོན་དང༌། གཞུང་དོན་ནོ། །དང་པོ་ལ་གསུམ་ལས།
Enumeration Block 13:
ཡན་ལག་ལ་བཞི་ལས།
Enumeration Block 14:
གཉིས་པ་གཞུང་དོན་ལ་གཉིས་ལས།
