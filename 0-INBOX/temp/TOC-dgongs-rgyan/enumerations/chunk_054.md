Enumeration Block 1:
བཞི་བ་ཅིར་འགྱུར་བཤད་པ་ལ༑ དངོས་དང་། སྦོམ་པོའི་ལྟུང་བའི་རྣམ་གཞག་བྱེ་བྲག་ཏུ་བཤད་པ་གཉིས་ལས། དང་པོ་ལན་སྨད་དུ་འགྱུར་ཚུལ། ཆེས་ན་སྨད་དུ་འགྱུར་ཚུལ། གཞན་དུ་འགྱུར་ཚུལ། ལྟུང་མེད་དུ་འགྱུར་ཚུལ་དང་བཞི་ལས།
Enumeration Block 2:
གསུམ་པ་གཞན་དུ་འགྱུར་ཚུལ་ལ་སྡེ་ཚན་གཞན་དུ་འགྱུར་ཚུལ། བཅས་པ་གཞན་དུ་འགྱུར་ཚུལ། གནས་སྐབས་གཞན་དུ་འགྱུར་ཚུལ་དང་གསུམ་ཡོད་པ་ལས།
Enumeration Block 3:
བཞི་པ། ལྟུང་མེད་དུ་འགྱུར་ཚུལ་བཤད་པ་ལ། ལྟུང་བ་དངོས་གཞི་མེད་པས་ལྟུང་མེད་དུ་འགྱུར་ཚུལ། སྐབས་དེར་གཏོགས་ཀྱི་ལྟུང་བ་མེད་པས་ལྟུང་མེད་དུ་འགྱུར་ཚུལ། ལྟུང་བ་རྣམ་གཞག་གི་ལྟུང་བ་མེད་པས་ལྟུང་མེད་དུ་འགྱུར་ཚུལ། ལྟུང་མེད་དུ་འགྱུར་ཚུལ་དངོས་བཤད་པ་དང་བཞི་ལས།
Enumeration Block 4:
བཞི་པ་ལྟུང་མེད་དུ་འགྱུར་ཚུལ་དངོས་བཤད་པ་ལ། བཅས་རང་གཉིས་ཀའི་སྒོ་ནས་ལྟུང་མེད་དུ་འགྱུར་ཚུལ་དང་། བཅས་པ་འབའ་ཞིག་གི་སྒོ་ནས་ལྟུང་མེད་དུ་འགྱུར་ཚུལ་གཉིས་ལས།
Enumeration Block 5:
གཉིས་པ་ལ་དགག་བྱ་མེད་པས་ལྟུང་མེད་དུ་འགྱུར་ཚུལ། བག་ཡངས་གནང་བའི་སྒོ་ནས་ལྟུང་མེད་དུ་འགྱུར་ཚུལ། སྒྲུབ་མི་ནུས་པའི་སྒོ་ནས་ལྟུང་མེད་དུ་འགྱུར་ཚུལ༑ རྐྱེན་དགོས་ལ་བལྟོས་ཏེ་ལྟུང་མེད་དུ་འགྱུར་ཚུལ་དང་བཞི་ལས།
Enumeration Block 6:
དེས་ན་བག་ཡངས་དེ་ལུང་གང་ལས་གསུངས་བ་ཤད་པ་དང་། གཞི་གང་ལས་བྱ་བ། ཆེད་དུ་བྱ་བ་གང་གི་ཕྱིར་དུ་བྱ་བ། ཆོ་ག་གང་གིས་བྱ་བ། སྡེ་པ་བཞི་པོ་གང་གི་ལུགས་ཡིན་བསྟན་པ་དང་། ལྔ་ལས།
Enumeration Block 7:
བཞི་པ་རྐྱེན་དགོས་ལ་ལྟོས་ཏེ་དེར་འགྱུར་ཚུལ་གཉིས་ལས།
Enumeration Block 8:
དེས་ན་སྦོམ་པོ་ལ། མཚན་ཉིད། དབྱེ་བ། བསྡུ་བ། ངོ་བོ། སྒྲ་བཤད་པ་དང་ལྔ་ལས།
