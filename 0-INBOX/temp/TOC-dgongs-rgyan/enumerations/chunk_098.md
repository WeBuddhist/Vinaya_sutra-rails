Enumeration Block 1:
༈ གསོ་སྦྱོང་བྱའོ། །ཟླ་བ་ཕྱེད་ཕྱེད་ཀྱི་ཚེས་བཅོ་ལྔ་ལའོ། །སོ་སོ་ཐར་པའི་མདོ་འདོན་ལས་སོ། །ཞེས་པའི་སྐབས་སུ། རང་ལུགས་གཞག་པ་དང་། གཞན་ལུགས་དགག་པ་གཉིས། དང་པོ་ལ། དགོས་དོན་དང་བསྡུས་དོན་གཉིས་ལས།
Enumeration Block 2:
གཉིས་པ་ལ། གསོ་སྦྱོང་གི་རྣམ་གཞག་སྤྱིར་བསྟན་པ་དང་། དེའི་རྣམ་གཞག་སོ་སོར་བཤད་པ་གཉིས། དང་པོ་ལ། གླིང་གཞི་འགོད་པ་དང་། དབྱེ་བ། བསྡུ་བ། ངོ་བོ། །

བྱེད་ལས། གྲངས་ངེས། གོ་རིམ། སྒྲ་བཤད་པ་དང་བརྒྱད་ཡོད་པ་ལས།
Enumeration Block 3:
རྩ་བའི་གཉིས་པ་སོ་སོར་བཤད་པ་ལ། ཞི་གནས་ཀྱི་གསོ་སྦྱོང་བཤད་པ་དང་། མཐུན་པའི་གསོ་སྦྱོང་བཤད་པ་གཉིས་ལས།
Enumeration Block 4:
གཉིས་པ་ལ། གང་དུ་བྱ་བ་གནས་ཀྱི་མཚན་ཉིད། གང་དག་དང་བྱ་བ་གྲོགས་ཀྱི་མཚན་ཉིད། ཇི་ལྟར་བྱ་བ་ཆོ་གའི་མཚན་ཉིད་དང་གསུམ་ལས།
Enumeration Block 5:
བློ་མཐུན་བྱ་བའི་ཚུལ་ལ་བདུན་ལས།
Enumeration Block 6:
མཚམས་དེ་ལ་མངོན་པར་སྒྲུབ་པའི་མཚམས་དང་། མངོན་པར་མ་སྒྲུབ་པའི་མཚམས་གཉིས། དང་པོ་ལ། ངག་གིས་མངོན་པར་སྒྲུབ་པའི་མཚམས་དང་། ལུས་ཀྱིས་མངོན་པར་སྒྲུབ་པའི་མཚམས་གཉིས། དང་པོ་ལ། མཚམས་པོ་ཆེ་བཅད་པ་དང་། མཚམས་བུ་ཆུང་ངུ་བཅད་པ་དང་། མཚམས་དེ་བཀྲོལ་བ་དང་གསུམ། དང་པོ་ལ། བདུན་ཡོད་པ་ལས།
