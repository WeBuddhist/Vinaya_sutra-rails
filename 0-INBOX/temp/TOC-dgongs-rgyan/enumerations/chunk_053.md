Enumeration Block 1:
ལྔ་པ་རྒྱུ་བཤད་པ་ལ། ཐུན་མོང་བའི་རྒྱུ་བཤད་པ་དང་། སོ་སོའི་རྒྱུ་བཤད་པ་གཉིས་ལས།

Enumeration Block 2:
དེ་ཡང་མི་ཤེས་པ་དེ་ལ་ཡང་། དེ་ཁོ་ན་ཉིད་ལ་རྨོངས་པའི་དེ། ལས་འབྲས་ལ་རྨོངས་པའི་དེ། རབ་བྱུང་གི་བྱ་བ་དང་། བྱ་བ་མ་ཡིན་པ་ལ་རྨོངས་པའི་དེ་དང་གསུམ་ཡོད་པ་ལས།

Enumeration Block 3:
མ་གུས་པ་ལ་སྤྱིར་བླ་མ་ལ་མ་གུས་པ་དང་ཁྱད་པར་མཁན་སློབ་ལ་མ་གུས་པ་གཉིས་ལས།

Enumeration Block 4:

Enumeration Block 5:
དེས་ན་རྟེན་གྱི་ཡན་ལག་འདི་ལ་ཡན་ལག་གི་མཚན་ཉིད་དང་སེལ་བ་གཉིས་ལས།

Enumeration Block 6:
དེས་ན་སེལ་བའི་རྣམ་གཞག་བཤད་པ་ལ། ངོ་བོ་བཤད་པ། སྒྲ་བཤད་པ། དབྱེ་བ་བཤད་པ། ཅིར་འགྱུར་རྩི་བ་དང་བཞི་ལས།

Enumeration Block 7:
གསུམ་པ་ནི་སེལ་བ་ལ་དབྱེ་ན། གཞིའི་ཡན་ལག་གི་སེལ་བ། བསམ་པའི་ཡན་ལག་གི་སེལ་བ། སྦྱོར་བའི་ཡན་ལག་གི་སེལ་བ། མཐར་ཐུག་གི་ཡན་ལག་གི་སེལ་བ་དང་བཞི་ཡོད་དེ།

Enumeration Block 8:
དེ་ལ་དབྱེ་ན། རྟེན་གྱི་ཡན་ལག་གི་སེལ་བ་དང་། ཡུལ་གྱི་ཡན་ལག་གི་སེལ་བ་གཉིས་ཡོད།

Enumeration Block 9:
གཉིས་པ་བསམ་པའི་ཡན་ལག་གི་སེལ་བ་དེ་ལ་འདུ་ཤེས་དང་ཀུན་སློང་གཉིས་ཡོད།

Enumeration Block 10:
བཞི་བ་ཅིར་འགྱུར་བཤད་པ་ལ༑ དངོས་དང་། སྦོམ་པོའི་ལྟུང་བའི་རྣམ་གཞག་བྱེ་བྲག་ཏུ་བཤད་པ་གཉིས་ལས།
དང་པོ་ལན་སྨད་དུ་འགྱུར་ཚུལ། ཆེས་ན་སྨད་དུ་འགྱུར་ཚུལ། གཞན་དུ་འགྱུར་ཚུལ། ལྟུང་མེད་དུ་འགྱུར་ཚུལ་དང་བཞི་ལས།
