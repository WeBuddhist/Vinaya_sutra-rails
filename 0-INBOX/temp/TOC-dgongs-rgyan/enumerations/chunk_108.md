Enumeration Block 1:
བདུན་པ་ཆོ་ག་ལ། སྦྱོར་བ། དངོས་གཞི། མཇུག་གི་ཆོ་ག་དང་གསུམ། དང་པོ་ལ། དགེ་འདུན་གྱིས་བྱ་བ་དང་། བསྐོས་པའི་དགེ་སློང་གིས་བྱ་བའི་ཚུལ་དང་གཉིས་ལས།
Enumeration Block 2:
སྐྱོང་ཚུལ་ལ་ཆུད་ཟ་བ་སྤོང་བ་དང་། མ་གུས་པ་སྤང་བ་དང་། རང་འཇུག་བྲལ་སྤང་བའི་སྒོ་ནས་སྐྱོང་ཚུལ་དང་གསུམ་ལས།
Enumeration Block 3:
༈ རྩ་བའི་གསུམ་པ་མཐར་སྲ་རྐྱང་དབྱུང་བའི་ཚུལ་ལ། རང་འཇུག་བྲལ་གྱིས་དབྱུང་བ་དང་། བཅོས་མས་དབྱུང་བ་གཉིས་ལས། དང་པོ་ལ། དགེ་འདུན་མཐའ་དག་གི་རང་འཇུག་བྲལ་དང་། གང་ཟག་སྒོས་ཀྱི་རང་འཇུག་བྲལ་གཉིས་ལས། དང་པོ་ལ་བདུན་ཡོད་དེ། སྲ་རྐྱང་མཚམས་ཀྱི་ཕྱི་རོལ་དུ་ཁྱེར་བ་དང་། བསྲུང་མཁན་མེད་པར་མཚམས་ནང་དུ་སྐྱ་རེངས་ཤར་བ་དང་། རྟེན་སྲ་རྐྱང་དུ་གཏིང་བའི་དངོས་པོ་རླག་པ་དང་། བྱེད་པ་པོ་དགེ་སློང་མིན་པར་གྱུར་བ་དང་། རེ་བ་ཆད་པ་དང་། དུས་ལ་མི་ལྟོས་པ་དང་། འཕེན་པ་ཟད་པ་རྣམས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 4:
གཉིས་པ་ལ། མ་མ་སུམ་ཅུས་དབྱུང་བ་དང་། གང་ཟག་སོ་སོའི་དྲན་ཞིང་མིན་པས་དབྱུང་བ་གཉིས་ལས། དང་པོ་ནི། སྤྱིར་མ་མ་ད་ལ་སུམ་ཅུ་ཡོད་དེ། མཚམས་ལ་རེ་བ་མེད་པའི་མ་མ། མཚམས་ལ་ཡིད་གཉིས་ཟ་བའི་མ་མ། མཚམས་ལ་རེ་བ་ཡོད་པའི་མ་མ་སྟེ་གསུམ་པོ་དེ་ལ་བརྒྱད་བརྒྱད་ཡོད་པའི་ཕྱིར། དེ་བཞིན་དུ། རྙེད་པ་ལ་ཡིད་གཉིས་ཟ་བའི་མ་མ་དྲུག་རྣམས་སུ་ཡོད་པའི་ཕྱིར༑

དང་པོ་མཚམས་ལ་རེ་བ་མེད་པའི་མ་མ་ལ་བརྒྱད་ཡོད་དེ། སྦྱོར་འགྲོའི་མ་མ་བཞི་དང་། ངེས་འབྱེད་ཀྱི་མ་མ་བཞི་རྣམས་སུ་ཡོད་པའི་ཕྱིར། དང་པོ་བཞི་ཡོད་དེ། འབྲེལ་མེད་གཅིག་དང་། འབྲེལ་བཅས་གསུམ་ཡོད་པའི་ཕྱིར།
Enumeration Block 5:
ངེས་འབྱེད་ལ་འབྲེལ་མེད་གཅིག་དང་། འབྲེལ་བཅས་གསུམ་ལས།
Enumeration Block 6:
མཚམས་ལ་ཡིད་གཉིས་ཟ་བའི་མ་མ་ལ་བརྒྱད་ཡོད་དེ། སྦྱོར་འགྲོ་བཞི་དང་། ངེས་འབྱེད་བཞི་ཡོད་ཅིང་། དེ་རེ་རེ་ལ་འབྲེལ་མེད་གཅིག་རེ་དང་འབྲལ་བཅས་གསུམ་གསུམ་ཡོད་ལ།
Enumeration Block 7:
ཡང་མཚམས་ལ་རེ་བ་ཡོད་པའི་མ་མ་བརྒྱད་ཡོད་དེ། འབྲེལ་མེད་གཉིས་དང་། འབྲེལ་བཅས་དྲུག་ཡོད་པའི་ཕྱིར།
