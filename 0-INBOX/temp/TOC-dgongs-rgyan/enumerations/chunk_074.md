Enumeration Block 1:
བདུན་པ་ལ་གོས་ཀྱི་རིགས་ངོས་བཟུང་བ་དང་། མུ་བཞིར་བརྩི་བའི་ཚུལ་དངོས་གཉིས། དང་པོ་ལ་ཞག་བཅུ་འཆང་སྤང་གི་གོས་ཀྱི་རིགས་ངོས་བཟུང་བ། ཟླ་འཇོག་གི་སྤང་བའི་གོས་ཀྱི་རིགས་ངོས་བཟུང་བ་གཉིས།

Enumeration Block 3:
དེས་ན་གོས་ཞག་བཅུ་འཆང་སྤང་བཤད་པ་ལ། གླེང་གཞི། རྒྱུ་མཚན། ངོ་ཏི། ཡན་ལག་གི་བརྩི་བ་རྣམ་པར་བཞག་པ་དང་བཞི།

Enumeration Block 4:
བཞི་པ་ལ། གཞི། བསམ་པ། སྦྱོར་བ། མཐར་ཐུག་གི་ཡན་ལག་དང་བཞི། དང་པོ་ལ། གང་འཆང་བའི་དངོས་པོ་དང་། གང་གིས་འཆང་བའི་རྟེན་གཉིས།

Enumeration Block 5:

Enumeration Block 6:
འབྲལ་སྤང་བཤད་པ་ལ་བཞི་ལས།

Enumeration Block 7:
བཞི་པ་ལ་བཞི་ལས། དང་པོ་ལ། གང་དང་འབྲལ་བའི་གོས། གང་དུ་བྲལ་བའི་གནས། གང་གིས་བྲལ་བའི་རྟེན་དང་གསུམ།

Enumeration Block 8:
འོ་ན་སྐབས་འདིར་སྣམ་སྦྱར་དང་མི་འབྲལ་བའི་གནང་བ་སྟེར་བའི་ཚུལ་དེ་གང་ཡིན་ཞེ་ན། འདི་ལ་ཡུལ་གང་ལ་སྦྱིན་པ། རྟེན་གྱི་གང་ཟག་གང་གིས་སྦྱིན་པ། དངོས་པོ་གང་སྦྱིན་པ། ཆོ་ག་ཇི་ལྟ་བུས་སྦྱིན་པ། དེ་འཇིག་པའི་དུས། སྦྱིན་པའི་དགོས་པ་བཤད་པ་དང་དྲུག །

Enumeration Block 10:

Enumeration Block 11:

Enumeration Block 12:
བཞི་བ་འཁྲུར་འཇུག་གི་སྤང་བ་བཤད་པ་ལ། གླེང་གཞི་དང་། ལྟུང་བ་རྣམ་བཞག་གཉིས།

Enumeration Block 13:

Enumeration Block 14:

Enumeration Block 15:

Enumeration Block 16:
བདུན་པ་སློང་བར་རིགས་པ་སློང་བའི་སྤང་བ་བཤད་པ་ལ་གཉིས་ལས།

Enumeration Block 17:

Enumeration Block 18:

Enumeration Block 19:

Enumeration Block 20:

Enumeration Block 21:
