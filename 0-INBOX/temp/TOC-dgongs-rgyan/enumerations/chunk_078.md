Enumeration Block 1:
བཅུ་པ་ཕ་གུ་རིམ་པ་གསུམ་ལས་ལྷག་པ་རྩིགས་པའི་ལྟུང་བྱེད་བཤད་པ་ལ་གསུམ་ལས།
Enumeration Block 2:
བཅུ་ཚན་གསུམ་པ་ལ་སྡོམ་གྱིས་བསྡུས་པའི་ཚུལ་དང་། དེའི་དོན་བཤད་པ་གཉིས།
Enumeration Block 3:
གཉིས་པ་ལ་བཅུ་ཡོད་པའི་དང་པོ། །མ་བསྐོས་པར་ཆོས་སྟོན་པའི་ལྟུང་བྱེད་བཤད་པ་ལ་གསུམ་ལས།
Enumeration Block 4:
གཉིས་པ་ཉི་མ་ནུབ་ཀྱི་བར་དུ་ཆོས་སྟོན་པའི་ལྟུང་བྱེད་ལ་གསུམ་ལས།
Enumeration Block 5:
གསུམ་པ་ཟས་ཅུང་ཟད་ཙམ་གྱི་ཕྱིར་ཆོས་སྟོན་ནོ་ཞེས་སྐུར་བ་འདབས་པའི་ལྟུང་བྱེད་ལ་གསུམ་ལས།
Enumeration Block 6:
བཞི་པ་གོས་བྱད་པའི་ལྟུང་བྱེད་ལ་གསུམ་ལས།
Enumeration Block 7:
ལྔ་པ་གོས་བྱིན་པའི་ལྟུང་བྱེད་ལ་གསུམ་ལས།
Enumeration Block 8:
དྲུག་པ་དགེ་སློང་མ་དང་ལྷན་ཅིག་ལམ་དུ་འགྲོ་བའི་ལྟུང་བྱེད་ལ་གསུམ་ལས།
Enumeration Block 9:
བདུན་པ་དགེ་སློང་མ་དང་ལྷན་ཅིག་གྲུར་ཞུགས་པའི་ལྟུང་བྱེད་ལ་གསུམ་ལས།
Enumeration Block 10:
བརྒྱད་པ་དབེན་པ་ན་འདུག་པའི་ལྟུང་བྱེད་ལ་གསུམ་ལས།
Enumeration Block 11:
དགུ་པ་དབེན་པ་ན་འགྲེང་བའི་ལྟུང་བྱེད་ལ་གསུམ་ལས།
Enumeration Block 12:
བཅུ་པ་དགེ་སློང་མས་སྦྱོར་ཏུ་བཅུག་པའི་ཟས་ཟ་བའི་ལྟུང་བྱེད་ལ་གསུམ་ལས།
Enumeration Block 13:
བཅུ་ཚན་བཞི་པ་འཆད་པ་ལ། སྡོམ་ཚིག་གིས་བསྡུས་པའི་ཚུལ་དང་། དེའི་དོན་བཤད་པ་གཉིས་ལས།
Enumeration Block 14:
གཉིས་པ་ལ་བཅུ་ཡོད་པ་ལས། དང་པོ་ནི། ཡང་ཡང་ཟ་བའི་ལྟུང་བྱེད་ལ་གསུམ་ཡོད་པ་ལས།
Enumeration Block 15:
གཉིས་པ་འདུག་གནས་སུ་ཟ་བའི་ལྟུང་བྱེད་ལ་གསུམ་ལས།
Enumeration Block 16:
གསུམ་པ་ལྷུང་བཟེད་དོ་གསུམ་ཙམ་ལས་ལྷག་པ་ལེན་པའི་ལྟུང་བྱེད་ལ་གསུམ་ལས།
Enumeration Block 17:
བཞི་པ་སྤངས་པ་ཟ་བའི་ལྟུང་བྱེད་བཤད་པ་ལ་གསུམ་ལས།
