Enumeration Block 1:
འདིའི་དོན་བཤད་པ་ལ། གླེང་གཞི། ངོ་ཏི། ཡན་ལག་གི་བརྩི་བ་རྣམ་པར་བཞག་པ་དང་གསུམ།

Enumeration Block 2:
གསུམ་པ་ལ་གཞི། བསམ་པ། སྦྱོར་བ། མཐར་ཐུག་གི་ཡན་ལག་དང་བཞི་ལས།

Enumeration Block 3:
འདིའི་དོན་བཤད་པ་ལ། གླེང་གཞི། ངོ་ཏི། ཡན་ལག་བཤད་པ་གསུམ་ལས།

Enumeration Block 4:
གསུམ་པ་ལ། གཞི། བསམ་པ། སྦྱོར་བ། མཐར་ཐུག་གི་ཡན་ལག་དང་བཞི་ལས།

Enumeration Block 5:
དེའི་དོན་བཤད་པ་ལ། གླེང་གཞི། ངོ་ཏི། ཡན་ལག་གི་བརྩི་བ་རྣམ་པར་བཞག་པ་དང་གསུམ།

Enumeration Block 6:
གསུམ་པ་ལ་གཞི། བསམ་པ། སྦྱོར་བ། མཐར་ཐུག་གི་ཡན་ལག་དང་བཞི་ལས།

Enumeration Block 7:
ལྟུང་བ་སྡེ་ལྔའི་ནང་ནས་ལྟུང་བྱེད་ཀྱི་སྡེ་བཤད་པ་ལ། སྤང་ལྟུང་གི་སྡེ་བཤད་པ་དང་། ལྟུང་བྱེད་འབའ་ཞིག་པའི་སྡེ་བཤད་པ་གཉིས། དང་པོ་ལ། བཅུ་ཚན་གསུམ་ཡོད་པ་ལས།
