Enumeration Block 1:
གཉིས་པ་ལ་བཅུ་ཡོད་པའི་ནང་ནས། དང་པོ་ཟས་གཅོད་པའི་ལྟུང་བྱེད་ལ་གསུམ་ལས།

Enumeration Block 2:
གཉིས་པ་མེ་རེག་གི་ལྟུང་བྱེད་ལ་གསུམ་ལས།

Enumeration Block 3:
གསུམ་པ་ལ། དངོས་དང་དུས་དྲན་བྱེད་ཚུལ་བཤད་པ་གཉིས།

Enumeration Block 4:
གཉིས་པ་དུས་དྲན་བྱེད་ཚུལ་ལ། དུས་དྲན་གང་ལ་བྱ་བའི་གཞི། གང་གིས་བྱེད་པའི་རྟེན། ནམ་གྱི་ཚེ་བྱ་བ། ཇི་ཙམ་བྱ་བ། དུས་དྲན་རང་གི་ངོ་བོ། བྱས་པའི་དགོས་པ། དུས་དྲན་འཇིག་པའི་ཚུལ་བཤད་པ་དང་བདུན།

Enumeration Block 5:
གསུམ་པ་འདུན་པ་ཕྱིར་བསྒྱུར་གྱི་ལྟུང་བྱེད་ལ་གསུམ་ལས།

Enumeration Block 6:
བཞི་པ་བསྙེན་པར་མ་རྫོགས་པ་དང་ལྷན་ཅིག་ཉལ་བའི་ལྟུང་བྱེད་ལ་གསུམ་ལས།

Enumeration Block 7:
ལྔ་པ་ཆོས་དང་ཞེས་པ་སྡིག་པ་ཅན་གྱི་ལྟ་བའི་རྣམ་པ་མི་གཏོང་བའི་ལྟུང་བྱེད་ལ་གསུམ་ལས།

Enumeration Block 8:
དྲུག་པ་སྨྲ་ཞེས་པ་སྤངས་པའི་རྗེས་སུ་ཕྱོགས་པའི་ལྟུང་བྱེད་ལ་གསུམ་ལས།

Enumeration Block 9:
བདུན་པ་དགེ་ཚུལ་བསྙིལ་བ་སྡུད་པའི་ལྟུང་བྱེད་ལ་གསུམ་ལས།

Enumeration Block 10:
བརྒྱད་པ་ཁ་དོག་མ་བསྒྱུར་བའི་གོས་གྱོན་པའི་ལྟུང་བྱེད་ལ་གསུམ་ལས།

Enumeration Block 11:
དགུ་པ་རིན་པོ་ཆེ་དང་ཞེས་པ་ལོངས་པ་གཞིར་གཏོགས་ཀྱི་ལྟུང་བྱེད་ལ་གསུམ་ལས།

Enumeration Block 12:
བཅུ་པ་ཚ་བའི་དུས་ཞེས་པ་ཁྲུས་བྱེད་པའི་ལྟུང་བྱེད་ལ་གསུམ་ལས།

Enumeration Block 13:
བཅུ་ཚན་བདུན་པ་འཆད་པ་ལ། སྡོམ་གྱིས་བསྡུས་པའི་ཚུལ་དང་། དེའི་དོན་བཤད་པ་གཉིས་ལས།
