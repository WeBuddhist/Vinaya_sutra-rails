Enumeration Block 1:
༈ ༎གསུམ་པ་བསྡུ་བ་བཤད་པ་ལ་གསུམ་དུ་བསྡུ་བ་དང་། གཉིས་སུ་བསྡུ་བ་གཉིས་ལས།
Enumeration Block 2:
གཉིས་པ་སྡེ་སྣོད་གསུམ་ཤེས་པ་ཡན་ལག་ཏུ་ལྡན་པའི་ལྔ་པ་དེ་ཡང་། དེ་གསུམ་གྱི་ཚིག་ཤེས་པ་ཡན་ལག་ཏུ་ལྡན་པའི་ལྔ་པ། དེ་གསུམ་གྱི་དོན་ཙམ་ཤེས་པ་ཡན་ལག་དུ་ལྡན་པའི་ལྔ་པ་དང་གཉིས་ལས།
Enumeration Block 3:
གཉིས་པ་ལ་ཡང་། བསླབ་པ་གསུམ་ལ་སློབ་པ་ཡན་ལག་ཏུ་ལྡན་པའི་ལྔ་པ། ལྷག་པའི་སྤྱོད་པ་ལ་སློབ་པ་ཡན་ལག་ཏུ་ལྡན་པའི་ལྔ་པ། ཕུན་ཚོགས་ཀྱི་ཡོན་ཏན་དང་ལྡན་པའི་ལྔ་པ། ཚོགས་སྦྱོར་བའི་ཡོན་ཏན་དང་ལྡན་པའི་ལྔ་པ། འཕགས་པ་ཁོ་ནའི་ཡོན་ཏན་དང་ལྡན་པའི་ལྔ་པ་དང་ལྔ་ཡོད་པ་ལས།
Enumeration Block 4:
གསུམ་པ་ཕུན་ཚོགས་ཀྱི་ཡོན་ཏན་དང་ལྡན་པའི་ལྔ་པ་དེ་ལ་ཡང་། སྐྱེ་འཕགས་ཐུན་མོང་པའི་ཡོན་ཏན་དང་ལྡན་པའི་དེའི་ལྔ་པ་དང་། མི་སློབ་པ་ཁོ་ནའི་ཡོན་ཏན་དང་ལྡན་པའི་དེའི་ལྔ་པ་གཉིས་ཡོད་པ་ལས།
Enumeration Block 5:
བཞི་པ་ཚོགས་སྦྱོར་བའི་ཡོན་ཏན་དང་ལྡན་པའི་ལྔ་པ་དེ་ལ་ཡང་། ལྷག་མཐོང་ཤས་ཆེར་སྤྱོད་པའི་ཡོན་ཏན་ཡན་ལག་ཏུ་ལྡན་པའི་ལྔ་པད་དང་། ཞི་གནས་ཤས་ཆེར་སྤྱོད་པའི་ཡོན་ཏན་ཡན་ལག་ཏུ་ལྡན་པའི་ལྔ་པ་གཉིས་ལས།
Enumeration Block 6:
རྩ་བའི་གསུམ་པ་འདུལ་བའི་སྡེ་སྣོད་ཙམ་ཤེས་པ་ཡན་ལག་ཏུ་ལྡན་པའི་ལྔ་པ་དེ་ལ་ཡང་། དེའི་དོན་ཙམ་ཤེས་པ་ཡན་ལག་ཏུ་ལྡན་པའི་ལྔ་པ་དང་། དེའི་ཚིག་དོན་གཉིས་ཀ་ཤེས་པ་ཡན་ལག་ཏུ་ལྡན་པའི་ལྔ་པ་གཉིས་ཡོད་པ་ལས།
Enumeration Block 7:
རྩ་བའི་བཞི་པ་ལ་གང་ཟག་རང་དབང་ཅན་ཡིན་མིན་གྱི་ཁྱད་པར་བཤད་པ། ལྔ་པ་རང་དབང་ཅན་ཡིན་མིན་གྱི་ཁྱད་པར་བཤད་པ། ལྔ་པའི་ཡན་ལག་རང་དབང་ཅན་ཡིན་མིན་གྱི་ཁྱད་པར་བཤད་པ་དང་གསུམ།
Enumeration Block 8:
གཉིས་པ་ལ་སོ་སོའི་མཚན་ཉིད་དང་། མཚན་གཞི་ངོས་བཟུང་བ་གཉིས་ལས།
