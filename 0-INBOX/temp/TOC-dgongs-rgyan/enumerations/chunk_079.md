Enumeration Block 1:
གཉིས་པ་འདུག་གནས་སུ་ཟ་བའི་ལྟུང་བྱེད་ལ་གསུམ་ལས།

Enumeration Block 2:
གསུམ་པ་ལྷུང་བཟེད་དོ་གསུམ་ཙམ་ལས་ལྷག་པ་ལེན་པའི་ལྟུང་བྱེད་ལ་གསུམ་ལས།

Enumeration Block 3:
བཞི་པ་སྤངས་པ་ཟ་བའི་ལྟུང་བྱེད་བཤད་པ་ལ་གསུམ་ལས།

Enumeration Block 4:
ལྔ་པ་སྤངས་པ་སྟོབས་པའི་ལྟུང་བྱེད་ལ་གསུམ་ལས།

Enumeration Block 5:
དྲུག་པ་འདུས་ཤིང་ཟ་བའི་ལྟུང་བྱེད་ལ་གསུམ་ལས།

Enumeration Block 6:
བདུན་པ་དུས་མ་ཡིན་པར་ཟ་བའི་ལྟུང་བྱེད་ལ་གསུམ་ལས།

Enumeration Block 7:
བརྒྱད་པ་གསོག་འཇོག་ཏུ་བཞག་པ་ཟོས་པའི་ལྟུང་བྱེད་ལ་གསུམ་ལས།

Enumeration Block 8:
དགུ་པ་བྱིན་ལེན་མ་བྱས་པར་ཟ་བའི་ལྟུང་བྱེད་ལ་གསུམ་ལས།

Enumeration Block 9:
བཅུ་པ་ཟས་བསོད་པ་སློང་བའི་ལྟུང་བྱེད་ལ་གསུམ་ལས།

Enumeration Block 10:
བཅུ་ཚན་ལྔ་པ་འཆད་པ་ལ། སྡོམ་གྱིས་བསྡུས་པའི་ཚུལ་དང་། དེའི་དོན་བཤད་པ་གཉིས།
