Enumeration Block 1:
མཁན་པོ་དངོས་ལ་མཚན་ཉིད། དབྱེ་བ། སྒྲ་དོན་དང་གསུམ་ལས།

Enumeration Block 2:
༈ གཉིས་པ་དགེ་ཚུལ་གྱི་སློབ་དཔོན་ལ། མཚན་ཉིད་དང་། དབྱེ་བ་གཉིས་ལས།

Enumeration Block 3:
གསུམ་པ་གསང་སྟོན་གྱི་སློབ་དཔོན་ལ་འོས་པ་དང་། དངོས་གཉིས་ལས།

Enumeration Block 4:
གཉིས་པ་དངོས་ལ། མཚན་ཉིད་དང་དབྱེ་བ་གཉིས་ལས།

Enumeration Block 5:
བཞི་པ་ལས་སློབ་ལ་འོས་པ་དང་། དངོས་གཉིས་ལས།

Enumeration Block 6:
གཉིས་པ་ལ་བསྙེན་རྫོགས་ཀྱི་ལས་སློབ་དང་། དགེ་སློབ་མའི་ལས་སློབ། ཚངས་སྤྱོད་ཉེར་གནས་ཀྱི་ལས་སློབ་དང་གསུམ་ཡོད་པ་ལས།

Enumeration Block 7:
༈ ལྔ་པ་གནས་བླ་མ་ལ་འོས་པ་དང་། དངོས་གཉིས་ལས།

Enumeration Block 8:
གཉིས་པ་ལ། མཚན་ཉིད་དང་། དབྱེ་བ་གཉིས་ལས།

Enumeration Block 9:
༈ ༎དྲུག་པ་ཀློག་པའི་སློབ་དཔོན་ལ་འོས་པ་དང་། དངོས་གཉིས་ལས།

Enumeration Block 10:
གཉིས་པ་ལ། མཚན་ཉིད་དང་། དབྱེ་བ་གཉིས་ལས།
