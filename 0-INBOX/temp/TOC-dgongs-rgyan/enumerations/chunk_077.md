Enumeration Block 1:
བཅུ་པ་ཁྱད་དུ་གསོད་པའི་ལྟུང་བྱེད་ལ་སྔར་ལྟར་གསུམ་ལས།

Enumeration Block 2:
བཅུ་ཚན་གཉིས་པ་འཆད་པར་བྱེད་པ་ལ་བསྡོམ་གྱིས་བསྡུས་པའི་ཚུལ་དང་། དེའི་དོན་བཤད་པ་གཉིས།

Enumeration Block 3:
གཉིས་པ་ལ་བཅུ་ཡོད་པའི་ནང་ནས་དང་པོ་ས་བོན་སྐྱེ་འཇིག་གི་ལྟུང་བྱེད་འཆད་པ་ལ། གསུམ་ལས།

Enumeration Block 4:
གཉིས་པ་འཕྱ་བའི་ལྟུང་བྱེད་ལ་གསུམ་ལས།

Enumeration Block 5:
གསུམ་པ་བསྒོ་བ་རྣ་ལ་གཟོན་པའི་ལྟུང་བྱེད་འཆད་པ་ལ་གསུམ་ལས།

Enumeration Block 6:
བཞི་པ་གནས་མལ་མ་བསྡུས་པར་འགྲོ་བའི་ལྟུང་བྱེད་འཆད་པ་ལ་གསུམ་ལས།

Enumeration Block 7:
ལྔ་པ་གདིང་བའི་ལྟུང་བྱེད་བཤད་པ་ལ་གསུམ་ལས།

Enumeration Block 8:
དྲུག་པ་སྐྲོད་པའི་ལྟུང་བྱེད་བཤད་པ་ལ་གསུམ་ལས།

Enumeration Block 9:
བདུན་པ་ཕྱིས་གནོན་བྱེད་པའི་ལྟུང་བྱེད་བཤད་པ་ལ་གསུམ་ལས།

Enumeration Block 10:
བརྒྱད་པ་རྩ་བ་འབྱུང་བ་ལ་འདུག་པའི་ལྟུང་བྱེད་བཤད་པ་ལ་གསུམ་ལས།

Enumeration Block 11:
དགུ་པ་དུད་འགྲོ་འདེབས་པའི་ལྟུང་བྱེད་བཤད་པ་ལ་གསུམ་ལས།

Enumeration Block 12:
བཅུ་པ་ཕ་གུ་རིམ་པ་གསུམ་ལས་ལྷག་པ་རྩིགས་པའི་ལྟུང་བྱེད་བཤད་པ་ལ་གསུམ་ལས།

Enumeration Block 13:
བཅུ་ཚན་གསུམ་པ་ལ་སྡོམ་གྱིས་བསྡུས་པའི་ཚུལ་དང་། དེའི་དོན་བཤད་པ་གཉིས།

Enumeration Block 14:
གཉིས་པ་ལ་བཅུ་ཡོད་པའི་དང་པོ། །མ་བསྐོས་པར་ཆོས་སྟོན་པའི་ལྟུང་བྱེད་བཤད་པ་ལ་གསུམ་ལས།
