Enumeration Block 1:
གསུམ་པ་སོ་སོའི་རང་བཞིན་བཤད་པ་ལ་བཅུ་གསུམ་ཡོད་པ་ལས། དང་པོ་ཁུ་བ་འབྱིན་པའི་ལྷག་མའི་ལྟུང་བ་ལ། གླེང་གཞི། དགག་བྱ། དོ་ཏི། ཡན་ལག་གི་བརྩི་བ་རྣམ་པར་བཞག་པ་དང་བཞི་ལས།

Enumeration Block 2:
བཞི་པ་ལ། གཞི། བསམ་པ། སྦྱོར་བ། མཐར་ཐུག་གི་ཡན་ལག་དང་བཞི།

Enumeration Block 3:
གཉིས་པ་ལ་འདུ་ཤེས་དང་། ཀུན་སློང་གཉིས་ལས།

Enumeration Block 4:
གཉིས་པ་རེག་པའི་དགེ་འདུན་ལྷག་མ་ལ། གླེང་གཟི། དགག་བྱ། ངོ་ཏི། ཡན་ལག་གི་བརྩི་བ་རྣམ་པར་བཞག་པ་དང་བཞི།

Enumeration Block 5:
བཞི་པ་ལ། གཞི། གསམ་པ། སྦྱོར་བ། མཐར་ཐུག་གི་ཡན་ལག་དང་བཞི་ལས།

Enumeration Block 6:
གཉིས་པ་བསམ་པ་ལ་གཉིས་ལས།

Enumeration Block 7:
གསུམ་པ་འཁྲིག་ཚིག་སྨྲ་བའི་ལྷག་མའི་ལྟུང་བ་འཆད་པ་ལ། གླེང་གཞི་སོགས་བཞི་ལས།

Enumeration Block 8:
བཞི་པ་ཡན་ལག་གི་བརྩི་ཚུལ་ལ་བཞི་ལས།

Enumeration Block 9:
གཉིས་པ་བསམ་པ་ལ་གཉིས་ལས།

Enumeration Block 10:
བཞི་པ་བསྙེན་བཀུར་བསྔགས་པའི་ལྷག་མའི་ལྟུང་བ་འཆད་པ་ལ། གླེང་གཞི་སོགས་བཞི་ལས།

Enumeration Block 11:
ལྔ་པ་སྨྱན་བྱེད་པའི་ལྷག་མའི་ལྟུང་བ་འཆད་པ་ལ༑ གླེང་གཞི་སོགས་བཞི་ལས།

Enumeration Block 12:
བཞི་པ་ཡན་ལག་གི་བརྩི་ཚུལ་ལ་བཞི་ལས།

Enumeration Block 13:
གཉིས་པ་ལ་གཉིས་ལས།

Enumeration Block 14:
དྲུག་པ་ཁང་པ་ལ་བརྟེན་པའི་ལྷག་མའི་ལྟུང་བ་འཆད་པ་ལ། གླེང་གཞི་སོགས་བཞི་ལས།
