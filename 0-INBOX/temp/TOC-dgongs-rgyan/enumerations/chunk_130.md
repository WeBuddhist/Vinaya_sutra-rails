Enumeration Block 1:
གཉིས་པ་བསམ་པའི་ཡན་ལག་ལ་གཉིས་ལས།
Enumeration Block 2:
དེས་ན་ལས་ཀྱི་དབྱེན་འབྱུང་བའི་རྒྱུ་སྤོང་བ་དང་། དེ་མི་འབྱུང་བའི་ཐབས་བསྟེན་པ་གཉིས་ལས།
Enumeration Block 3:
འབྲེལ་པ་ཅན་གྱི་གཞུང་དོན་སྤྱིར་བསྟན་པ་ལ། ཁྱད་པར་གྱི་གཞི་ཆོས་འཁོར་གྱི་རྣམ་གཞག་དང་། ཁྱད་པར་གྱི་ཆོས་འཁོར་ལོའི་དབྱེན་གྱི་རྣམ་གཞག་བཤད་པ་དང་གཉིས་ལས།
Enumeration Block 4:
གཉིས་པ་ནི། དེ་བསྟན་པ་འདི་ལ་བྱུང་ཚུལ་དང་། དེའི་རྣམ་གཞག་བཤད་པ་གཉིས་ལས།
Enumeration Block 5:
གཉིས་པ་དེའི་རྣམ་གཞག་བཤད་པ་དངོས་ལ། གཞི། བསམ་པ། སྦྱོར་བ། མཐར་ཐུག་གི་ཡན་ལག་དང་བཞི། དང་པོ་གཞིའི་ཡན་ལག་ལ་ཡང་། གང་དུ་དབྱེ་བའི་གནས། གང་དག་དབྱེ་བའི་ཡུལ། གང་གི་ཚེ་འབྱེད་པའི་དུས། གང་ལས་དབྱེ་བའི་དོན། གང་གིས་འབྱེད་པའི་རྟེན་བཤད་པ་དང་ལྔ་ལས།
