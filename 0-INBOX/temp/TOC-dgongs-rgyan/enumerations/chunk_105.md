Enumeration Block 1:
རང་ལུགས་གཞག་པ་ལ། དགོས་པ་གང་གི་ཕྱིར་དུ་དབྱར་ཁས་བླང་བ། གང་ཟག་གང་གིས་བླང་བ། གནས་གང་དུ་བླང་བ། དུས་ནམ་གྱི་ཚེ་བླང་བ། ཡུན་ཇི་སྲིད་དུ་བླང་བ། བསམ་པ་གང་གིས་བླང་བ། ཆོ་ག་གང་གིས་བླང་བ། དབྱར་གྱི་དམ་ཚིག་བསྲུང་ཚུལ་དང་བརྒྱད་ཡོད།

Enumeration Block 2:
ཆོ་ག་ལ་སྦྱོར་དངོས་མཇུག་གསུམ། དང་པོ་ལ་ཡང་། གནས་ཇི་ལྟར་བྱ་བ། གནས་མལ་སྟོབས་པ། བྱེད་པ་པོ་བསྐོ་ཞིང་དེས་ཇི་ལྟར་བྱ་བ་དང་གསུམ་ལས།

Enumeration Block 3:
གསུམ་པ་ལ། སྦྱོར་བའི་ཆོ་ག་དང་། དངོས་གཞིའི་ཆོ་ག་དང་། མཇུག་གི་ཆོ་ག་དང་གསུམ་ལས།

Enumeration Block 4:
གསུམ་པ་བྱེད་པ་པོ་བསྐོས་པ་ཇི་ལྟར་བྱ་བའི་ཚུལ་འདི་ལ་ཡང་། སྦྱོར་བའི་ཆོ་ག ། དངོས་གཞིའི་ཆོ་ག ། 
མཇུག་གི་ཆོ་ག་དང་གསུམ། དང་པོ་ལ། ཚུལ་ཤིང་ཉེ་བར་བཞག་པ། དབྱར་གནས་པར་ཁས་ལེན་མི་ནུས་པས། གནས་མལ་མི་ནོད་པའི་ཕྱིར་དུ་ཁྲིམས་སུ་བཅའ་བ་བསྒྲགས་པ། དབྱར་གནས་པ་ཁས་ལེན་པ་དང་ཚུལ་ཤིང་བླང་བའི་ཕྱིར་དུ་གསོལ་བ་འབའ་ཞིག་པའི་ལས་བྱ་བ། གྲངས་བཟུང་བའི་ཕྱིར་ཚུལ་ཤིང་བླང་བ་དང་བཞི་ལས།

Enumeration Block 5:
བཞི་པ་ལ། ཚུལ་ཤིང་འབྲིམ་པའི་ཆོ་ག་དང་། དེ་ལེན་པའི་ཆོ་ག་གཉིས།

Enumeration Block 6:
དངོས་གཞི་ལ། གནས་སྟོབས་པ་དང་། མལ་ཆ་སྟོབས་པ་གཉིས་ལས།

Enumeration Block 7:
མཇུག་གི་ཆོ་ག་ལ། གནས་མལ་ལོགས་པར་ལོངས་སྤྱོད་པའི་དགག་པ་དང་། སྙན་གསན་འབབ་པ་དང་གཉིས་ལས།

Enumeration Block 8:
གཉིས་པ་དངོས་གཞིའི་ཆོ་ག་ལ། སྤྱིར་བཏང་དང་། དམིགས་བསལ་གཉིས་ལས།

Enumeration Block 9:
དམ་ཚིག་བསྲུང་བ་ལ། བསྐོས་པའི་དམ་ཚིག་དང་། ཁས་བླངས་པའི་དམ་ཚིག་བསྲུང་ཚུལ་གཉིས་ལས།

Enumeration Block 10:
དབྱར་རལ་བ་སྤང་བ་ལ། དེའི་རྒྱུ་སྤང་བ་དང་། དེ་སྤང་བ་དངོས་གཉིས་ལས།
