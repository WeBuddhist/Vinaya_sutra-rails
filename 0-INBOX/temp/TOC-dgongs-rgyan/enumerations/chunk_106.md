Enumeration Block 1:
མཇུག་གི་ཆོ་ག་ལ། གནས་མལ་ལོགས་པར་ལོངས་སྤྱོད་པའི་དགག་པ་དང་། སྙན་གསན་འབབ་པ་དང་གཉིས་ལས།

Enumeration Block 2:
གཉིས་པ་དངོས་གཞིའི་ཆོ་ག་ལ། སྤྱིར་བཏང་དང་། དམིགས་བསལ་གཉིས་ལས།

Enumeration Block 3:
དམ་ཚིག་བསྲུང་བ་ལ། བསྐོས་པའི་དམ་ཚིག་དང་། ཁས་བླངས་པའི་དམ་ཚིག་བསྲུང་ཚུལ་གཉིས་ལས།

Enumeration Block 4:
དབྱར་རལ་བ་སྤང་བ་ལ། དེའི་རྒྱུ་སྤང་བ་དང་། དེ་སྤང་བ་དངོས་གཉིས་ལས།

Enumeration Block 5:
འོ་ན། བྱིན་གྱིས་བརླབ་ཚུལ་དེ་གང་ཡིན་ཞེ་ན། འདི་ལ། གནང་བ་མ་ཐོབ་པས་བྱིན་གྱིས་བརླབ་པ་དང་། དེ་ཐོབ་པས་བྱིན་གྱིས་བརླབ་པ་གཉིས་ལས།

Enumeration Block 6:
༈ དབྱར་གནས་པས་དགེ་འདུན་ལ་མཐོང་བ་དང་། ཐོས་པ་དང་། དོགས་པ་དག་གིས་དགག་དབྱེ་བྱའོ། །དབྱར་རྣམས་ཀྱི་ཐ་མའི་ཉི་མ་ལའོ། །ཞེས་པའི་སྐབས་སུ་སྤྱི་དོན་དང་། ངག་དོན་གཉིས་ལས།

Enumeration Block 7:
ཚུལ་ཇི་ལྟར་བྱ་བ་ལ་སྦྱོར་དངོས་མཇུག་གསུམ་ལས། དང་པོ་སྦྱོར་བ་ལ། ཞག་བཅུའམ། ཟླ་བ་ཕྱེད་ཀྱི་བར་ལ་ཇི་ལྟར་སྒྲུབ་པ། ཚེས་བཅུ་བཞི་ལ་ཇི་ལྟར་སྒྲུབ་པ། ལས་བྱེད་པའི་མདུན་རོལ་དུ་ཇི་ལྟར་སྒྲུབ་པ་དང་གསུམ།
