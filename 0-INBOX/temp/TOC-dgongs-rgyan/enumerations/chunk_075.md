Enumeration Block 1:
དགུ་པ་སོ་སོ་ནས་སྤགས་པ་སློང་བ་ལ་གཉིས་ལས།

Enumeration Block 2:
བཅུ་པ་བསྐུར་བའི་སྤང་བ་བཤད་པ་ལ་གཉིས་ལས།

Enumeration Block 3:
བཅུ་ཚན་གཉིས་པ་བཤད་པ་ལ། སྡོམ་གྱིས་བསྡུས་པའི་ཚུལ་དང་། སོ་སོའི་རང་བཞིན་བཤད་པ་གཉིས་ལས།

Enumeration Block 4:
གཉིས་པ་ལ་བཅུ་ཡོད་པའི་ནང་ནས། དང་པོ་སྟན་ལ་བརྟེན་པའི་སྤང་བ་དང་པོ་གསུམ་ལ། གླེང་གཞི་དང་། ལྟུང་བ་རྣམ་བཞག་གཉིས།

Enumeration Block 5:
བཞི་པ་ལོ་དྲུག་གི་ནང་དུ་སྟན་བྱས་པའི་སྤང་བ་བཤད་པ་ལ་གཉིས་ལས།

Enumeration Block 6:
ལྔ་པ་གནས་མལ་སྐྱོབ་པ་གདང་བ་ལས་གྱུར་པའི་སྤང་བ་བཤད་པ་ལ་གཉིས་ལས།

Enumeration Block 7:
དྲུག་པ་བལ་ཁུར་ཐོགས་པའི་སྤང་བ་བཤད་པ་ལ་གཉིས་ལས།

Enumeration Block 8:
བདུན་པ་འཁྲུ་བའི་སྤང་བ་བཤད་པ་ལ་གཉིས་ལས།

Enumeration Block 9:
བརྒྱད་པ་རིན་པོ་ཆེ་ལ་རེག་པའི་སྤང་བ་བཤད་པ་ལ་གཉིས་ལས།

Enumeration Block 10:
དགུ་པ་མངོན་མཚན་ཅན་གྱི་སྤང་བ་བཤད་པ་ལ་གཉིས་ལས།

Enumeration Block 11:
བཅུ་པ་ཉོ་འཚོང་བྱེད་པའི་སྤང་བ་བཤད་པ་ལ་གཉིས་ལས།

Enumeration Block 12:
བཅུ་ཚན་གསུམ་པ་བཤད་པ་ལ། སྡོམ་གྱིས་བསྡུས་པའི་ཚུལ་དང་། སོ་སོའི་དོན་བཤད་པ་གཉིས།

Enumeration Block 13:
གཉིས་པ་ལ། སོ་སོར་བཤད་པ་དང་། བསྡུ་བ་བཤད་པ་གཉིས། དང་པོ་ལ་བཅུ་ཡོད་པའི་ནང་ནས། དང་པོ་ལྷུང་བཟེད་ཞག་བཅུ་འཆང་སྤང་བཤད་པ་ལ་གཉིས་ལས།

Enumeration Block 14:
གཉིས་པ་ལྷུང་བཟེད་ལྷག་པོ་འཚོལ་བའི་སྤང་བ་བཤད་པ་ལ་གཉིས་ལས།

Enumeration Block 15:
གསུམ་པ་འཐག་ཏུ་འཇུག་པའི་སྤང་བ་བཤད་པ་ལ་གཉིས་ལས།

Enumeration Block 16:
བཞི་པ་འཐག་པ་བསྐྱེད་དུ་འཇུག་པའི་སྤང་བ་བཤད་པ་ལ་གཉིས།

Enumeration Block 17:
ལྔ་པ་བྱིན་འཕྲོག་གི་སྤང་བ་བཤད་པ་ལ་གཉིས་ལས།

Enumeration Block 18:
དྲུག་པ་བརྟད་པ་ལས་བྱུང་བའི་སྤང་པ་བཤད་པ་ལ་གཉིས་ལས།

Enumeration Block 19:
བདུན་པ་དགོན་པ་བའི་འབྲལ་སྤང་བཤད་པ་ལ་གཉིས་ལས།

Enumeration Block 20:
བརྒྱད་པ་རས་ཆེན་གྱི་སྤང་བ་བཤད་པ་ལ་གཉིས་ལས།

Enumeration Block 21:
དགུ་པ་བསྔོས་པ་གཞན་དུ་བསྒྱུར་བའི་སྤང་བ་བཤད་པ་ལ་གཉིས་ལས།

Enumeration Block 22:
བཅུ་པ་གསོག་འཇོག་གི་སྤང་བ་བཤད་པ་ལ་གཉིས་ལས།
