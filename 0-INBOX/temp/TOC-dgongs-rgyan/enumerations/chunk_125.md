Enumeration Block 1:
གཉིས་པ་སྤོ་བ་སྤྱོད་པ་འདི་ལ། ཡུལ་གང་ལ་སྤྱད་པ། གནས་གང་དུ་སྤྱད་པ། རྟེན་གང་གིས་སྤྱད་པ། དོན་གང་གི་ཕྱིར་སྤྱད་པ། ཡུན་ཇི་ཙམ་སྤྱད་པ། ཚུལ་ཇི་ལྟར་སྤྱད་པ། སྤོ་བ་སྤྱད་པའི་དགོས་པ་བཤད་པ་དང་བདུན་ལས།

Enumeration Block 2:
དམན་སྤྱོད་ལྔ་པོ་གང་ཞེ་ན། འདི་ལ་ནང་པར་གྱི་དུས་སུ་ཇི་ལྟར་བསྒྲུབ་པ་དང་། ཆོས་སྟོན་ལ་སོགས་པའི་དུས་སུ་ཇི་ལྟར་བསྒྲུབ་པ། དགེ་འདུན་འདུ་བའི་དུས་སུ་ཇི་ལྟར་བསྒྲུབ་པ། དུས་ཐམས་ཅད་དུ་ཇི་ལྟར་བསྒྲུབ་པ། དགོངས་ཀའི་དུས་སུ་ཇི་ལྟར་བསྒྲུབ་པའི་ཚུལ་དང་ལྔ་ཡོད་པ་ལས།

Enumeration Block 3:
གཉིས་པ་ལྟུང་བ་དངོས་བཤགས་པ་ལ། དགོས་པ་སྤྱིར་བཤད་པ་དང་། བསྡུས་དོན་སོ་སོར་བཤད་པ་གཉིས་ལས།

Enumeration Block 4:
གཉིས་པ་ལ་རྩ་ལྟུང་གི་བཤགས་ཚུལ་དང་། ལྷག་མའི་བཤགས་ཚུལ་དང་། དེ་གཉིས་ལས་གཞན་པའི་ལྟུང་བའི་བཤགས་ཚུལ་དང་གསུམ། དང་པོ་ལ། ཆད་པའི་ལས་ཀྱི་བསླབ་པ་ནོད་པའི་ཚུལ་དང་། ཆད་པའི་ལས་ཀྱི་བསླབ་པ་ལ་སྤྱོད་པའི་ཚུལ་དང་གཉིས་ལས།

Enumeration Block 5:
དེ་ལྟར་ན་འདི་ཡུལ་གང་ལས་ནོད་པ་དང་། རྟེན་གང་གིས་ནོད་པ། དགོས་པ་གང་གི་ཕྱིར་ནོད་པ། ཡུན་ཇི་ཙམ་ཞིག་ནོད་པ། ཆོ་ག་གང་གིས་ནོད་པ། སྒྲ་བཤད་པ། ལྟུང་བ་བཤགས་པའི་དགོས་པ་བཤད་པ་དང་བདུན་ལས།

Enumeration Block 6:
གཉིས་པ་བསླབ་པ་སྤྱོད་པའི་ཚུལ་ལ། བསླབ་པ་དེ་ཡུལ་གང་ལ་སྤྱད་པ། རྟེན་གང་གིས་སྤྱད་པ། ཚུལ་ཇི་ལྟར་སྤྱད་པ། གནས་གང་དུ་སྤྱད་པ། དོན་གང་གི་ཕྱིར་སྤྱད་པ། ཡུན་ཇི་ཙམ་སྤྱད་པ་དང་དྲུག་ལས།

Enumeration Block 7:
གཉིས་པ་ལྷག་མའི་ལྟུང་བ་བཤགས་ཚུལ་ལ། མགུ་བའི་སྒོ་ནས་ཕྱིར་བཅོས་པ་དང་། དབྱུང་བའི་སྒོ་ནས་ཕྱིར་བཅོས་པ་དང་གཉིས། དང་པོ་ལ། མགུ་བ་ནོད་པ་དང་། མགུ་བ་སྤྱད་པའི་ཚུལ་གཉིས། དང་པོ་ལ། ཡུལ་གང་ལས་ནོད་པ། རྟེན་གང་གིས་ནོད་པ། དོན་གང་གི་ཆེད་དུ་ནོད་པ། ཡུན་ཇི་ཙམ་ནོད་པ། ཆོ་ག་གང་གིས་ནོད་པ། སྒྲ་དོན་བཤད་པ། ནོད་པའི་དགོས་པ་བཤད་པ་དང་བདུན་ལས།
