Enumeration Block 1:
དྲུག་པ། ཤན་བརྡེག་པའི་ཚུལ་ལ། ཞག་ཤན་བརྡེག་པའི་ཚུལ་དང་། ལྟུང་ཤན་བརྡེག་པའི་ཚུལ་དང་གཉིས། དང་པོ་ལ། གོས་ཤན་བརྡེག་པའི་ཚུལ། ལྷུང་བཟེད་ཀྱི་ཤན་བརྡེག་པའི་ཚུལ་དང་། སྨན་ཤན་བརྡེག་པའི་ཚུལ་དང་གསུམ། དང་པོ་ལ། ཞག་བཅུའི་གོས་ཤན་བརྡག་པའི་ཚུལ་དང་། ཟླ་འཇོག་གི་གོས་ཤན་བརྡེག་པའི་ཚུལ་གཉིས། དང་པོ་ལ། ཞག་བཅུའི་གོས་ཤན་ཁྱད་པར་ཅན་མ་ཡིན་པའི་དེ་དང་། ཞག་བཅུའི་ཁྱད་པར་ཅན་གྱི་དེ་གཉིས་ཡོད།
Enumeration Block 2:
དེའི་ཚུལ་ལ། གོས་སྔ་མས་ཕྱི་མ་ལ་ཤན་བརྡེག་པའི་ཚུལ་དང་། དུས་མཉམ་པའི་དུས་མཉམ་པ་ལ་ཤན་བརྡེག་པའི་ཚུལ་གཉིས།
Enumeration Block 3:
གཉིས་པ། ཟླ་འཇོག་གི་གོས་ཤན་བརྡེག་པའི་ཚུལ་ལ། ཁྱད་པར་ཅན་མ་ཡིན་པའི་དེ་དང་། ཁྱད་པར་ཅན་གྱི་ཟླ་འཇོག་གི་གོས་ཤན་བརྡེག་པའི་ཚུལ་གཉིས།
Enumeration Block 4:
དེ་ལ་དུས་མི་མཉམ་པས་དུས་མི་མཉམ་པ་ལ་ཤན་བརྡེག་པའི་ཚུལ་དང་། དུས་མཉམ་པས་དུས་མཉམ་པ་ལ་ཤན་བརྡེག་པའི་ཚུལ་གཉིས།
Enumeration Block 5:
གཉིས་པ་ལྷུང་བཟེད་ཀྱི་ཤན་བརྡེག་པའི་ཚུལ་ལ། ཁྱད་པར་ཅན་གྱི་དེ་དང་ཁྱད་པར་ཅན་མ་ཡིན་པའི་དེ་དང་། གཉིས་ཡང་། དང་པོ་ལ་ཡང་དུས་མཉམ་པ་དང་། མི་མཉམ་པའི་ཤན་བརྡག་ཚུལ་གཉིས་ཡོད་ཅིང་།
Enumeration Block 6:
༈ གསུམ་པ་སྨན་ཤན་བརྡེག་པའི་ཚུལ་ལ་ཞག་བདུན་པའི་དེ་དང་། ཐུན་ཚོད་དུ་རུང་བའི་དེ་དང་། ཇི་སྲིད་འཚོ་བཅང་གི་དེ་དང་གསུམ། དང་པོ་ལ་ཁྱད་པར་ཅན་གྱི་སྨན་ཞག་བདུན་པའི་ཤན་བརྡེག་པའི་ཚུལ་དང་། ཁྱད་པར་ཅན་མ་ཡིན་པའི་དེ་བརྡེག་པའི་ཚུལ་གཉིས། དང་པོ་ལ་ཡང་དུས་མཉམ་པ་དང་། མི་མཉམ་པའི་ཤན་བརྡེག་པའི་ཚུལ་གཉིས།
Enumeration Block 7:
གཉིས་པ་ལ་དུས་མཉམ་པ་དང་དུས་མི་མཉམ་པའི་ཤན་བརྡེག་པའི་ཚུལ་གཉིས།
Enumeration Block 8:
གསུམ་པ་ལ། ནད་ཇི་སྲིད་འཚོ་བཅང་གི་སྨན་གྱིས་ཤན་བརྡེག་པའི་ཚུལ་དེ་ལ། ཁྱད་པར་ཅན་གྱི་དེ་དང་། ཁྱད་པར་ཅན་མ་ཡིན་པའི་དེ་གཉིས། དང་པོ་ལ། དུས་མཉམ་པའི་དེ་དང་། དུས་མི་མཉམ་པའི་དེ་གཉིས།
Enumeration Block 9:
བདུན་པ་ལ་གོས་ཀྱི་རིགས་ངོས་བཟུང་བ་དང་། མུ་བཞིར་བརྩི་བའི་ཚུལ་དངོས་གཉིས། དང་པོ་ལ་ཞག་བཅུ་འཆང་སྤང་གི་གོས་ཀྱི་རིགས་ངོས་བཟུང་བ། ཟླ་འཇོག་གི་སྤང་བའི་གོས་ཀྱི་རིགས་ངོས་བཟུང་བ་གཉིས།
Enumeration Block 10:
གཉིས་པ་ལ་བཞི་ལས།
