Enumeration Block 1:
གཉིས་པ་ལ། བཅུ་ཡོད་པའི་དང་པོ་རྐུན་མ་དང་ལྷན་ཅིག་ལམ་དུ་འགྲོ་བའི་ལྟུང་བྱེད་ལ་གསུམ་ལས།

Enumeration Block 2:
གཉིས་པ་ལོ་ཉི་ཤུ་མ་ལོན་པར་བསྙེན་པར་རྫོགས་པར་བྱེད་པའི་ལྟུང་བྱེད་ལ་གསུམ་ལས།

Enumeration Block 3:
གསུམ་པ་ས་རྐོ་བའི་ལྟུང་བྱེད་ལ་གསུམ་ལས།

Enumeration Block 4:
བཞི་པ་མགྲོན་དུ་གཉེར་བ་ལས་རིང་དུ་འདུག་པའི་ལྟུང་བྱེད་ལ་གསུམ་ལས།

Enumeration Block 5:
ལྔ་པ་བསླབ་པ་ལ་ཉེ་བར་འཇོག་པ་སྤོང་བའི་ལྟུང་བྱེད་ལ་གསུམ་ལས།

Enumeration Block 6:
དྲུག་པ་ཉན་རྣ་བྱེད་ཏྤའི་ལྟུང་བྱེད་ལ་གསུམ་ལས།

Enumeration Block 7:
བདུན་པ་ལས་གྲལ་ནས་མ་སྨྲས་པར་འགྲོ་བའི་ལྟུང་བྱེད་ལ་གསུམ་ལས།

Enumeration Block 8:
བརྒྱད་པ་མ་གུས་པའི་ཚུལ་གྱི་ལྟུང་བྱེད་ལ་གསུམ་ལས།

Enumeration Block 9:
དགུ་པ་མྱོས་འགྱུར་འཐུང་བའི་ལྟུང་བྱེད་ལ་གསུམ་ལས།

Enumeration Block 10:
བཅུ་པ་དུས་མིན་པར་གྲོང་དུ་འགྲོ་བའི་ལྟུང་བྱེད་ལ་གསུམ་ལས།

Enumeration Block 11:
བཅུ་ཚན་དགུ་པ་བཤད་པ་ལ། སྡོམ་གྱིས་བསྡུས་པའི་ཚུལ་དང་། དེའི་དོན་བཤད་པ་གཉིས།

Enumeration Block 12:
གཉིས་པ་ལ་བཅུ་ཡོད་པའི་དང་པོ་གྲོང་དུ་རྒྱུ་བའི་ལྟུང་བྱེད་ལ། སྔ་དྲོ་གྲོང་དུ་རྒྱུ་བའི་ལྟུང་བྱེད་དང་། ཕྱི་དྲོ་གྲོང་དུ་རྒྱུ་བའི་ལྟུང་བྱེད་གཉིས།

Enumeration Block 13:
གཉིས་པ་ཕྱི་དྲོ་གྲོང་དུ་རྒྱུ་བ་ལ་གསུམ་ལས།

Enumeration Block 14:
རྩ་བའི་གཉིས་པ། རྒྱལ་པོའི་ཕོ་བྲང་དུ་ནུབ་མོ་འགྲོ་བའི་ལྟུང་བྱེད་ལ་གསུམ་ལས།

Enumeration Block 15:
གསུམ་པ་ཁྱད་དུ་གསོད་པའི་ལྟུང་བྱེད་ལ་གསུམ་ལས།

Enumeration Block 16:
བཞི་པ་ཁབ་རལ་འཆོས་པའི་ལྟུང་བྱེད་ལ་གསུམ་ལས།

Enumeration Block 17:
ལྔ་པ་ཁྲི་རྐང་འཆོས་པའི་ལྟུང་བྱེད་ལ་གསུམ་ལས།
