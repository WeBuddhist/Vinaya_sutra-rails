Enumeration Block 1:
༈ རྩ་བའི་གཉིས་པ༑ རང་གཞན་གྱི་ལྟུང་བ་ཕྱིར་འཆོས་པའི་ཚུལ་ལ། རང་གི་ལྟུང་བ་ཕྱིར་འཆོས་པའི་ཚུལ་དང་། གཞན་གྱི་ལྟུང་བ་ཕྱིར་འཆོས་པའི་ཚུལ་དང་། རང་གཞན་གཉིས་ཀའི་དེ་ཕྱིར་འཆོས་པའི་ཚུལ་དང་གསུམ་ལས།

Enumeration Block 2:
གཉིས་པ་དངོས་གཞི་ལ། བསྙེན་པར་མ་རྫོགས་པའི་གསོ་སྦྱོང་དང་། དེ་རྫོགས་པའི་དེ་གཉིས།

Enumeration Block 3:
གཉིས་པ་ལ། སྤྱིར་བཏང་དང་དམིགས་བསལ་གཉིས་ལས།

Enumeration Block 4:
གཉིས་པ་དམིགས་བསལ་ལ། ཡོངས་རྫོགས་ཀྱི་གསོ་སྦྱོང་གི་དེ། བྱིན་གྱིས་བརླབས་པའི་གསོ་སྦྱོང་། མདོར་བསྡུས་པའི་གསོ་སྦྱོང་། དགག་དབྱེའི་གསོ་སྦྱོང་། དགེ་སློང་མའི་གསོ་སྦྱོང་དང་ལྔ་ཡོད་པ་ལས།

Enumeration Block 5:
ཆོ་ག་ལ་སྦྱོར་དངོས་གཉིས་ལས།
