Enumeration Block 1:
བཞི་པ་ལ་བཞི་ལས།

Enumeration Block 2:
འདིའི་སྐབས་སུ། བསྒོ་གྱུར་གྱི་ལྷག་མའི་ལྟུང་བ་བཤད་པ་ལ། དབྱེ་བ༑ བསྡུ་བ། ངོ་བོ། 

ཐུན་མོང་གི་ཡན་ལག་བཤད་པ་དང་བཞི་ལས།

Enumeration Block 3:
དེ་ལ་དབྱེ་ན། སྦྱོར་ལྟུང་དུ་གྱུར་པའི་བསྒོ་གྱུར་གྱི་ལྟུང་བ་དང་། དངོས་གཞིའི་ལྟུང་བར་གྱུར་པའི་བསྒྲོ་གྱུར་གྱི་ལྟུང་བ་གཉིས་ཡོད་དོ། །

Enumeration Block 4:
བཞི་པ་ཐུན་མོང་གི་ཡན་ལག་བཤད་པ་ལ། དེ་དངོས་བཤད་པ་དང་། ལྟུང་བ་གྲངས་དུ་བསྐྱེད་བཤད་པ། བསྒོ་གྱུར་གྱི་ལྟུང་བའི་ཐོག་མ་བཤད་པ། དེའི་དངོས་གཞི་བསྐྱེད་པའི་དུས་མཚམས་བཤད་པ་དང་བཞི་ལས།

Enumeration Block 5:
དེས་ན་བསྒོ་གྱུར་གྱི་ལྟུང་བ་འདི་ལ། ཁྱབ་པ། ངོ་བོ། 

སེལ་བ། ཅི་འགྱུར་བཤད་པ་དང་བཞི། དང་པོ་ལ། དངོས་ཁྱབ་དང་། ཤུགས་ཁྱབ་གཉིས་ལས།

Enumeration Block 6:
བཞི་པ་ཅིར་འགྱུར་ལ། ངོ་བོ་ལ་ཅིར་འགྱུར་དང་། སེལ་བ་ལ་ཅིར་འགྱུར་གཉིས་ལས།
