Enumeration Block 1:
བཅུ་པ་ཚ་བའི་དུས་ཞེས་པ་ཁྲུས་བྱེད་པའི་ལྟུང་བྱེད་ལ་གསུམ་ལས།
Enumeration Block 2:
བཅུ་ཚན་བདུན་པ་འཆད་པ་ལ། སྡོམ་གྱིས་བསྡུས་པའི་ཚུལ་དང་། དེའི་དོན་བཤད་པ་གཉིས་ལས།
Enumeration Block 3:
གཉིས་པ་ལ། བཅུ་ཡོད་པའི་དང་པོ་དུད་འགྲོ་གསོད་པའི་ལྟུང་བྱེད་ལ་གསུམ་ལས།
Enumeration Block 4:
གཉིས་པ་འགྱོད་པ་བསྐྱེད་པའི་ལྟུང་བྱེད་ལ་གསུམ་ལས།
Enumeration Block 5:
གསུམ་པ་ག་ག་ཚིལ་བྱེད་པའི་ལྟུང་བྱེད་ལ་གསུམ་ལས།
Enumeration Block 6:
བཞི་པ་ཆུ་ལ་རྩེ་བའི་ལྟུང་བྱེད་ལ་གསུམ་ལས།
Enumeration Block 7:
ལྔ་པ་བུད་མེད་དང་ལྷན་ཅིག་ཉལ་བའི་ལྟུང་བྱེད་ལ་གསུམ་ལས།
Enumeration Block 8:
དྲུག་པ་དངངས་པར་བྱེད་པའི་ལྟུང་བྱེད་ལ་གསུམ་ལས།
Enumeration Block 9:
བདུན་པ་སྦེད་པར་བྱེད་པའི་ལྟུང་བྱེད་ལ་གསུམ་ལས།
Enumeration Block 10:
བརྒྱད་པ་གདེངས་མེད་པར་སྤྱོད་པའི་ལྟུང་བྱེད་ལ་གསུམ་ལས།
Enumeration Block 11:
དགུ་པ་ལྷག་མས་སྐུར་པ་འདེབས་པའི་ལྟུང་བྱེད་ལ་གསུམ་ལས།
Enumeration Block 12:
བཅུ་པ་བུད་མེད་དང་ལྷན་ཅིག་ལམ་དུ་འགྲོ་བའི་ལྟུང་བྱེད་ལ་གསུམ་ལས།
Enumeration Block 13:
བཅུ་ཚན་བརྒྱད་པ་འཆད་པ་ལ། སྡོམ་གྱིས་བསྡུས་པའི་ཚུལ་དང་། དེའི་དོན་བཤད་པ་གཉིས།
Enumeration Block 14:
གཉིས་པ་ལ། བཅུ་ཡོད་པའི་དང་པོ་རྐུན་མ་དང་ལྷན་ཅིག་ལམ་དུ་འགྲོ་བའི་ལྟུང་བྱེད་ལ་གསུམ་ལས།
Enumeration Block 15:
གཉིས་པ་ལོ་ཉི་ཤུ་མ་ལོན་པར་བསྙེན་པར་རྫོགས་པར་བྱེད་པའི་ལྟུང་བྱེད་ལ་གསུམ་ལས།
Enumeration Block 16:
གསུམ་པ་ས་རྐོ་བའི་ལྟུང་བྱེད་ལ་གསུམ་ལས།
Enumeration Block 17:
བཞི་པ་མགྲོན་དུ་གཉེར་བ་ལས་རིང་དུ་འདུག་པའི་ལྟུང་བྱེད་ལ་གསུམ་ལས།
