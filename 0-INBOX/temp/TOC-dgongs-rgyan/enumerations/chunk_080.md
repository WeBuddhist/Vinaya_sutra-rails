Enumeration Block 1:
བཅུ་ཚན་ལྔ་པ་འཆད་པ་ལ། སྡོམ་གྱིས་བསྡུས་པའི་ཚུལ་དང་། དེའི་དོན་བཤད་པ་གཉིས།
Enumeration Block 2:
གཉིས་པ་ནི་དེ་ལ་བཅུ་ཡོད་པའི་དང་པོ་སྲོག་ཆགས་དང་བཅས་པའི་ཆུ་ལ་ལོངས་སྤྱོད་པའི་ལྟུང་བྱེད་ལ་གསུམ་ལས།
Enumeration Block 3:
གཉིས་པ་ཉལ་པོ་བྱེད་པར་གཤོམ་པའི་ཁྱིམ་ན་འདུག་པའི་ལྟུང་བྱེད་ལ་གསུམ་ལས།
Enumeration Block 4:
གསུམ་པ་ནི། ཉལ་པོ་བྱེད་པར་གཤོམ་པའི་ཁྱིམ་ན་འགྲེང་བའི་ལྟུང་བྱེད་ལ་གསུམ་ལས།
Enumeration Block 5:
བཞི་པ་ནི། གཅེས་བུ་ལ་ཟས་བྱིན་པའི་ལྟུང་བྱེད་ལ་གསུམ་ལས།
Enumeration Block 6:
ལྔ་པ་དམག་ལ་ལྟ་བའི་ལྟུང་བྱེད་ལ་གསུམ་ལས།
Enumeration Block 7:
དྲུག་པ་དམག་ནང་དུ་གནས་པའི་ལྟུང་བྱེད་ལ་གསུམ་ལས།
Enumeration Block 8:
བདུན་པ་དཔུང་གི་ཡན་ལག་ཉམས་སུ་མྱོང་བའི་ལྟུང་བྱེད་ལ་གསུམ་ལས།
Enumeration Block 9:
གསུམ་པ་ནི་དཔུང་གི་ཡན་ལག་ཉམས་སུ་མྱོང་བའི་ལྟུང་བྱེད་འདི་ལ། དམག་ལ་རེག་པ་དང་། བཤམས་པ་དཀྲུགས་པ་དང་དམག་ལ་ལྟ་བའི་ལྟུང་བྱེད་དང་གསུམ་ལས།
Enumeration Block 10:
བརྒྱད་པ་བརྡེག་པའི་ལྟུང་བྱེད་ལ་གསུམ་ལས།
Enumeration Block 11:
དགུ་པ་བརྡེག་པར་གཟས་པའི་ལྟུང་བྱེད་ལ་གསུམ་ལས།
Enumeration Block 12:
བཅུ་པ་གནས་ངན་ལེན་འཆབ་པའི་ལྟུང་བྱེད་ལ་གསུམ་ལས།
Enumeration Block 13:
བཅུ་ཚན་དྲུག་པ་འཆད་པ་ལ། སྡོམ་གྱིས་བསྡུས་པའི་ཚུལ་དང་། དེའི་དོན་བཤད་པ་གཉིས།
Enumeration Block 14:
གཉིས་པ་ལ་བཅུ་ཡོད་པའི་ནང་ནས། དང་པོ་ཟས་གཅོད་པའི་ལྟུང་བྱེད་ལ་གསུམ་ལས།
Enumeration Block 15:
གཉིས་པ་མེ་རེག་གི་ལྟུང་བྱེད་ལ་གསུམ་ལས།
Enumeration Block 16:
གསུམ་པ་ལ། དངོས་དང་དུས་དྲན་བྱེད་ཚུལ་བཤད་པ་གཉིས།
Enumeration Block 17:
གཉིས་པ་དུས་དྲན་བྱེད་ཚུལ་ལ། དུས་དྲན་གང་ལ་བྱ་བའི་གཞི། གང་གིས་བྱེད་པའི་རྟེན། ནམ་གྱི་ཚེ་བྱ་བ། ཇི་ཙམ་བྱ་བ། དུས་དྲན་རང་གི་ངོ་བོ། བྱས་པའི་དགོས་པ། དུས་དྲན་འཇིག་པའི་ཚུལ་བཤད་པ་དང་བདུན།
