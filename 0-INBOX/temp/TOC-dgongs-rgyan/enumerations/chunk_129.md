Enumeration Block 1:
བདུན་པ་ནི། སྤྱིར་ཉེས་པ་གླེང་བའི་སྐབས་ཕྱེ་ཞིག་ཅེས་སྐབས་འབྱེད་དུ་བཅུག་པ་ན། ཉེས་པ་གླེང་སྐབས་མི་འབྱེད་པ་དང་། འབྱེད་པའི་རིགས་གཉིས་ཡོད། དང་པོ་དེ་ལ་ཡང་ཉེས་པ་མཐའ་དག་ལ་སྐབས་མི་འབྱེད་པ་དང་། ཕྱོགས་གཅིག་ལ་སྐབས་མི་འབྱེད་པ་གཉིས་ཡོད་པའི་ཕྱིར།
Enumeration Block 2:
གཉིས་པ་སྐབས་འབྱེད་པ་ལ། མི་མཉེན་པར་འབྱེད་པ་དང་། མཉེན་པར་འབྱེད་པ་གཉིས་ལས།
Enumeration Block 3:
གཉིས་པ་ལྟུང་བ་ཁས་བླངས་ནས་མཉེན་པར་འབྱེད་པ་དེ་ལ་ཡང་དེར་གྱུར་བའི་ཕྱིར་བཅོས་མི་བྱེད་པ་དང་། བྱེད་པ་གཉིས་ལས།
Enumeration Block 4:
ཡང་སྐབས་མཉེན་པར་ཕྱེ་ནས་ལྟུང་བ་གླེངས་པ་ན། ལྟུང་བ་ཁས་མི་ལེན་པ་དང་། ལེན་པ་གཉིས་ལས།
Enumeration Block 5:
དགེ་འདུན་ཐ་དད་པ་ཉིད་དུ་ནུས་པ་ལ་མི་འདོད་པར་གླེང་བ་དང་གླེང་བར་བྱེད་པ་ན་ལོག་པར་མི་བྱའོ། །ཞེས་པའི་སྐབས་སུ་འབྲེལ་བ་ཅན་གྱི་གཞུང་དོན་སྤྱིར་བསྟན་པ་ལ། ལས་ཀྱི་དབྱེན་གྱི་རྣམ་གཞག་འཆད་པ་འདི་ལ། གཞི། བསམ་པ། སྦྱོར་བ། མཐར་ཐུག་གི་ཡན་ལག་དང་བཞི། དང་པོ་ལ། གང་དུ་དབྱེ་བའི་གནས། གང་འབྱེད་པའི་ཡུལ། གང་གིས་འབྱེད་པའི་རྟེན་བཤད་པ་དང་གསུམ། དང་པོ་ལ། གླེང་བཞི་དང་། གང་དུ་འབྱེད་པའི་གནས་བཤད་པ་དངོས་གཉིས་ལས།
Enumeration Block 6:
གཉིས་པ་བསམ་པའི་ཡན་ལག་ལ་གཉིས་ལས།
Enumeration Block 7:
དེས་ན་ལས་ཀྱི་དབྱེན་འབྱུང་བའི་རྒྱུ་སྤོང་བ་དང་། དེ་མི་འབྱུང་བའི་ཐབས་བསྟེན་པ་གཉིས་ལས།
