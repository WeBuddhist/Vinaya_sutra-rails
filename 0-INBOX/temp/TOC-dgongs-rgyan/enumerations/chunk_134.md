Enumeration Block 1:
འགྱེད་པ་གཉིས་རང་གིས་མི་ནུས་ན། ཚོགས་པར་དབྱུང་བ་དག་གིས་ལེགས་པར་སྒྲུབ་བོ། །ཞེས་སོགས་ཀྱི་སྐབས་སུ། གཟུ་བོ་བསྐོ་བའི་ཚུལ་བཤད་པ་ལ། བཤད་བྱའི་ལུང་འགོད་པ་དང་། ལུང་གི་དོན་བཤད་པ་དང་། གཟུ་བོའི་རྣམ་གཞག་དངོས་བཤད་པ་དང་གསུམ་ལས།

Enumeration Block 2:
ཆོ་ག་ལ་གསུམ་ལས་སྦྱོར་བ་འདུ་བའི་སྐབས་བསྒྲུབ་པ་དང་། སྤྲོ་བ་དྲི་བ། དངོས་གཞི་གསོལ་གཉིས་ཀྱི་ལས་བྱ་བ། མཇུག་ཆོག་ནི་མཇུག་སྡུད་བརྗོད་པའོ༎

Enumeration Block 3:
༈ ཆེས་མང་བའི་བློས་ལེགས་པར་བཞག་པ་ནི། ལེགས་པར་བསྒྲུབ་པའི་རྣམ་པ་གཞན་ཡིན་ནོ། ཞེས་པར། གང་མང་ཞི་བྱེད་ཀྱི་རྣམ་གཞག་བཤད་པ་ལ། གཞི་གང་ལ་བྱ་བ་དང་། བྱེད་པ་པོ་གང་གིས་བྱ་བ། ཚུལ་ཇི་ལྟར་བྱ་བ་དང་གསུམ་ལས།

Enumeration Block 4:
རྩ་བའི་གསུམ་པ། ཚུལ་ཇི་ལྟར་བྱ་བ་ལ། སྦྱོར་བ་དང་། དངོས་གཞི་གཉིས་དང་པོ་ལ། ཚུལ་ཤིང་འབྲིམ་པ་པོ་བསྐོས་ནས་དེས་དགེ་འདུན་ལ་འདུ་བར་གསོལ་བ་དང་། འདུ་བའི་སྐབས་རྗེས་སུ་སྒྲུབ་པ་གཉིས་ལས།

Enumeration Block 5:
༈ སོ་སོ་ཐར་པའི་སྡོམ་པའི་མཆོག་ལ་རབ་ཏུ་བྱུང་བས་ཕྱག་བྱའོ། 

ཞེས་པ་དང་། གཙུག་ལག་ཁང་བྱའོ། །ཞེས་སོགས་ཀྱི་སྐབས་སུ། སྤྱི་དོན་དང་། ངག་དོན་གཉིས་ལས། དང་པོ་ལ། དགོས་དོན་དང་། བསྡུས་དོན་གཉིས།

Enumeration Block 6:
གཉིས་པ་ལ། ཡུལ་གང་ལ་ཕྱག་བྱ་བ། གང་ཟག་གང་གིས་ཕྱག་བྱ་བ། ཚུལ་ཇི་ལྟར་ཕྱག་བྱ་བ་སོགས་དུ་མ་ཡོད་པ་ལས།
