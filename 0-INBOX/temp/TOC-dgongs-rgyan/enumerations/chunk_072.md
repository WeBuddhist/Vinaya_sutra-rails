Enumeration Block 1:
གཉིས་པ། བདག་འབྲལ་གྱི་ལྟུང་བ་བཤད་པ་ལ། བདག་འབྲེལ་གྱི་ལྟུང་བས་ལྟུང་བ་དུ་ལ་ཁྱད་པའི་ཚུལ། བདག་འབྲེལ་གྱི་ལྟུང་བའི་ཐུ་མོང་གི་ཡན་ལག་གི་ངོ་བོ། 

སེལ་བ་ལ་ཅི་འགྱུར་བཤད་པ་དང་གསུམ།
Enumeration Block 2:
གསུམ་པ། ཤན་འབྲེལ་གྱི་ལྟུང་བ་བཤད་པ་ལ། སྤྱི་དོན་གཞུང་དོན་གཉིས། དང་པོ་ལ། དགོས་དོན་དང་། བསྡུས་དོན་གཉིས།
Enumeration Block 3:
གཉིས་པ། བསྡུས་དོན་ལ། ཤན་འབྱུང་བའི་གཞི། དབྱེ་བ། བསྡུ་བ། ངོ་བོ། 

ཤན་འབྲེལ་བའི་དུས། ཤན་བརྡེག་པའི་ཚུལ། མཐའ་དཔྱད་དེ་མུ་བཞིར་རྩི་བའི་ཚུལ་དང་བདུན། དང་པོ་ལ། ཞག་ཤན་འབྱུང་བའི་གཞི་དང་། སྤང་ཤན་འབྱུང་བའི་གཞི་གཉིས་ལས།
Enumeration Block 4:
གཉིས་པ་ནི། ཤན་ལ་དབྱེ་ན། གོས་ཤན། ལྷུང་བཟེད་ཀྱི་ཤན། སྨན་ཤན། ལྟུང་ཤན་དང་བཞི་ཡོད། 

དང་པོ་ལ། ཞག་བཅུའི་གོས་ཤན་དང་། ཟླ་འཇོག་གི་གོས་ཤན་གཉིས་ཡོད།
Enumeration Block 5:
དེ་ཡང་ཞག་ཤན་གྱི་ངོ་བོ་རྣམ་གྲངས་དང་བཅས་པ་བཤད་པ་དང་། ལྟུང་ཤན་གྱི་ངོ་བོ་རྣམ་གྲངས་དང་བཅས་པ་བཤད་པ་གཉིས།
Enumeration Block 6:
དྲུག་པ། ཤན་བརྡེག་པའི་ཚུལ་ལ། ཞག་ཤན་བརྡེག་པའི་ཚུལ་དང་། ལྟུང་ཤན་བརྡེག་པའི་ཚུལ་དང་གཉིས། དང་པོ་ལ། གོས་ཤན་བརྡེག་པའི་ཚུལ། ལྷུང་བཟེད་ཀྱི་ཤན་བརྡེག་པའི་ཚུལ་དང་། སྨན་ཤན་བརྡེག་པའི་ཚུལ་དང་གསུམ། དང་པོ་ལ། ཞག་བཅུའི་གོས་ཤན་བརྡག་པའི་ཚུལ་དང་། ཟླ་འཇོག་གི་གོས་ཤན་བརྡེག་པའི་ཚུལ་གཉིས། དང་པོ་ལ། ཞག་བཅུའི་གོས་ཤན་ཁྱད་པར་ཅན་མ་ཡིན་པའི་དེ་དང་། ཞག་བཅུའི་ཁྱད་པར་ཅན་གྱི་དེ་གཉིས་ཡོད།
Enumeration Block 7:
དེའི་ཚུལ་ལ། གོས་སྔ་མས་ཕྱི་མ་ལ་ཤན་བརྡེག་པའི་ཚུལ་དང་། དུས་མཉམ་པའི་དུས་མཉམ་པ་ལ་ཤན་བརྡེག་པའི་ཚུལ་གཉིས།
