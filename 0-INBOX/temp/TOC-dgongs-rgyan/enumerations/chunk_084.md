Enumeration Block 2:
བཞི་པ་ཁབ་རལ་འཆོས་པའི་ལྟུང་བྱེད་ལ་གསུམ་ལས།

Enumeration Block 3:
ལྔ་པ་ཁྲི་རྐང་འཆོས་པའི་ལྟུང་བྱེད་ལ་གསུམ་ལས།

Enumeration Block 4:
དྲུག་པ་ཤིང་བལ་གྱིས་གོས་པར་བྱས་པའི་ལྟུང་བྱེད་ལ་གསུམ་ལས།

Enumeration Block 5:
བདུན་པ་གདིང་བ་ཚད་ལས་ལྷག་པ་བཟོས་པའི་ལྟུང་བྱེད་དང་། བརྒྱད་པ་གཡན་པ་དགབ་པ་ཚད་ལས་ལྷག་པ་བྱེད་པའི་ལྟུང་བྱེད་དང་། དགུ་པ་དབྱར་གྱི་གོས་རས་ཆེན་ཚད་ལས་ལྷག་པ་བཟོས་པའི་ལྟུང་བྱེད་དང་གསུམ་ལས། དང་པོ་ལ་སྔར་ལྟར་གསུམ་ལས།

Enumeration Block 6:
བཅུ་པ་བདེ་བར་གཤེགས་པའི་ཆོས་གོས་ཀྱི་ཚད་ལས་ལྷག་པའི་བཟོ་བྱས་པའི་ལྟུང་བྱེད་ལས་གསུམ་ལས།

Enumeration Block 7:
༈ བཞི་པ་སོར་བཤགས་ཀྱི་སྡེ་བཤད་པ་ལ་སྡོམ་གྱིས་བསྡུས་པའི་ཚུལ་དང་། དེའི་དོན་བཤད་པ་གཉིས།

Enumeration Block 8:
གཉིས་པ་ལ། བཞི་ཡོད་པ་ལས། དང་པོ་དགེ་སློང་མ་ལ་ཟས་ལན་པའི་སོར་བཤགས་ལ་གསུམ་ལས།

Enumeration Block 9:
གཉིས་པ་ཁྱིམ་གཞན་དུ་བསྐོ་བཤམ་ཕྱིན་ཅི་ལོག་བྱེད་པ་མ་ལྡོག་པའི་སོར་བཤགས་ལ་གསུམ་ལས།

Enumeration Block 10:
གསུམ་པ་བསླབ་པ་བྲལ་ཏེ་ཁྱིམ་དུ་འཇུག་པའི་སོར་བཤགས་ལ་གསུམ་ལས་

Enumeration Block 11:
བཞི་པ་ནགས་མ་བརྟགས་པ་ལས་བྱུང་བའི་སོར་བཤགས་ལ་གསུམ་ལས།

Enumeration Block 12:
༈ ལྔ་པ་ཉེས་བྱས་ཀྱི་སྡེ་ཚན་བཤད་པ་ལ། གོས་བགོ་བའི་སྡེ་ཚན། ཁྱིམ་དུ་འགྲོ་བའི་སྡེ་ཚན། ཁྱིམ་དུ་འདུག་པའི་སྡེ་ཚན། ཟས་བླངས་པའི་སྡེ་ཚན། ཟས་བཟའ་བའི་སྡེ་ཚན། ལྷུང་བཟེད་ལ་སྤྱད་པའི་སྡེ་ཚན། ཆོས་ཉན་བཤད་ཀྱི་སྡེ་ཚན། སྒྲུབ་པའི་སྡེ་ཚན་དང་བརྒྱད་ཡོད་དོ། །དང་པོ་གོས་བགོ་བའི་སྡེ་ཚན་ལ། སྡོམ་གྱིས་བསྡུས་པའི་ཚུལ་དང་། དེའི་དོན་བཤད་པ་གཉིས་
