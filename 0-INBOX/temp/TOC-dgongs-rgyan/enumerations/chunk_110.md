Enumeration Block 1:
དེས་སྤྱིར་བཤད་ནས་ཡོ་བྱད་བགོ་ཚུལ་བྱེ་བྲག་དུ་བཤད་ན། ཤི་བའི་རྫས་བགོ་ཚུལ་དང་། དབྱར་རྙེད་བགོ་ཚུལ་གཉིས་ལས།
Enumeration Block 2:
འོ་ན་བྱིན་གྱིས་བརླབ་ཚུལ་ཇི་ལྟར་ཞེ་ན། འདི་ལ་གསོལ་བའི་ལས་ཀྱིས་བྱིན་གྱིས་བརླབ་ཚུལ་དང་། དང་པོ་དང་ཐ་མས་བྱིན་གྱིས་བརླབ་ཚུལ་གཉིས་ལས།
Enumeration Block 3:
གཉིས་པ་དེ་ལས་གྲུབ་པའི་གོས་ཀྱི་རྣམ་གཞག་བཤད་པ་ལ། གོས་དྲུབ་པའི་ཚུལ། གོས་ཀྱི་དབྱེ་བ། ཕྱེ་བ་སོ་སོའི་རང་བཞིན། གོས་ལ་ལོངས་སྤྱོད་པའི་ཚུལ། གོས་རུང་བ་དང་མི་རུང་བའི་ཁྱད་པར་བྱེ་བྲག་ཏུ་བཤད་པ་དང་ལྔ། དང་པོ་ལ། དྲ་བ། དྲུབ་པ། བགྲུ་བ། ཁ་བསྒྱུར་བ་དང་བཞི་ལས།
Enumeration Block 4:
གཉིས་པ་གོས་ཀྱི་དབྱེ་བ་བཤད་པ་ལ། འཚོ་བའི་ཡོ་བྱད་ཀྱི་གོས་བཤད་པ་དང་། ལྷག་པའི་ཡོ་བྱད་ཀྱི་གོས་བཤད་པ་དང་། མཁོ་བའི་ཡོ་བྱད་ཀྱི་གོས་བཤད་པ་དང་གསུམ་དང་པོ་ལ། གཙོ་ཆེ་བའི་དབང་དུ་བྱས་པ་དང་། ཕྲན་ཚེགས་ཀྱི་དབང་དུ་བྱས་པ་གཉིས།
