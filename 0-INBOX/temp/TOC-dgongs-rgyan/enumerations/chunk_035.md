Enumeration Block 1:
གཉིས་པ་འབྲེལ་བ་ཅན་གྱི་གཞུང་དོན་སྤྱིར་བསྟན་པ་ལ། གནས་བླ་མ་དང་གནས་པ་སློབ་མ་གཉིས་སོ་སོའི་ངོ་བོ་བཤད་པ་དང་། གནས་བླ་མའི་ཚུལ་ཁྲིམས་དང་། གནས་པ་སློབ་མའི་ཚུལ་ཁྲིམས་ཀྱི་རྣམ་གཞག་བཤད་པ་གཉིས། དང་པོ་ལ་གནས་བླ་མའི་མཚན་ཉིད་དང་། གནས་པ་སློབ་མའི་མཚན་ཉིད་བཤད་པ་དང་གཉིས། དང་པོ་ལ་བླ་མ་བསྟེན་པའི་ཕན་ཡོན་བཤད་པ་དང་། མ་བསྟེན་པའི་ཉེས་དམིགས་བཤད་པ། བཤེས་གཉེན་བསྟེན་པའི་ཚུལ། མཚན་ཉིད་དངོས་བཤད་པ་དང་བཞི་ལས།

Enumeration Block 2:
གཉིས་པ་ལ། གནས་བླ་མའི་ཚུལ་ཁྲིམས་ཀྱི་རྣམ་གཞག་བཤད་པ་དང་། གནས་པ་སློབ་མའི་ཚུལ་ཁྲིམས་ཀྱི་རྣམ་གཞག་བཤད་པ་དང་གཉིས། དང་པོ་ལ་བསམ་པ་གང་གིས་བསྐྱང་བ། སྦྱོར་བ་ཇི་ལྟ་བུས་སྐྱོང་བ་དང་། ཚུལ་ཇི་ལྟར་སྐྱོང་བ། སློབ་མ་གང་སྐྱོང་བ་དང་བཞི་ལས།

Enumeration Block 3:
གཉིས་པ་ལ། ཟང་ཟིང་གི་སྒོ་ནས་སྐྱོང་ཚུལ་དང་། ཆོས་ཀྱི་སྒོ་ནས་སྐྱོང་ཚུལ་གཉིས་ལས།

Enumeration Block 4:
གཉིས་པ་གནས་པ་སློབ་མའི་ཚུལ་ཁྲིམས་ཀྱི་རྣམ་གཞག་བཤད་པ་ལ། གནས་པ་སློབ་མ་དེས། གནས་བླ་མ་བསམ་པའི་སྒོ་ནས་བསྟེན་ཚུལ་དང་། སྦྱོར་བའི་སྒོ་ནས་བསྟེན་ཚུལ་གཉིས་ལས།

Enumeration Block 5:
འདི་ལ་ཐོག་མར་གནས་འཆའ་བའི་ཚུལ་དང་། གནས་བཅས་ནས་བྱ་བ་ཞུ་ཚུལ་དངོས་བཤད་པ་དང་གཉིས་ལས།

Enumeration Block 6:
གཉིས་པ་ལ། ཡུལ་གང་ལ་ཞུ་བ། གང་ཟག་གང་གིས་ཞུ་བ། དངོས་པོ་གང་ཞུ་བ། དུས་ནམ་གྱི་ཚེ་ཞུ་བ། ཚུལ་ཇི་ལྟར་ཞུ་བ། དགོས་པ་གང་གི་ཕྱིར་ཞུ་བ། དམིགས་བསལ་དང་བདུན་ལས།
