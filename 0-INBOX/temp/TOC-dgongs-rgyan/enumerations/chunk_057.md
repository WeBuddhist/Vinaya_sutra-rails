Enumeration Block 1:
དེས་ན་ཕམ་པ་དང་པོ་མི་ཚངས་སྤྱོད་ཀྱི་ཕམ་པ་བཤད་པ་ལ། བསླབ་པ་འཆའ་བའི་སྙད་ཀ་གླེང་གཞི་བཤད་པ་དང་། བསླབ་པ་འཆའ་བའི་རྒྱུ་མཚན་དགག་བྱ་ཉེས་དམིགས་བཤད་པ། ངོ་ཏི་བཤད་པ། བསླབ་པ་འཆའ་བའི་རྒྱུ་ཚོགས་ཡན་ལག་གི་རྩི་པ་རྣམ་པར་བཞག་པ་དང་བཞི་ལས།
Enumeration Block 2:
གཉིས་པ་བསླབ་པ་འཆའ་བའི་རྒྱུ་མཚན་དགག་བྱ་ཉེས་དམིགས་བཤད་པ་ལ། མཐོང་བའི་རྒྱུ་མཚན་དང་མ་མཐོང་བའི་རྒྱུ་མཚན་གཉིས་ལས།
Enumeration Block 3:
གཉིས་པ་རྒྱུ་མཐུན་གྱི་འབྲས་བུ་ལ་མྱོང་བ་རྒྱུ་མཐུན་གྱི་འབྲས་བུ་དང་། བྱེད་པ་རྒྱུ་མཐུན་གྱི་འབྲས་བུ་གཉིས་ཡོད་པ་ལས།
Enumeration Block 4:
གསུམ་པ་རྣམ་སྨིན་གྱི་འབྲས་བུ་ལ་ཆེ་འབྲིང་ཆུང་གསུམ་ལས།
Enumeration Block 5:
རྩ་བའི་བཞི་པ་ལ། གཞིའི་ཡན་ལག་བཤད་པ་དང་། བསམ་པའི་ཡན་ལག་བཤད་པ་དང་། སྦྱོར་བའི་ཡན་ལག་བཤད་པ་དང་། མཐར་ཐུག་གི་ཡན་ལག་བཤད་པ་དང་བཞི་ལས།
Enumeration Block 6:
གཉིས་པ་བསམ་པའི་ཡན་ལག་ལ་འདུ་ཤེས་དང་ཀུན་སློང་གཉིས་ལས།
