Enumeration Block 1:
དེ་ལ་དབྱེ་ན། ཚེ་ཇི་སྲིད་འཚོ་བཅང་གི་སྨན་དང་། ནད་ཇི་སྲིད་འཚོ་བཅང་གི་སྨན་གཉིས་སུ་ཡོད།
Enumeration Block 2:
ཡང་ཐུན་ཚོད་དུ་རུང་བའི་སྨན་གྱི་རིགས་སུ་གྱུར་པའི་བཏུང་བ་དེ་ལ། དུས་རུང་གི་སྨན་ལ་བརྟེན་པའི་དེ། ཞག་བདུན་པའི་སྨན་ལ་བརྟེན་པའི་དེ། ཇི་སྲིད་འཚོ་བཅང་གི་སྨན་ལ་བརྟེན་པའི་དེ་གསུམ་ཡོད།
Enumeration Block 3:
ལྔ་པ་བྱིན་གྱིས་རླབས་ཚུལ་ལ། དངོས་པོ་གང་བྱིན་གྱིས་རླབས་པ། གང་ཟག་གང་གིས་བྱིན་གྱིས་རླབས་པ། ཡུལ་གང་གི་མདུན་དུ་བྱིན་གྱིས་རླབས་པ། དུས་ནམ་གྱི་ཚེ་བྱིན་གྱིས་རླབས་པ། ཡུན་ཇི་སྲིད་དུ་བྱིན་གྱིས་རླབས་པ། ཆོ་ག་ཇི་ལྟ་བུས་བྱིན་གྱིས་རླབས་པ། དགོས་པ་གང་གི་ཕྱིར་དུ་བྱིན་གྱིས་རླབས་པ། ལོངས་སྤྱོད་པའི་ཆོ་ག་བསྟན་པ་དང་བརྒྱད་ལས།
Enumeration Block 4:
བརྒྱད་པ་ལོངས་སྤྱོད་པའི་ཆོ་ག་བཤད་པ་ལ། བྱིན་གྱིས་རླབས་པ་འོག་མ་དང་ལྷན་ཅིག་ལོངས་སྤྱོད་མི་སྤྱོད་དཔྱད་པ། འདྲེས་པ་ལ་ཆོ་ག་སྔ་མ་འཇུག་མི་འཇུག་ལ་དཔྱད་པ། བྱིན་རླབས་འཇིག་པའི་རྒྱུ་སྤང་བ་དང་གསུམ་ལས།
Enumeration Block 5:
གསུམ་པ་ལ་བྱིན་རླབས་འཇིག་པའི་རྒྱུ་སྤང་བ་ལ་དངོས་དང་། ཕོངས་པའི་དུས་ཀྱི་དམིགས་བསལ་བཤད་པ། སྨན་དེ་རྣམས་གང་ཟག་གང་གིས་བཅང་བ་དང་གསུམ་ལས།
Enumeration Block 6:
བདུན་པ་བཙོ་ཞིང་བཞག་པའི་གནས་རུང་ཁང་བཅད་པ་ལ། དགོས་དོན་དང་བསྡུས་དོན་གཉིས་ལས།
Enumeration Block 7:
གཉིས་པ་ལ། གཞི་གང་དུ་བྱིན་གྱིས་རློབ་པ། དུས་ནམ་གྱི་ཚེ་བྱིན་གྱིས་རློབ་པ། གང་ཟག་གང་གིས་བྱིན་གྱིས་རློབ་པ། ཆོ་ག་ཇི་ལྟ་བུས་བྱིན་གྱིས་རློབ་པ། རུང་ཁང་གི་བྱེད་ལས་བཤད་པ། བྱིན་རླབས་འཇིག་པའི་རྒྱུ་བཤད་པ་དང་དྲུག་ལས།
Enumeration Block 8:
གསུམ་པ་གང་ཟག་གང་གིས་བྱིན་གྱིས་རློབ་པ་ལ་བཞི་ཡོད་པ་ལས།
