Enumeration Block 1:
གཉིས་པ་འབྲེལ་པ་ཅན་གྱི་གཞུང་དོན་སྤྱིར་བསྟན་པ་ལ། དགོས་དོན་དང་། བསྡུས་དོན་གཉིས་ལས།
Enumeration Block 2:
གཉིས་པ་ལ། ཡུལ་གང་ལ་བླང་བ། རྟེན་གང་གིས་བླང་བ། ཆོ་ག་གང་གིས་བླང་བ་དང་གསུམ་ལས།
Enumeration Block 3:
ཆོས་ལ་ལུང་རྟོགས་ཀྱི་ཆོས་གཉིས།
Enumeration Block 4:
གཉིས་པ་ལ་ལུས་ཕུན་ཚོགས་པ། ཆ་ལུགས་ཕུན་སུམ་ཚོགས་པ། བསམ་པ་ཕུན་སུམ་ཚོགས་པ། བསླབ་ཚིག་ཕུན་སུམ་ཚོགས་པ་དང་བཞི་ལས།
Enumeration Block 5:
གསུམ་པ་ནི། དར་ཆོག་ལ་བརྟེན་ནས་བསྙེན་རྫོགས་སུ་སྒྲུབ་པའི་ཆོ་ག་ལ། སྦྱོར་བའི་ཆོ་ག ། དངོས་གཞིའི་ཆོ་ག ། མཇུག་གི་ཆོ་ག་དང་གསུམ་ལས།
Enumeration Block 6:
སློབ་དཔོན་མངོན་དུ་གྱུར་པ་ལ་གཉིས་ལས།
Enumeration Block 7:
གསུམ་པ་མཇུག་གི་ཆོ་ག་ལ། དུས་གོ་བརྗོད་པ་དང་། གདམས་ངག་བརྗོད་པ་གཉིས་ཡོད་པ་འོག་ཏུ་འཆད་དོ། །
