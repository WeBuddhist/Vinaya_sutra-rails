Enumeration Block 1:
དྲུག་པ་ཁང་པ་ལ་བརྟེན་པའི་ལྷག་མའི་ལྟུང་བ་འཆད་པ་ལ། གླེང་གཞི་སོགས་བཞི་ལས།

Enumeration Block 2:
འདིའི་སྐབས་སུ་མཐའ་དཔྱད་པ་ལ་གླེང་གཞི་སོགས་བཞི།

Enumeration Block 3:
བཞི་པ་ལ་བཞི་ཡོད་པ་ལས་

Enumeration Block 4:
མདོར་ན་ཁང་པ་དང་ཁང་ཆེན་གཉིས་ལ་ཁྱད་པར་ལྔ་ཡོད་དེ། དངོས་ཀྱི་བདག་པོའི་གྲངས་ཀྱི་ཁྱད་པར། ཆེད་དུ་བྱ་བའི་ཁྱད་པར། བཙལ་དགོས་མི་དགོས་ཀྱི་ཁྱད་པར། ཚད་ལས་ལྷག་པ་དགོས་མི་དགོས་ཀྱི་ཁྱད་པར། གནས་ཀྱི་ཐ་ཚད་ཀྱི་ཁྱད་པར་རྣམས་སུ་ཡོད་པའི་ཕྱིར།

Enumeration Block 5:
བཞི་པ་ལ་བཞི་ལས།
