Enumeration Block 1:
རྩ་བའི་བཞི་པ་ལ། གཞིའི་ཡན་ལག་བཤད་པ་དང་། བསམ་པའི་ཡན་ལག་བཤད་པ་དང་། སྦྱོར་བའི་ཡན་ལག་བཤད་པ་དང་། མཐར་ཐུག་གི་ཡན་ལག་བཤད་པ་དང་བཞི་ལས།
Enumeration Block 2:
གཉིས་པ་བསམ་པའི་ཡན་ལག་ལ་འདུ་ཤེས་དང་ཀུན་སློང་གཉིས་ལས།
Enumeration Block 3:
ཕམ་པ་གཉིས་པ་མ་བྱིན་ལེན་གྱི་ཕམ་པ་འཆད་པ་ལ། བསླབ་པ་འཆའ་བའི་སྙད་ཀ་གླེང་གཞི་དང་། བཅས་པ་འཇོག་པའི་རྒྱུ་མཚན་དགག་བྱ་ཉེས་དམིགས་བཤད་པ་དང་། ངོ་ཏི་བཤད་པ་དང་། ལྟུང་བའི་རྒྱུ་ཚོགས་ཡན་ལག་གི་བརྩི་བ་རྣམ་པར་གཞག་པ་དང་བཞི།
Enumeration Block 4:
བཞི་པ་ལ་དངོས་དང་། མ་བྱིན་ལེན་གྱི་ཕམ་པ་འབྱུང་བའི་གཞིར་གྱུར་བའི་རྫས་ཀྱི་རིན་ཐང་གི་ཚད་རྩི་ཚུལ་བཤད་པ་དང་གཉིས་ལས། དང་པོ་ལ། གཞི། བསམ་པ། སྦྱོར་བ། མཐར་ཐུག་གི་ཡན་ལག་དང་བཞི། དང་པོ་ལ། དེའི་གཞིར་གྱུར་བའི་རྫས་བདག་གི་ཁྱད་པར་དང་། དེའི་གཞིར་གྱུར་པའི་རྫས་ཀྱི་ཁྱད་པར་གཉིས་ལས།
Enumeration Block 5:
དེས་ན་འདི་ལ་བསམ་སྦྱོར་གཉིས་ཀྱི་སྒོ་ནས་རྫས་བདག་ཏུ་འགྱུར་ཚུལ། རིགས་རྒྱུད་ཀྱི་སྒོ་ནས་རྫས་བདག་ཏུ་འགྱུར་ཚུལ། ཡུལ་དུས་ཀྱི་སྒོ་ནས་དར་འགྱུར་ཚུལ། བཅས་པའི་སྟོབས་ཀྱི་དེར་འགྱུར་ཚུལ་དང་བཞི་ཡོད།
Enumeration Block 6:
དེས་ན་འདིར་ཤོ་གམ་གྱི་རྣམ་གཞག་བཤད་པ་ལ་ཤོ་གམ་དེ་ས་གང་ལ་དབང་བ། གང་ལ་གཞལ་བའི་བདག་པོ། དངོས་པོ་གང་ལ་དབང་གི་ཚད་ཇི་ཙམ་དབང་བ་དང་བཞི་ལས།
