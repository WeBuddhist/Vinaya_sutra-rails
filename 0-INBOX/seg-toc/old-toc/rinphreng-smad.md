# 4 མཇུག་གི་དོན། [[བཞི་པ་མཇུག་གི་དོན་ལ་བཞི། གུས་པ་བསྐྱེད་པའི་ཕྱིར་ཆེ་བ་བརྗོད་པ་]]
### 4.1 གུས་པ་བསྐྱེད་པའི་ཕྱིར་ཆེ་བ་བརྗོད་པ། [[དང་པོ་ནི། འདུལ་བའི་མདོ་ཞེས་བྱ་བ་ངེས་པར་འབྱུང་བའི་ཚུལ་ཁྲིམས་ཀ]]
